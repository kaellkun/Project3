# PreparationEffects：準備v3の実装と引き継ぎ

## 登録（別担当へ）

- 新規登録名：`Battle/Logic/PreparationEffects`、有効、パラメータ `{}`。
- **NRP_ChainSkill / StateAddMZ / CustomizeCritical / Keke_SpeedStarBattle / RIT_SucHitEva より後、ShieldBreakSystem より前**。現在の並びでは Battle/Slip/Keke_SlipCustom より後かつ ShieldBreakSystem より前に挿入できる。
- ShieldBreakSystem を後にする理由：敵のブレイクによる遅延行動の拒否を、準備の試行処理より先に判定するため。
- 会心2倍は別担当が CustomizeCritical の `commonFormula` を `normalDamage * 2` に変更する。このプラグインは会心倍率を上書きしない。1.25倍設定もそのまま尊重する回帰テストあり。
- 新規プラグインの登録、スキル・職業・武器の編集はこの担当では実施していない。登録前は移行した準備タグは動作しないため、データと登録を同時に反映すること。
- 古いNUUNスリップ系、State側の同名KekeはOFFのまま。Battle/Slip/Keke_SlipCustomを使用する。

## 採用した根拠

- [v3の準備ルール](職業ステータス設計案_全23職_v3.md#L107-L177)：倍率は `1 + PrepBonus合計 + TakenBonus合計`。異なる自己準備も加算。同一ステートは上書き。
- [既存の変更一覧](変更一覧.md#L128-L149)で上げた気合い2.5・熱血3・魂4・応援2倍は維持。旧メモ欄の1.5／2／3／1.2は採用しない。ATK/MAT特性と旧ダメージ倍率タグは除去して二重計上を防いだ。
- v3は通常の持続ATKバフ、耐性低下、脆弱を**乗算のまま**としている。勇気27、剣気解放55、興奮剤69、武器を研ぐ76、研磨98、業物仕上げ105、全軍武装108などを準備加算に置換していない。回復・銃の固定威力にATKバフを誤適用しない。
- 武器研磨77は既存の「次の一撃1.5倍＋必中」とv3の一点集中研磨が対応するため、明示的新値 **+1.0＋必中** を採用。現DBではこの77を付与するスキルは見つからなかった。
- 一撃集中104（スキル193）は「一点集中研磨」と同一だと断定できない別名・別効果なので、既存1.8倍＝**+0.8** と会心+30%を維持。v3の一律基準から推測して値を上げてはいない。

## タグ/API

ステートのメモ欄に設定する。ボーナスは倍率そのものではない。

| タグ | 意味 |
|---|---|
| `<PrepBonus:1.5>` | 使用者側に+1.5（単独2.5倍） |
| `<TakenBonus:1>` | 対象側に+1.0（単独2倍） |
| `<PrepSkillIds:1,2>` | スキルID限定 |
| `<PrepElements:2,3>` | 属性ID限定。通常攻撃属性の場合は使用者の攻撃属性集合と照合 |
| `<PrepHitTypes:0,1,2>` | 元の命中タイプ限定（必中／物理／魔法） |
| `<TakenSkillIds:1,2>` / `<TakenElements:2>` / `<TakenHitTypes:2>` | 対象側の同様の条件 |
| `<PrepConsume:false>` / `<TakenConsume:false>` | 消費せずに利用。省略時はtrue |
| `<PrepCertainHit>` | 命中1・回避0。物理／魔法分類や反撃・反射率は変えない |
| `<PrepCritical>` | **会心可能な攻撃だけ**会心確定。会心回避も無視 |
| `<PrepCriticalBonus:0.3>` | 会心可能な攻撃に会心+30ポイント（対象の会心回避を適用） |

- 異なる条件はAND、1つの条件内のカンマ列はOR。指定しない条件は制限なし。空の条件は不一致。式のevalはしない。
- 対象はスキルのHP/MPダメージ・HP/MP吸収。通常攻撃も含む。回復、支援、ダメージのない技、アイテムは対象外。0ダメージの攻撃・属性無効・外れでも試行として消費する。
- 同じステートに複数の準備効果があれば、どれかが有効な攻撃でまとめて消費する。104は会心不可魔法でも威力＋必中を使って消費するが会心は出さない。39単独は会心不可魔法では保持する。
- 明示的な0ボーナスも条件に合えば消費。負の加算は許可し、合計倍率の下限は0。
- `PrepConsume:false`も加算プールの指定であり、既存の持続ATK特性の代用ではない。

公開プレビューは `Game_Action.preparationRate(target)`、`preparationCertainHit()`、`preparationCriticalChance(target)`。予約・ステート解除・会心キューのshift・乱数消費を行わない。**calcElementRateは変更しない**ので、Resist系プラグインやChainSkillの属性照会も準備を消費しない。

威力は `evalDamageFormula` の結果に自動適用し、分散・最終丸めの前で反映する。**スキル式にさらにprepRateを掛けないこと**。v3文書の式サンプルは別実装案であり、この実装と併用しない。公開APIは照会用である。

## 消費・遅延・連結

1. 最初の実 `invokeAction`（Keke使用時はキュー投入）で使用者の一致効果を保存し、対象の一致効果も保存・消費する。
2. 保存先はGame_ActionをキーとしたWeakMap。**endActionでは消さない**。Kekeが終了済みアクションを復元しても全対象・全リピートの倍率を維持する。
3. 消費したステートは既に取り除かれているため、別の重なった行動やChainSkillに再利用されない。同じステートの再付与は次の別行動用として残る。古い行動の完了時解除で再付与を消す処理はない。
4. 入力取消・発動前の中止・対象なしは消費しない。キュー投入後の逃走・中止は既に試行済みなので返還しない。
5. 反撃・反射でも元の攻撃準備と元対象のTakenBonusは試行として消費する。反撃は新しいGame_Actionで反撃者自身の準備を使う。反射は元のGame_Actionの威力を保持し、反射先のTakenBonusは別に取得する。
6. 身代わりでは、元対象のTakenBonusは試行として消費するが、ダメージに使うTakenBonusは実際の被弾者のもの。これは「命中時」消費ではなく「試行時」消費を一貫させた挙動。
7. `Game_Action.apply`の直接実行にも対応。Kekeの仮適用 `_isTempApplyKe` / `_isTempKe` は準備を予約・消費しない。
8. CustomizeCriticalの事前会心判定に準備分を反映する。ミス・反撃で通常のitemCriが呼ばれない場合も対応する会心キューを進め、次対象へ結果をずらさない。
9. StateAddMZの旧残りターン数だけをリセットし、同じ準備ステートの再付与でターンを蓄積しない。スキル個別の追加ターン指定は尊重。移行した単発ステートはautoRemovalTiming=0で、支援・回復・ターン終了では失われない。戦闘終了時には除去する。

## 検証と未対応

- 新規34テスト成功：実MZ Game_Action/Game_Battler/BattleManager＋導入済みKeke_SpeedStarBattle、NRP_ChainSkill、StateAddMZ、CustomizeCritical、Battle/Slip/Keke_SlipCustomを全体評価。描画・入力・タイマー配送・パラメータ解析はテスト用境界。
- 検証条件：最初の32件は作業ツリーのままで成功。その後、別担当が編集中の[data/Skills.json](../data/Skills.json#L58)にJSON構文エラーが発生したため、最終34件は**SkillsだけHEAD版へメモリ内差し替え**して成功を確認した。Statesとプラグインは現在の作業ツリー版。ディスク上の担当外ファイルは変更していない。Skills修復後に通常の2テストファイルを再実行すること。
- 加算、対象数、リピート、遅延、早期endAction、重なる別行動、取消、再付与、条件、0、HP/MP回復・吸収、反撃、反射、身代わり、連結、会心、スリップ符号と二重計上、純粋プレビューを検証。
- 既存バトル回帰63件中62成功。盾のweapon-onlyテスト1件は、既存メモにも記録された装備なしfixtureの`weapons()[0]`エラーで失敗。このタスクでは未変更。
- RIT_SucHitEvaは物理回避式の不足していた1を補った（hit100/eva70/success100 → 実命中30%）。魔法・必中式は維持。元ファイルのCRLFを保つため差分チェックは`core.whitespace=cr-at-eol`で確認。

**未実装／検証外（推測で補っていない）**：

- 直撃43の防御・耐性無視、期待36の次バフ強化、祝福45のコスト0、不屈22・見切り47等の特殊消費。これらの旧データは変更していない。
- 職業専用の印段階・極み・ロックオン・過冷却・専用技の加算除外や追加MP/状態効果。現DBに対応ステートが特定できないため新IDを発明していない。条件付きタグの基盤は利用できる。
- 業火炉110の「炎威力2倍・3T」など、既存の空実装／説明と継続設定の不整合、伝説の武器100・神器109の特殊効果、混合効果67/68/79。通常の乗算バフを安易に準備加算に変えていない。
- Keke/NRP自体のChainSkillHit/Missの遅延判定タイミング（連結は着弾前に決まり得る）は変更していない。通常ChainSkillの別行動分離を検証済み。
- Kekeの固定スリップは既存の個別キュー経由。固定量の生成・適用は検証したが、TPBの個人ターンと全体endTurnの配送タイミング、マップ上の固定スリップ配送は変更・保証しない。
- 描画を含む全プラグイン同時起動の実ブラウザ戦闘、保存済み進行中アクションの再開、別プラグインが同じGame_Actionを別攻撃へ再利用する独自処理は未検証。WeakMapのスナップショットはセーブデータに書き込まない。
