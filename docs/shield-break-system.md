# シールドブレイクと弱点UI

[プラグイン本体](../js/plugins/ShieldBreakSystem.js) は導入・有効化済みです。
RPGツクールMZのプラグイン管理では、戦闘高速化・表示変更プラグインより下に置いてください。
専用画像やブレイク用ステートの登録は不要で、既存の敵DBも変更していません。

## まず試す

そのまま敵グループの戦闘テストを開始してください。ゴブリンなどの画像上側に、
盾と残数、弱点名が表示されます。タグなしの初期動作は以下のとおりです。

- **シールド3**。弱点への正のHPダメージで、1ヒットにつき1減少。
- 弱点は、DBの属性有効度が100%を超える属性。それがなければ**属性1（本プロジェクトでは物理）**。
- 弱点は最初から表示。プラグインパラメータで未発見時の「?」表示に切り替え可能。
- シールド0で **BREAK**。未実行行動を中断し、行動不能・被HPダメージ**2倍**。
- ブレイクさせた一撃は通常倍率。その後のヒットから倍率が適用されます。
- 期間終了でシールド全回復。敵が先に倒れる場合は防御中心で進めるか、テスト用に敵のHPを増やすと確認しやすくなります。

## 敵キャラのメモ欄

| タグ例 | 意味 | 省略時 |
| --- | --- | --- |
| `<ShieldPoints:5>` | 最大シールド。0でシステムとUIを無効化 | 3 |
| `<WeakElements:2,3,4>` | 属性弱点の属性ID | 下記の自動設定 |
| `<WeakWeapons:2,7>` | 武器弱点の武器タイプID | 下記の自動設定 |
| `<BreakTurns:1>` | ブレイク期間 | 1 |
| `<BreakDamageRate:2.0>` | ブレイク中の被HPダメージ倍率 | 2 |
| `<WeaknessHidden:true>` | 未発見の弱点を「?」表示。falseで常時公開 | パラメータに従う |
| `<ShieldUiOffsetX:20>` | UIを右へ20px（負数で左） | 0 |
| `<ShieldUiOffsetY:-16>` | UIを上へ16px（正数で下） | 0 |

属性ID・武器タイプIDは「データベース → タイプ」で確認できます。
本プロジェクトの属性は、1:物理、2:炎、3:氷、4:雷、5:水、6:土、7:風、8:光、9:闇です。
武器タイプは、2:剣、7:弓などです。**武器の個別アイテムIDではありません。**

### 弱点設定の優先順位

1. 有効な `WeakElements` または `WeakWeapons` があれば、そのタグを使用。未指定のもう一方は空になります。
2. 両方とも未設定なら、敵の初期化時点の属性有効度が100%を超える属性を使用。
3. それもなければ `DefaultWeakElements`（初期値1）を使用。

`<WeakElements:0>` は「属性弱点なし」を明示します。武器弱点だけの敵にも利用できます。
空値や不正なIDしかないタグは未設定扱い、有効IDの重複は除去します。
属性弱点の自動取得は初期化時に行い、戦闘中の一時的な耐性ステートで一覧は増減しません。

**タグはシールド弱点だけを指定し、DBの属性ダメージ倍率を書き換えません。**
たとえば炎弱点タグだけなら、炎ダメージが通常倍率でもシールドを削れます。
炎ダメージそのものも増やす場合は、通常のDB機能で属性有効度を設定してください。

通常攻撃属性（属性ID -1）のスキルでは、攻撃者の攻撃属性を参照します。
武器弱点はアクターによる通常攻撃属性（-1）のスキルで判定し、装備中の武器タイプを参照します。
二刀流・複数属性などで複数の弱点に一致しても、シールド減少は1ヒットにつき1回です。

## スキル・アイテムのメモ欄

| タグ例 | 効果 |
| --- | --- |
| `<ShieldDamage:2>` | 1ヒットでシールドを2減らす（省略時1）。0で減少だけ無効 |
| `<ShieldPierce>` | 弱点でなくてもシールドを削る（正のHPダメージが必要） |
| `<RevealWeaknesses>` | 命中時に対象の弱点をすべて公開（分析用） |

`ShieldPierce` と `RevealWeaknesses` は `:true` / `:false` も使用可能です。
分析スキルは「敵単体・必中・ダメージなし」などで作成し、`<RevealWeaknesses>` を指定します。
弱点発見は敵個体ごと・その戦闘中だけ保持し、同種の別個体や次の戦闘には引き継ぎません。
ブレイク中や `ShieldDamage:0` の攻撃でも弱点を発見できます。

ミス・回避・0ダメージ・HP回復・MPダメージではシールドを減らしません。
HP吸収は正のHPダメージとして扱います。継続ダメージやイベントのHP増減はシールド対象外です。
連続攻撃は命中ごとに判定します。味方にはこのシステムを適用しません。

## ブレイク期間

- **ターン制**: 発生ターンの残りに加え、指定したターン数だけ休止。最後のターン終了時に回復。
- **TPB（本プロジェクト）**: 本人の通常チャージ時間×指定数だけ休止。回復後はチャージ0から再開。
  ウェイトTPBの入力待ちでは期間も停止し、戦闘速度変更には追従します。
- ブレイク中は通常の行動制約4相当。専用ステートを使わないため、ステート解除でブレイクは消えません。
- 戦闘不能・復活・変身・戦闘終了時にはシールドと発見情報をリセットします。
- `Keke_SpeedStarBattle` のダメージ遅延待ち中の攻撃は、行動者がブレイクすると無効になり、回復後にも復活しません。
  すでに適用されたダメージや開始済みアニメーションを巻き戻すものではありません。

## 表示

独立したUIレイヤーで、敵画像上端に追従します。敵画像の色相変更・点滅には巻き込まれません。
通常のステートアイコンがある場合はその上に表示。画面端では画面内に収めます。
弱点は最大5列で折り返し、表示内容が変わったときだけ再描画します。
敵が非常に近い場合や巨大な敵の場合は、敵配置または位置補正タグで調整してください。

## 設定例

- 炎・氷が弱点のボス: `<ShieldPoints:6>` `<WeakElements:2,3>` `<BreakTurns:2>`
- 剣・弓だけが弱点: `<ShieldPoints:4>` `<WeakWeapons:2,7>` `<WeaknessHidden:true>`
- 弱点を無視して2削る技: `<ShieldPierce>` `<ShieldDamage:2>`
- 対象外の敵: `<ShieldPoints:0>`
