# ステータス確認画面

既存の `FlexibleTopDownUI` に統合。プラグインの追加登録やセーブデータの変更は不要です。

戦闘中の「味方ステータス」から開く場合も、この画面を使用します。旧ステート情報ウィンドウは表示しません。

- 上部：**ステート状況／弱点･耐性／威力増加／戻る**の4択。初期表示はステート状況です。
- 左側：名前、職業、レベル、HP・MP（設定時はTP）、能力値、経験値、プロフィール。装備一覧は表示しません（装備画面で確認）。
- 右側：選んだ情報を表示。左側の内容は切替時も維持します。

## 表示内容

**弱点･耐性**は属性ごとのダメージ倍率とステートごとの付与率補正です。
属性・ステートは1行に2件ずつ並べ、見出し行だけが1行を占めます。
装備・職業・現在のステートを含むアクターの実効値を参照します。
100%は通常、100%超は弱点、100%未満は耐性、0%は無効です。
属性の負の倍率は吸収として表示します。付与率補正は、スキル固有の成功率などを
含めた最終的な命中確率ではありません。敵のシールド弱点タグとは別の表示です。

状態異常の耐性は、ステートのメモ欄に `<StatusState:スコア>` を設定したものだけを表示します。
スコアの小さい順に並び、スコアが大きいステートほど下になります。同点の場合はステートID順です。
タグのないステートは表示しません。

**威力増加**は属性ごとの与ダメージ倍率です。`Keke_ElementFullCustom` の
`<属性威力: *1.1, 炎>` などのタグを、アクター・職業・装備・ステート・
習得中のパッシブ（`NUUN_PassiveSkill` の武器オブジェクト）から集計します。
`*n` は乗算、`+*n` はダメージのn倍を加算（倍率に合算）、`+n` は固定加算として
倍率の後ろに `+n` を併記します。`全`、`!属性名`（指定以外）にも対応します。
末尾に通常攻撃へ付く属性（特徴「攻撃時属性」）を表示します。
スキル側の `<属性威力>`、`通常攻撃` 指定、反転 `r` は含みません。

**ステート状況**は付与中のステート（アイコンなしも含む）、自動解除までの残りターン・歩数、
能力強化／弱体の段階・倍率・残りターンです。何も付与されていない場合は「なし」を表示します。

## 操作

- 上部コマンドの選択で右側の表示を切替。決定すると詳細一覧を操作できます。
- マウス／タッチはコマンドを1回クリック／タップして決定。「戻る」で画面を閉じます。
- 左右パネルはホイール／ドラッグでスクロールできます。パネルをタップすると操作対象になります。
- 詳細閲覧中の上下キーで項目移動、左右キーで左／右パネルを切替。
- キャンセルで上部コマンドへ戻り、コマンド上のキャンセルで画面を閉じます。
- Q/W（ゲームパッドではL/R）で前後のアクターへ切替。表示種類は維持されます。
- 画面が狭い場合も左右構成を維持し、文字サイズとスクロールで対応します。

## 検証

`node --test tests/status-detail.test.cjs tests/menu-window-layout.test.cjs`

実エンジンのウィンドウ、アクター、装備・ステートの特徴計算を利用し、
4種類の画面サイズ・情報切替・戻る・実効耐性・威力増加タグの集計・2列配置・
残り期間・アクター切替を確認します。

## 同じプラグインに含む他の調整

- 装備画面のスロット一覧は2列表示。スロット名幅は実際の装備タイプ名に合わせ、
  長い装備名はセル幅に収まるよう文字サイズを縮小します。
- スキル画面で選択中のスキルタイプに該当スキルがない場合、一覧に「該当スキルなし」を表示します。
- メニューコマンドは生成時に1行分で作られてから全行分へ拡張されるため、2行目のコマンドを
  記憶して戻った際に残っていたスクロール量を、拡張時に再クランプして解消します。
