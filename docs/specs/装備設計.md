# 装備設計

本作の装備の考え方・枠・数値の物差し・合成・初期装備をまとめたもの。赤シンボル設計書（序章・第1章v4、第2〜4章v2）と対になる。

------------------------------------------------------------------------

## 0. 基本方針

| 方針                   | 内容                                                                                                             |
|------------------------|------------------------------------------------------------------------------------------------------------------|
| 装備で格上を倒す       | 数値の底上げより、相性で格上の敵を倒す遊びを主役にする。装備は「レベルの代わり」ではなく「レベル差を埋める道具」 |
| デバフで釣り合いを取る | 積載のような特殊パラメータは増やさない。強い効果には、装備そのものにデバフを付けて釣り合わせる                   |
| 無限強化はしない       | 決まったレシピでの合成だけで装備を増やす。強さの上限はレシピで決まる                                             |
| 枠ごとに役割を分ける   | 同じ効果をどの枠でも積めるようにせず、枠ごとに受け持ちを決める                                                   |
| 装飾品でビルドを楽しむ | 装飾品の枠は多めにし、職業の仕組みを伸ばす効果や代償つきの効果で組み合わせを楽しませる                           |

前提になる本作のルール：DEF・MDFは使わない（ダメージ式に防御の引き算がない）。経験値は赤シンボルでしか入らず、1体1Lv（全98体でLv99）。一人倒れたらゲームオーバー。行動順はCTB。

## 1. 装備の枠と役割

| 枠                     | 受け持ち                                                       | 典型的なデバフ                                   |
|------------------------|----------------------------------------------------------------|--------------------------------------------------|
| 武器                   | ATK・MAT、属性、系統の威力、会心・命中                         | MP消費増、命中低下                               |
| 外装（ローブ・マント） | 魔法倍率、属性耐性、最大MP                                     | 別の属性の弱点化（対炎のマントは氷に弱い、など） |
| 内装（アーマー）       | 物理倍率、最大HP                                               | AGI低下、雷弱点（金属）                          |
| 帽子                   | 状態異常耐性、命中、初期TP                                     | 最大MP低下、被会心増                             |
| 靴                     | 回避、先制、TPチャージ                                         | 最大HP低下、被ダメ増                             |
| 装飾品（多数）         | 職業の仕組みの増幅、条件つき効果、代償つき効果、属性ごとの耐性 | 代償型（回復アイテムと同じ考え方）               |

- 「鎧の上にマントを羽織る」重ね着が、そのまま「物理対策と魔法対策の組み合わせ」になる。
- 金属の内装は雷に弱い（導体だから）。外装の「絶縁の外套」で補う、といった組み合わせが生まれる。
- 物理・魔法の被ダメ倍率を持てるのは内装と外装だけ。装飾品に汎用の被ダメ倍率は付けず、属性ごとの耐性に限る。

## 2. デバフで釣り合いを取るルール

### 2.1 重い防具ほどAGIが下がる

防具の被ダメ倍率が大きいほど、AGIを下げる。

- AGIは固定値ではなく、特性の「通常能力値 AGI×〇〇%」（code 21）で下げる。固定値だとLv1では重すぎ、高Lvではほぼ意味がなくなる。
- CTBでは、AGIの低下がそのまま行動回数の低下になる。重い防具のコストは「自分の手数」。
- その結果、重い防具は被弾が集中するかばう役に集まり、攻撃役は軽い防具を選ぶ、という役割分担がルールから自然に生まれる。

### 2.2 効かないデバフを作らない

デバフに使ってよいのは次の2種類だけ。

- **誰にでも効くもの**：AGI、最大HP、被ダメ倍率、回避、属性弱点、被会心。
- **プラスの効果と同じ軸のもの**：「炎術の威力+20%・MP消費+20%」「会心+15・命中−10」など。

「ATK+15%・MAT−30%」を剣士が着ても何も失わないので、こうした組み合わせは作らない。例外は雷魔術師で、ATKとMATの両方を使うため「ATK+20%・MAT−20%」が本当の選択になる（両刀の意味が装備選びにも出る）。

### 2.3 常用装備と対策装備

| 種類     | 内容                       | 歯止め                                                     |
|----------|----------------------------|------------------------------------------------------------|
| 常用装備 | いつ着ても強い品           | 価値点（3章）の上限を守る                                  |
| 対策装備 | 特定の敵にだけ非常に強い品 | 価値点の外に置く。普段使いすると損になる重いデバフを付ける |

例：「絶縁の外套：雷耐性0.3倍、ただしAGI−15%・炎弱点1.2倍」。雷を使う敵の前では主力、普段は着たくない。付け替える理由がデバフで生まれる。

## 3. 数値の物差し

### 3.1 価値点（常用装備の歯止め）

効果を「戦力5%＝1点」で換算する。プラスの効果は点を使い、デバフは点を返す。

| 効果                   | 1点あたり             | 備考                                  |
|------------------------|-----------------------|---------------------------------------|
| ATK・MAT               | 想定Lvでの素の値の+5% | 固定値で書き、章ごとに換算し直す      |
| 最大HP                 | +5%                   | 一人倒れたら終わりなので重要          |
| 最大MP                 | +10%                  |                                       |
| 物理・魔法の被ダメ倍率 | 0.05下げる            |                                       |
| 会心率                 | +5                    | 会心2倍なので期待火力+5%              |
| 命中率                 | +5                    | 物理職だけに意味がある                |
| TPチャージ率           | +10%                  |                                       |
| 初期TP                 | +10                   |                                       |
| 特定の系統の威力       | +10%                  | 「炎術」「連撃」など                  |
| 属性耐性（1属性）      | 0.8倍                 | 弱点1.2倍はマイナス1点                |
| 回避率                 | +5で1.5点             | 結果の振れ幅が大きいので割高          |
| AGI                    | ±5%で2点              | CTBでは行動回数そのものなので最も割高 |

常用装備1つあたりの合計点（プラス−デバフ）の上限：

| 時期  | 上限の目安 |
|-------|------------|
| 序章  | 2点        |
| 第1章 | 4点        |
| 第2章 | 6点        |
| 第3章 | 8点        |
| 第4章 | 10点       |

武器の基本ATK・MAT（3.2の目安）は価値点に数えない。価値点は、それ以外の効果（防具のすべて、武器の追加効果）に適用する。

Excelに「価値点」の列を足して式で合計し、上限を超えた品をデータ生成の段階で検出する。

### 3.2 武器の上げ幅

武器の上げ幅は「手に入る時点の想定Lvにおける素の値の20%」、上限30%。上限の30%は、格闘家の「素手時ATK+30%」（武器補正の代わり）と揃えている。初期装備だけは12%に抑え、最初の合成で「倍以上になった」と感じられる落差を残す。

剣士のATK（設計書v3：65→650、普通成長）での目安：

| 時期     | Lv  | 素のATK | 武器の目安（20%） |
|----------|-----|---------|-------------------|
| 序章開始 | 1   | 65      | 初期のみ+8（12%） |
| 序章末   | 15  | 149     | +30               |
| 第1章末  | 46  | 334     | +67               |
| 第2章末  | 68  | 465     | +93               |
| 第3章末  | 85  | 566     | +113              |
| 最終     | 99  | 650     | +130              |

### 3.3 固定値と倍率

- ATK+30のような固定値は、レベルが上がるほど価値が薄まる。
- 「炎術+20%」「会心+10」のような倍率の効果は、ずっと同じ価値を持つ。後半に重ねすぎると掛け算で膨らむので、倍率の効果は1キャラあたり系統ごとに合計の上限を決める（威力系は合計+50%まで、など）。

### 3.4 被ダメ倍率の下限

- MZでは被ダメ倍率の特性はすべて掛け算で重なる。
- 装備による倍率は、物理・魔法とも合計0.6までを下限にする。スキルやステートの倍率はその外に置き、硬さの天井を職業とスキルの側に残す（ビーツー、老兵、機械装甲兵のタンクとしての価値を守る）。

### 3.5 相性で埋まるレベル差

弱点を突く武器（1.5倍）と、主な攻撃を半減する防具（敵のダメージの半分がその攻撃なら、被ダメ全体で−25%）の2つを揃えると、第1章前半なら約10Lv上の敵と「ぎりぎり」で戦える。敵は脅威を2〜3つ持ち、その時点の手持ちでは2つまでしか塞げないように作る（赤シンボル設計書0.2）。

## 4. 合成とレシピ

### 4.1 基本

- 装備は決まったレシピでの合成だけで増える。無限強化はしない。
- 汎用素材は稼げても、稼ぎで変わるのは「いつ作れるか」だけで、「どこまで強くなるか」は変わらない。

### 4.2 素材の2種類

| 種類     | 入手                                         | 役割                     |
|----------|----------------------------------------------|--------------------------|
| 汎用素材 | ランダムエンカウント、採取ポイント（稼げる） | 作る時期を早められる     |
| 要の素材 | 宝箱・サブクエスト・赤シンボル（一点物）     | どこまで進んだかで決まる |

各レシピに要の素材を1つ必ず入れる。汎用素材をいくら稼いでも、先の章の装備は前倒しで作れない。

### 4.3 レシピが解放される経路

- 鍛冶屋・薬師のパッシブ（系統ごとの大きな解放）
- 探索で見つかる設計図（宝箱・遺跡・サブクエスト）
- 素材を初めて手に入れたとき（「魔鉄を見た鍛冶屋が思いつく」形）
- 条件ドロップ（部位を壊してから倒す、弱点属性で倒す、など手間をかけた倒し方で出る珍しい素材）

レシピの解放を鍛冶屋のレベルだけに結びつけると、装備の成長もシンボル撃破に縛られるので、経路を分ける。

### 4.4 作れる数

- **基本の品は何個でも作れる**：汎用素材だけで作れる帽子・靴など。全員に行き渡らせてよいもの。
- **上位の品は一点物**：要の素材が1つしかないので1個だけ。誰に着せるかがパーティー全体のビルドになる。

### 4.5 分岐する強化

同じ装備から方向の違う2つのレシピを用意する。片方を作ると元の装備は消える。

> 支給の胸当て ├ 魔鉄の胸当て：物理0.8・HP+15%、AGI−10%（重く硬い方向） └ 軽鋼の胸当て：物理0.9・回避+5、デバフなし（軽く避ける方向）

どちらも価値点は同じ。強さは同じで、使い方だけが違う。

### 4.6 素材で重さが変わる

上位の素材ほど「同じ守りでより軽く」する（AGIの低下が小さくなる）。材料工学の比強度（重さあたりの強さ）を遊びにしたもので、鍛冶屋の会話や図鑑で教育要素につなげられる。

### 4.7 第4章のループ

第4章のループは、実質的に章を重ねていく扱いにする。ループで世界が巻き戻っても、Lv・装備・素材・レシピ・倒した赤シンボルはすべて引き継ぐ。

- ループごとの赤シンボルは、前のループまでの装備を持っている前提で強さを決める。
- 価値点の上限（第4章は10点）は、第4章全体で1つの上限として扱う。ループごとに上限を上げない。
- 物語上は「時魔術師の力で、持ち物と経験が巻き戻らずに残る」と説明できる。

### 4.8 出さないもの

ランダムな付加効果の付いた装備（いわゆるハクスラの掘り出し物）は出さない。決まったレシピでの合成と両立しないため。境の樹海でのハクスラは、素材集めと条件ドロップで楽しませる。

## 5. 装飾品

### 5.1 持たせたい効果

- **代償つきの効果**：「会心+15・最大HP−15%」など。回復アイテムの代償と同じ考え方で、世界観の一貫性が出る。
- **職業の仕組みを増幅する効果**：「印Lv3で撃つ炎術の威力+20%」「帯電の敵への初撃必中」など。その仕組みを持つ職業にしか意味がないので、装飾品で職業の代わりができない。
- **条件つきの効果**：「HP50%以下で敏捷+20%」「戦闘開始から3行動、回避+20」など。
- **属性ごと・状態異常ごとの耐性**：即死耐性、魔封じ耐性、錆止め、丸呑み防止など、特定の敵への対策。

### 5.2 避けたい効果

- 汎用の被ダメ倍率（防具の役目）
- 固定値のAGI（CTBでは最も強い上げ幅）
- スキルを付与する装飾品（魔狐の魔石のようなもの）は、職業のスキルと役割が重ならないものに限る。序章には置かない。

### 5.3 重ね掛けの歯止め

同じ系統の装飾品は`<EquipUnique>`で1つまでにする（会心系は1つまで、など）。掛け算の暴走を止める。

## 6. 初期装備（支給品）

3人は東方の都市国家から派遣された先遣隊なので、初期装備は全員同じ規格の「支給品」。性能が控えめなのは「国の規格品だから」で説明がつく。鍛冶屋が開拓地の素材で最初の装備を作る場面が、「故郷の支給品から、この土地で作った道具へ」という開拓の物語になる。

|          | 武器                     | 防具                                          | 価値点  |
|----------|--------------------------|-----------------------------------------------|---------|
| 剣士     | 支給の長剣：ATK+8        | 支給の胸当て（内装）：物理0.9・HP+10%・AGI−5% | 防具2点 |
| 炎魔術師 | 支給の杖：MAT+12         | 支給のローブ（外装）：魔法0.95・HP+20         | 防具2点 |
| 雷魔術師 | 支給の短杖：ATK+4・MAT+4 | 支給の外套（外装）：魔法0.95・HP+20           | 防具2点 |

- 帽子・靴・装飾品は空。空いた枠は、この先で手に入る物への約束になる。
- 剣士だけ最初からデバフ付きなので、最初の装備画面で「重い防具は遅くなる」ことを見せられる。
- 雷魔術師の武器をATKとMATに半分ずつ振るのは、最初の合成を「短剣か杖か」という選択にするため。
- 具体的な数値・説明文・序章で手に入る装備は「初期装備の具体案」にまとめている。
- 序章では、S1の前に村の鍛冶場で「採掘つるはし」（打属性・岩特効）を借りられる。S1とS1bの回答になる。

## 9. 注意したい点

- **AGIの固定値**：CTBでは最も強い上げ幅。既存の「敏捷マナ石+20」は、Lv1の炎魔術師に付けると行動回数が4割前後増える。マナ石（HP+100、MP+30、AGI+20）はLv10開始の頃の前提なので、入手時期を遅らせるか%表記に変える。
- **回避**：一人倒れたら終わりのルールでは、回避に頼るほど「運で全滅」が起きやすい。初期装備には付けず、回避は価値点を割高にしている。
- **VisuMZ CTBの速度式**：ゲージの速度がAGIに比例する設定か確認する。比例していないと、AGI×0.85が行動回数−15%にならない。
- **付け替えの手間**：対策装備が増えると、赤シンボルの前に何人も着替えさせる作業が面倒になる。装備の組み合わせを保存して切り替えられる仕組み（プラグインの装備セット機能など）を確認する。

| 属性耐性・弱点       | 属性有効度（code 11）                                |
| 状態異常耐性         | ステート有効度（code 13）、ステート無効化（code 14） |
| 同系統の重ね掛け防止 | メモ欄の`<EquipUnique>`                              |

- 錆び（F6）は、錆びた版の装備に差し替える形か、装備に付くステートで作る。研ぎ直しで元に戻す。
- 丸呑み（G5）は、戦闘中に外装を一時的に外し、4ターン後に所持品から消す。
- Excelの装備シートに「価値点」「解放の章」「要の素材」「分岐元」の列を持たせる。
