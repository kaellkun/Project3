# 教育要素の開示指針

## 概要

本書は、ゲーム内で教育的コンテンツをプレイヤーに自然に届けるための設計指針である。
「繰り返し見ても価値がある」「ゲームとして面白い」「受験勉強に役立つ」の3点を両立させる。

---

## 基本方針

| 原則 | 内容 |
|------|------|
| 押し付けない | 教育要素は「気づいたら覚えていた」が理想 |
| 繰り返しに耐える | 何度見ても「そうだった」と確認できる内容 |
| 段階的に深まる | 浅い→深いへ、興味に応じて掘り下げ可能 |
| 受験に直結 | 中学〜高校範囲の理科・社会の用語を正確に使用 |

---

## 5層構造

```
【第1層】スキル説明文（1行・繰り返し表示）
    ↓
【第2層】戦闘後セリフ（ランダム・1回表示・実績記録）
    ↓
【第3層】拠点会話（任意・フラグ管理）
    ↓
【第4層】図鑑/考察録（完全任意・コレクション）
    ↓
【第5層】ダンジョン内リアクション（条件付き・短め）
```

# 第1層：スキル説明文

## 設計指針

| 項目 | 内容 |
|------|------|
| 文字数 | 全角25〜35文字程度（1行に収まる） |
| 表示頻度 | スキル選択時に毎回表示 |
| 目的 | 「何度も見て自然に覚える」フレーズ |

## 作成ルール

### 1. 受験キーワードを必ず1つ含める

```
○ 「燃焼の三要素を強制供給」      → 燃焼の三要素（中学理科）
○ 「電位差で電流を流す」          → 電位差、電流（中学理科）
○ 「分子間力を超える衝撃」        → 分子間力（高校化学）
× 「めっちゃ燃える炎を出す」      → キーワードなし
```

### 2. 因果関係を含める

```
○ 「帯電させれば雷は落ちる」      → 帯電→雷の因果
○ 「熱膨張で継ぎ目が歪む」        → 熱膨張→歪みの因果
× 「強い雷を落とす」              → 因果なし
```

### 3. キャラの口調を反映

```
炎魔術師（知的・自信家）：「プラズマ化した炎は形を選ばない」
雷魔術師（クール・皮肉）：「神経伝達も電気信号。止めてあげる」
美人格闘家（熱血・直球）：「共振で内側から壊す！これが極み！」
ハロルド（メタ・ネタ）：「主人公補正＝確率の偏り。統計学的に正しい」
```

# 第2層：戦闘後セリフ

## 設計指針

| 項目 | 内容 |
|------|------|
| 文字数 | 3〜5行（80〜150文字程度） |
| 表示条件 | 戦闘中に使用したスキルからランダム抽選 |
| 表示回数 | 各セリフ1回のみ（実績欄に記録） |
| 目的 | 第1層の内容を少し掘り下げる |

## 発生ルール

1. 戦闘終了時、その戦闘で使用されたスキルをリストアップ
2. 未表示のセリフを持つスキルからランダムに1つ選択
3. 該当スキルのセリフを表示
4. 表示済みフラグをON（実績欄に追加）
5. 全スキルが表示済みの場合、何も表示しない

## 具体例

### 【共振と固有振動数】

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【共振と固有振動数】

■ 固有振動数とは
全ての物体には、最も振動しやすい周波数がある。
これを「固有振動数」という。

例えば：
・ブランコには、最も効率よく揺れる周期がある
・ワイングラスには、最も響く音の高さがある
・橋には、最も揺れやすい風の周期がある

■ 共振とは
外部からの振動が固有振動数と一致すると、
振幅が急激に大きくなる。これを「共振」という。

身近な例：
・ブランコを押すタイミングを合わせると大きく揺れる
・オペラ歌手がワイングラスを割る
・1940年、タコマ橋が風で崩壊（共振による破壊）

■ 二重の極みの原理
0コンマ数秒の間に二度の打撃を与えることで、
対象の固有振動数に近い振動を発生させる。
これにより共振が起こり、内部構造が崩壊する。

理論上は、どんな硬い物質でも破壊可能。
ただし、固有振動数を正確に把握し、
適切なタイミングで打撃を与える技術が必要。

■ 関連する受験知識
・固有振動数（高校物理）
・共振・共鳴（高校物理）
・強制振動（高校物理）
・タコマ橋崩落（物理の教科書でよく引用される事例）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 【燃焼の三要素と熱暴走】

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【燃焼の三要素と熱暴走】

■ 燃焼の三要素
火が燃えるためには、以下の3つが必要：

1. 酸素（支燃物）
   └ 酸化反応を起こすために必要

2. 熱（点火源）
   └ 発火点まで温度を上げるために必要

3. 燃料（可燃物）
   └ 酸化されて熱を発する物質

この3つのうち1つでも欠けると、火は消える。
消火器は「酸素を遮断」「温度を下げる」「燃料を除去」の
いずれかの方法で消火する。

■ 発火点と引火点
・発火点：外部からの火がなくても自然に燃え始める温度
・引火点：火を近づけると燃え始める温度

例：紙の発火点は約450℃、ガソリンの引火点は約-40℃

■ 熱暴走とは
発熱反応が制御不能になり、温度が急激に上昇する現象。

メカニズム：
1. 発熱反応で温度が上昇
2. 温度上昇により反応速度が上昇（アレニウスの法則）
3. 反応速度上昇によりさらに発熱
4. 1に戻る（正のフィードバック）

冷却が追いつかないと、温度は際限なく上昇する。
原子炉のメルトダウンも、熱暴走の一種。

■ 天照の原理
魔力を燃料として供給し続けることで、
熱暴走状態を人工的に維持する。
燃料が尽きないため、炎は消えない。

■ 関連する受験知識
・燃焼の三要素（中学理科）
・発火点・引火点（中学理科）
・酸化反応（中学理科）
・アレニウスの法則（高校化学）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
