# 機械虫設計（序章・薬草地帯）

遺跡の手前にある薬草地帯の奥だけに出るランダムエンカウント。**目標Lv5**（遺跡・中層のS2cを倒したあと）で安定して勝て、Lv1では「正解の手を知っていても苦しい」強さにする。経験値は入らない（ランダムエンカウント共通）。

------------------------------------------------------------------------

## 0. 方針

| 項目 | 内容 |
|------|------|
| 出現場所 | 薬草地帯の奥のリージョンのみ。メインクエストの薬草は手前で取れる |
| 目標Lv | Lv5で勝率ほぼ100％・残りHP8割前後（今のLv1で戦うワーウルフと同じくらいの手応え） |
| Lv1 | 勝率1〜3割。挑発・弱点・優先撃破を知っていても苦しい |
| Lv3 | 8割前後勝てるが、残りHPは半分〜7割（赤字） |
| 3種の役割 | 重装＝HPのしきい値、高速＝AGIと手数、妨害＝先に落とすかどうか |
| 数値 | すべて昼の値。夜はEnemyNightPowerの倍率がかかる |

------------------------------------------------------------------------

## 1. 敵キャラ

能力値は `[HP, MP, ATK, DEF, MAT, MDF, AGI, LUK]` の順。DEF/MDF/LUKは0（本作では未使用）。

### 1.1 装甲甲虫（重装型）

| 項目 | 値 |
|------|----|
| 能力値 | `[3400, 0, 90, 0, 0, 0, 50, 0]` |
| 属性有効度 | 近接物理 50％、雷 150％ |
| その他 | 麻痺の有効度 50％ |
| メモ | `<ShieldPoints:8>`（弱点は雷が自動で入る） |
| 行動 | 突進 → 力溜め → 圧砕 の繰り返し |

| スキル | 内容 | 行動条件 |
|--------|------|----------|
| 突進 | `a.atk*1.2`、打＋近接物理、敵単体（ランダム）、分散10 | ターン 1+3X |
| 力溜め | ダメージなし。「装甲を軋ませ、脚を沈めた…」 | ターン 2+3X |
| 圧砕 | `420`（固定）、打＋近接物理、敵単体（ランダム）、分散5 | ターン 3+3X |

- 圧砕は399〜441。Lv1の炎（380）・雷（400）は一撃で倒れ、Lv3（450／473）なら満タンで耐えられる。剣士は物理0.8倍で約336なので、挑発で受けられる。
- 行動予測UIで「力溜め→圧砕」が見えるので、挑発・回避・先に削り切る、の3つの回答がある。
- 物理はほぼ通らず、雷魔法（紫電-放）が弱点を突く。紫電-斬は近接物理×雷で0.75倍になり、弱点としては働かない（この差を見せる敵）。

### 1.2 跳ね脚虫（高速型）

| 項目 | 値 |
|------|----|
| 能力値 | `[900, 0, 80, 0, 0, 0, 125, 0]` |
| 属性有効度 | 炎 130％ |
| 特徴 | 回避率 +30％（魔法回避なし） |
| メモ | `<ShieldPoints:4>`（弱点は炎） |
| 行動 | 連続刺しのみ |

| スキル | 内容 |
|--------|------|
| 連続刺し | `a.atk*0.9`、刺＋近接物理、**敵2体ランダム**、分散10 |

- AGI125。Lv1のパーティー（剣49・炎50・雷83）に対しておよそ1.5〜2.5倍の手数になる。Lv5の雷（132）で追い越す。
- 物理は3割外れ、魔法は外れない。豪火球の火傷（AGI・ATK×0.8、回避−30）がよく効く。

### 1.3 電波蛾（妨害型）

| 項目 | 値 |
|------|----|
| 能力値 | `[480, 0, 40, 0, 40, 0, 90, 0]` |
| 属性有効度 | 変更なし |
| メモ | `<ShieldPoints:3>`（弱点は自動で近接物理） |
| 行動 | ジャミング → 放電 の繰り返し |

| スキル | 内容 | 行動条件 |
|--------|------|----------|
| ジャミング | 敵全体に状態「ジャミング」50％ | ターン 1+2X |
| 放電 | `a.mat*1`、雷＋魔法、敵単体（ランダム）、分散10 | ターン 2+2X |

- 状態「ジャミング」：MPを使うスキルタイプを封印、行動終了時に3ターンで解除。封印中はジャブなどMPを使わない技だけになる。
- 単体では出さず、重装型か高速型と組ませる。HP480はLv5の3人が集中すれば1巡で落とせる量。Lv1では落としきれず、先に動かれる（AGI90＞剣・炎）。

| # | 編成 | 出現の重み | ねらい |
|---|------|-----------|--------|
| 1 | 装甲甲虫 | 3 | 予告を見て挑発で受ける／雷で弱点を突く |

## 3. 簡易シミュレーションの結果

勝率／勝ったときの残りHP合計（％）。各4000戦。

| 編成 | Lv1 | Lv2 | Lv3 | Lv4 | Lv5 | Lv7 |
|------|-----|-----|-----|-----|-----|-----|
| 装甲甲虫 | 27／71 | 93／71 | 100／75 | 99／83 | 99／93 | 100／96 |
| 装甲甲虫（挑発を使わない） | 19／76 | － | 77／77 | － | 97／88 | － |
| 跳ね脚虫×2 | 12／33 | 41／43 | 81／54 | 95／63 | 100／76 | 100／81 |
| 電波蛾＋装甲甲虫 | 12／63 | 52／59 | 87／69 | 100／80 | 93／82 | 100／92 |
| 電波蛾＋跳ね脚虫 | 33／43 | 73／57 | 90／64 | 97／71 | 99／77 | 100／83 |
| 参考：ワーウルフ（既存） | 98／71 | 100／78 | 100／83 | 100／86 | 100／90 | 100／92 |

- 跳ね脚虫×2に風切り羽根を足すと（雷AGI×1.155）、Lv4で95→99％に上がる。
- 装甲甲虫は「挑発で圧砕を受ける」を知っているとLv2で越えられる。知識で早く越えられる敵として残すか、突進を強めてLv3まで引き上げるかは要検討。
- 電波蛾＋装甲甲虫のLv5（93％）がLv4より低いのは、ジャミングの当たり方による揺れと見ている。実機で確認する。

### 前提（反映していないもの）

- 回復アイテム・瞑想・TP技（乱舞技など）・パッシブ・会心は使っていない。実機ではもう少し楽になる。
- パーティーは初期装備（剣：ATK×1.1・AGI×0.9・物理被ダメ0.8／炎：MAT×1.21・AGI×1.1・回避10／雷：MAT×1.1・ATK×0.9・AGI×1.1・回避10）。
- 行動はLinearTimeBattleどおりAGIに比例。ブレイクは次の1行動を飛ばし、その間の被ダメージ2倍。
- 作戦：剣＝ミナモギリ（圧砕の予告中は挑発）、炎＝豪火球（単体の大物には先に火遁印）、雷＝紫電-放か紫電-斬の強い方。狙いは電波蛾を優先し、次にHPが少ない敵。

## 4. 実装メモ

- 行動条件の「ターン」は、タイムプログレスではそれぞれのバトラーの行動回数で数えるので、1+3Xの形で周期を作れる。
- ジャミングの封印対象は、各職業のMPスキルが入っているスキルタイプ（特徴：スキルタイプ封印）。瞑想・挑発・ジャブが別タイプなら、それだけ残る。
- 報酬は経験値なし。機械部品（合成素材）とお金を落とし、遺跡から戻ってきたときに狩る理由にする。
