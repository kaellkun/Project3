## ロール別解説

### 【純アタッカー】8職

物理か魔法で大ダメージを与えることに特化。パーティの火力の要。

|:-----|:-------|:-----|:-----|:------:|
| **剣士** | 物理バランス | 連撃・単体・全体すべてこなせる | 器用貧乏になりがち | ★★☆ |
| **炎魔術師** | 魔法（印システム） | 印Lv3で最高火力、全体攻撃◎ | 準備に時間がかかる | ★★★ |
| **雷魔術師** | 魔法（瞬間火力） | 過電流で最大ダメージ | 自傷があり継続力△ | ★★★ |
| **格闘家** | 物理（最高ATK） | 単純火力No.1、破砕でデバフも | MPが低く技が限られる | ★★☆ |
| **特記戦力兵** | 物理（カウンター） | 見切り・反撃が強力 | 読み合いが必要 | ★★★ |
| **侍** | 物理（一撃必殺） | 居合いで超高倍率ダメージ | 構えが必要、隙が大きい | ★★★ |

## 職業詳細

### 【剣士】バランス型物理アタッカー

```
HP:  ■■■■■■□□□□ B (6000)
MP:  ■■■□□□□□□□ C (800)
ATK: ■■■■■■■■■□ A (900)
MAT: ■■■■□□□□□□ D (400)
AGI: ■■■■■■■□□□ B (700)
```

**特徴**
- 序盤から終盤まで安定して使える万能剣士
- 連撃（九頭龍閃）、単体（超振動斬り）、全体（オールレンジ乱舞）をすべて習得
- 終盤は「浮遊剣展開」でオールレンジ攻撃が可能に

**おすすめの使い方**
- 序盤：斬撃系スキルで堅実にダメージ
- 中盤：魔法剣で属性を使い分け
- 終盤：ニュータイプ覚醒→九頭龍閃で大ダメージ

**相性の良い職業**
- 音魔術師（バフで火力UP）
- 狩人（弱点製造で連撃が刺さる）
- 老兵（守ってもらいながら攻撃）

