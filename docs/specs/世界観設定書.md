# 世界観設定書

## 概要

本作は「宇宙世紀」から続く遠未来を舞台としたファンタジーRPGである。SF技術と魔法が融合した独自の世界観を持つ。

## 技術体系

### 宇宙世紀の遺産（コールドスリープ前の技術）

大厄災以前の高度な科学技術。現代では**製造不可能**だが、遺物として発掘・利用されている。

| 技術名 | 説明 | ゲーム内での扱い |
|--------|------|------------------|
| ミノフスキー粒子 | 電磁波を遮断する特殊粒子 | 設定上の存在 |
| ビーム兵装 | MS用の光線兵器 | 機械キャラの武器 |
| Iフィールド | ビームを弾く防御技術 | 一部装備の耐性 |
| サイコフレーム | ニュータイプの感応波を増幅 | ビッド系装備 |
| EPAC | 機械用大容量電源 | 機械キャラの装備 |
| コンピュータチップ | 超高性能演算装置 | 高級素材（製造不可） |

**フレーバーテキストでの表現例：**
- 「宇宙世紀の遺産」「コールドスリープ前の技術」
- 「1500年経っても製造法は復元できない」
- 「宇宙世紀853年製の規格が今も現役」

### 第2世代魔導（統一政府時代の技術革新）

第2世代起床後（新人暦500年頃）に体系化された魔法技術。現代の主流技術。

| 技術名 | 説明 | ゲーム内での扱い |
|--------|------|------------------|
| 魔導術式 | 体系化された魔法 | 杖が付与するスキル |
| 良質な魔石 | 魔力の結晶 | 魔法装備の強化素材 |
| マナ石 | ステータス強化用の装飾品 | 合成可能な装備 |
| 魔鉄 | 宇宙世紀合金と魔導の融合 | 万能素材 |

**フレーバーテキストでの表現例：**
- 「第2世代が体系化した術式」「統一政府時代の魔導革命」
- 「第2世代魔導の産物」「500年後も現役」

### 融合技術

宇宙世紀の遺産と第2世代魔導を組み合わせた技術。

| 装備例 | 説明 |
|--------|------|
| 大魔導増幅棒 | Iフィールド × 第2世代魔導 |
| 高出力魔導ビームライフル | ビーム兵装 × 魔導強化 |

## 主要キャラクター設定

### ビーツー（機械キャラ）

| 項目 | 内容 |
|------|------|
| 製造年 | 宇宙世紀853年（西暦2953年） |
| 種別 | ニュータイプ対応ドローン |
| 経歴 | 外宇宙進出後200年の時代に製造 |
| 任務 | 地球圏調査ドローンとして派遣、20年間のテラフォーミングに従事 |
| 停止理由 | 魔道戦争最初期の電子攻撃で機能停止 |
| 現状 | 人類の保管庫で長い眠りの後、第3世代に発見・再起動 |

**フレーバーテキストでの活用：**
- ビーム兵装やEPACは「宇宙世紀853年製」と言及可能
- サイコフレーム系装備は「外宇宙進出時代のニュータイプ技術」

## 世界観の匂わせ方

### 基本方針

- **直接的な説明は避ける**
- 断片的な情報で「何かある」と思わせる
- プレイヤーの想像を掻き立てる

### 表現テクニック

| 手法 | 例 |
|------|-----|
| 年代の匂わせ | 「1500年経っても」「宇宙世紀853年製」 |
| 世代言及 | 「第2世代が体系化した」「第3世代の冒険者」 |
| 失われた技術 | 「現代では製造不可能」「製造法は復元できない」 |
| 時代の重層性 | 「宇宙世紀の遺産と魔導の融合」 |

### 禁止事項

- 年表を直接説明しない
- 「コールドスリープ」「大厄災」の詳細説明
- 設定の押し付け
