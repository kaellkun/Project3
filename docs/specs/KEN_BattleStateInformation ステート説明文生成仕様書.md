# KEN_BattleStateInformation ステート説明文生成仕様書

## 概要

本仕様書は、RPGツクールMZプラグイン「KEN_BattleStateInformation」のステート説明文を、スプレッドシートのステートデータから生成し、プラグイン設定項目（JSON形式）に落とし込むためのルールを定義する。

---

## 第1章：プラグイン設定構造

### 1.1 StateConfig 構造体

プラグインは以下の構造体でステート説明を管理する：

```json
{
  "stateId": "ステートID（数値を文字列として）",
  "description": "説明文（制御文字使用可・要エスケープ）"
}
```

### 1.2 JSON配列形式（プラグインパラメータ）

複数のステートを配列として設定：

```json
{
  "states": "[
    \"{\\\"stateId\\\":\\\"2\\\",\\\"description\\\":\\\"説明文1\\\"}\",
    \"{\\\"stateId\\\":\\\"3\\\",\\\"description\\\":\\\"説明文2\\\"}\"
  ]"
}
```

**エスケープルール：**
| 文字 | エスケープ後 |
|------|-------------|
| `"` | `\\\"` |
| `\` | `\\\\` |
| 改行 | 使用不可（1行に収める） |

### 1.3 利用可能な特殊機能

| 機能 | 記法 | 用途 |
|------|------|------|
| 制御文字 | `\V[n]`, `\c[n]` 等 | 色変更、変数参照 |
| JavaScript実行 | `\js<式>` | 動的な値の表示 |
| 累積ステート参照 | `\stack[ステートID]` | KEN_StackState連携時 |

## 第2章：色コード体系

### 2.1 カテゴリタグ用色コード

| タグ | 色コード | 色 | 用途 |
|------|----------|-----|------|
| `[行動不能]` | `\c[2]` | 赤 | 行動制限（危険） |
| `[強化]` | `\c[24]` | 薄青 | バフ効果 |
| `[弱体]` | `\c[10]` | 橙/茶 | デバフ効果 |
| `[耐性]` | `\c[14]` | 黄色 | 被ダメージ軽減 |
| `[スリップ]` | `\c[2]` | 赤 | 継続ダメージ |
| `[身代わり]` | `\c[24]` | 薄青 | 味方を庇う |

### 2.2 効果値用色コード

| 効果種別 | 色コード | 色 | 例 |
|----------|----------|-----|-----|
| プラス効果 | `\c[24]` | 薄青 | 攻撃1.3倍、命中+30% |
| マイナス効果 | `\c[10]` | 橙/茶 | 攻撃0.8倍、回避-10% |
| 耐性軽減 | `\c[14]` | 黄色 | 物理系0.1倍 |
| 耐性悪化 | `\c[10]` | 橙/茶 | スタン3倍 |
| ダメージ系 | `\c[2]` | 赤 | HP-100、ダメージ2倍 |
| 通常テキスト | `\c[0]` | 白 | リセット用 |

### 2.3 色コード適用の基本ルール

**タグと効果値をセットで色付けする：**

```
\c[24][強化]\c[0] \c[24]命中+30%\c[0],\c[24]回避+30%\c[0]
```

**複合効果（強化＋弱体）の場合：**

```
\c[24][強化]\c[0] \c[24]敏捷*4倍\c[0], \c[24]回避+30%\c[0], \c[10][弱体]\c[0] \c[10]魔力0.1倍\c[0]
```

## 第3章：説明文生成ルール

### 3.1 基本フォーマット

ステート説明文は**1行構成**で、以下の形式を基本とする：

```
\c[色][カテゴリタグ]\c[0] \c[色]効果1\c[0],\c[色]効果2\c[0]
```

### 3.2 カテゴリタグ一覧

| タグ | 用途 | 適用条件 | 色コード |
|------|------|----------|----------|
| `[行動不能]` | 行動が制限されるステート | restriction ≠ 0 | `\c[2]` |
| `[強化]` | 味方に有利なバフ | バフステート全般 | `\c[24]` |
| `[弱体]` | 敵/自身に不利なデバフ | デバフステート全般 | `\c[10]` |
| `[耐性]` | 被ダメージ軽減 | 属性有効度 < 1.0 | `\c[14]` |
| `[スリップ]` | 継続ダメージ | note に SlipDamage 系タグあり | `\c[2]` |
| `[身代わり]` | 味方を庇う | 特殊フラグ:身代わり | `\c[24]` |

### 3.3 効果記述の標準表記

#### 能力値変化（code:21）

| スプレッドシート記述 | 説明文表記 | 色 |
|---------------------|-----------|-----|
| ATK+30% | `攻撃1.3倍` | 薄青 |
| ATK-20% | `攻撃0.8倍` | 橙 |
| 敏捷*4倍 | `敏捷*4倍` | 薄青 |
| MAT0.1倍 | `魔力0.1倍` | 橙 |

**変換ルール：**
- `+N%` → `X.XX倍`（1 + N/100）→ 薄青
- `-N%` → `X.XX倍`（1 - N/100）→ 橙
- `*N倍`（N>1） → `*N倍` → 薄青
- `*N倍`（N<1） → `*N倍` → 橙

#### 追加能力値変化（code:22）

| スプレッドシート記述 | 説明文表記 | 色 |
|---------------------|-----------|-----|
| 命中+30% | `命中+30%` | 薄青 |
| 回避-10% | `回避-10%` | 橙 |
| クリティカル率+20% | `クリ率+20%` | 薄青 |
| 回避-999% | `回避-999%` | 橙 |

#### 属性耐性変化（code:11）

| スプレッドシート記述 | 説明文表記 | 色 |
|---------------------|-----------|-----|
| 物理系0.1倍 | `物理系0.1倍` | 黄色 |
| 炎系0.6倍 | `炎系0.6倍` | 黄色 |
| ビーム系0.1倍 | `ビーム系0.1倍` | 黄色 |

#### ステート有効度（code:13）

| スプレッドシート記述 | 説明文表記 | 色 |
|---------------------|-----------|-----|
| スタン耐性0.1倍 | `スタン0.1倍` | 黄色 |
| スタン付与率3倍 | `スタン3倍` | 橙 |

#### スリップダメージ（noteタグ）

| noteタグ | 説明文表記 | 色 |
|----------|-----------|-----|
| `<SlipDamageFixedHP:-100>` | `毎ターンHP-100` | 赤 |
| `<SlipDamageFixedMP:-30>` | `MP-30` | 赤 |

#### 特殊効果

| 効果 | 説明文表記 | 色 |
|------|-----------|-----|
| 被ダメージ2倍 | `ダメージ2倍` | 赤 |
| 逃走成功率+25% | `逃走+25%` | 薄青 |
| 単体攻撃を代わりに受ける | `単体攻撃を引き受ける` | 薄青 |

## 第8章：補足事項

### 8.1 説明文に含めない情報

以下は説明文に含めず、ゲーム内の別の場所で確認させる：

| 情報 | 理由 |
|------|------|
| 持続ターン数 | プラグインの「残り○ターン」表示で確認 |
| 付与元スキル名 | スキル説明で確認 |
| フレーバーテキスト | 戦闘中の情報ウィンドウには不要 |

### 8.2 文字数目安

- 1ステートの説明文：**30〜50文字程度**（色コード除く）
- 効果が多い場合でも**60文字以内**を推奨
- 色コードは表示文字数にカウントしない

### 8.3 色コードの省略形式

文字数が多い場合、以下の省略形式を使用可能：

**通常形式（推奨）：**
```
\c[24][強化]\c[0] \c[24]命中+30%\c[0],\c[24]回避+30%\c[0]
```

**省略形式（同じカテゴリの効果が連続する場合）：**
```
\c[24][強化] 命中+30%,回避+30%\c[0]
```

### 8.4 将来の拡張

累積ステートプラグイン（KEN_StackState.js）との連携時：

```
\c[24][累積]\c[0] \c[24]スタック\stack[ステートID]：ATK+10%*スタック数\c[0]
```
