# 赤シンボル設計：序章・第1章（v4）

有名なゲームの敵を「仕組みの元ネタ」として当て、本作のルール（1体1Lv、敵は強め、一人倒れたら終わり、敵情報は常に見える）に合わせて作り直したもの。元ネタは設計上の参照で、公開時の名前・見た目・台詞は独自のものにする。

**v4の主な変更**

- 序章を14体に増やした。加入した仲間がすぐに活躍できる敵を置いた（薬師→F5、鍛冶屋→F6、音魔術師→C4など）。
- 敵の人気だけでなく、ギミックの面白さと「厄介さの伝説」も重視して選び直した（タケシのイワーク、ウォールマスター、毒吹きアゲハ、ラストモンスターなど）。
- やり込み用の超強敵は別に作るので、98体には含めない。本編（任意を含む）の98体を倒すとLv99になる。

## 0. 前提

### 0.1 Lvとシンボル数（前半を厚く、後半を薄く）

赤シンボルは全98体。1体1Lvなので、すべて倒すとLv99になる。

| 章    | 赤シンボル | Lv    |
|-------|------------|-------|
| 序章  | 14体       | 1→15  |
| 第1章 | 31体       | 15→46 |
| 第2章 | 22体       | 46→68 |
| 第3章 | 17体       | 68→85 |
| 第4章 | 14体       | 85→99 |

- 任意の赤シンボル（宝箱の擬態、樹海の主など）もこの98体に含める。任意を飛ばすと、その分だけLv99に届かない。
- やり込み用の超強敵は別に作り、98体には含めない。
- 設計書v3の能力値曲線（Lv1〜99）をそのまま使う。
- 序盤ほど数が多く、終盤は少ない代わりに1体ずつが非常に強い。後半の成長は装備・レシピ・スキルポイントで支える。
- 98体は「仕組みが新しい核の敵」と「既存の仕組みを2つ組み合わせた敵・上位個体」で作る。組み合わせは、前に覚えた回答を2つ同時に使う問題になる。

### 0.2 敵の強さの基準

| 状態                      | 結果                           |
|---------------------------|--------------------------------|
| 脅威に何も備えず殴り合う  | 負ける                         |
| 脅威の1つに回答を用意する | かなり苦しいが勝てることがある |
| 脅威の2つに回答を用意する | ぎりぎり勝てる（基準）         |

- 1体に脅威は2〜3つ。すべてを塞ぐ手段は、その時点では揃わないようにする。
- 即死級の攻撃には、必ず1ターン以上前の予告と、2つ以上の回答を用意する（企画書0.4）。
- 回答は「装備」「スキル」「仲間」の3系統からできるだけ散らし、鍵穴を1つにしない。

### 0.3 装備の枠と役割

| 枠                     | 受け持ち                                       |
|------------------------|------------------------------------------------|
| 武器                   | 攻撃力、属性、系統の威力、会心・命中           |
| 外装（ローブ・マント） | 魔法倍率、属性耐性                             |
| 内装（アーマー）       | 物理倍率、最大HP（重いほどAGI低下）            |
| 帽子                   | 状態異常耐性、命中、初期TP                     |
| 靴                     | 回避、先制、TPチャージ                         |
| 装飾品（多数）         | 職業の仕組みの増幅、条件つき効果、代償つき効果 |

## 1. 境の樹海（世界樹の迷宮型の探索ダンジョン）

### 1.1 位置付け

開拓予定地の奥、開拓村と荒野のあいだに広がる樹海。**開拓とは知らない土地を調べて地図にすること**なので、世界樹の迷宮の「未知の迷宮を歩いて地図を描く」遊びが、3人の仕事そのものになる。

| 項目              | 内容                                                                                                                                          |
|-------------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| 層                | 章ごとに1層ずつ開く（序章で第1層、第1章で第2層…）。企画書の「村の発展：測量」で地図が詳しくなる                                               |
| 本編との関係      | 本編の合間に挟む。層の赤シンボルは本編のLv計画に含める                                                                                        |
| 赤シンボル（FOE） | マップ上を歩数に合わせて動き、視界に入ると追ってくる。当たり方で先制が決まる。倒すと1Lv上がって夜になり、復活しない（ほかの赤シンボルと同じ） |
| 通常戦闘          | ランダムエンカウント。経験値はなく、素材とお金が入る（企画書0.6どおり）                                                                       |
| 採取ポイント      | 採集・伐採・採掘の3種。1日（1区間）ごとに復活する                                                                                             |
| 条件ドロップ      | 決まった倒し方（部位を壊してから、特定の属性で、ブレイク中に、など）をすると珍しい素材が出る                                                  |
| 帰り道            | 一度通った層にはショートカットが開く                                                                                                          |

### 1.2 ハクスラの輪

> 樹海を歩く → 通常戦闘と採取で素材を集める → 鍛冶屋・薬師のレシピが開く → 装備を作る → 本編の赤シンボルやFOEに挑む → 条件ドロップで次のレシピが開く

- **稼げるのは素材だけで、強さの上限はレシピで決まる**。何時間回っても、その時点のレシピ以上の装備は作れない。
- **条件ドロップを「相性で倒す遊び」の報酬にする**。部位を壊す、弱点属性で倒す、といった手間をかけた倒し方ほど、良い素材が出る。
- ランダムな付加効果の付いた装備（いわゆるハクスラの掘り出し物）は出さない。決まったレシピでの合成という方針と両立しないため。

### 1.3 「強くなった実感」を味わう場所

赤シンボルは1体ずつ手ごわく保つ。**強くなった実感は、樹海の浅い層の通常戦闘で味わわせる**。

- 第1章に入る頃には、第1層の通常戦闘はほぼ一撃で終わる。素材集めが速くなり、序章で苦労した場所を軽く抜けられる。
- 経験値が入らないので、ここで楽をしても本編の難しさは崩れない。
- 消化試合になるのは通常戦闘だけで、赤シンボルは消化試合にならない。

### S1　瓦礫纏いの作業機（イワロック型）

**場所・Lv**：遺跡・上層／Lv1（最初の赤シンボル）

**元ネタの核**：体は硬く、普通に斬っても効かない。弱点の鉱石を正しい道具で叩くと倒せる。倒すと鉱石が取れる。

**本作での形**：崩落した瓦礫を体に固めた、宇宙世紀の作業機械。瓦礫の隙間から古い配線がのぞいている。

**脅威**

1.  瓦礫の装甲：物理0.3倍、魔法0.5倍。そのままではほとんど効かない。
2.  天井落とし：全体の重い物理攻撃。2ターン前から「天井が軋む」と予告。

**回答**

- 雷で配線に通電すると「露出」状態になる（被ダメ1.5倍、2T）。露出中にブレイクまで持ち込めば2倍。
- 村の鍛冶場の任意イベントで借りられる「採掘つるはし」（打属性、瓦礫・鉱石特効）。
- 天井落としには、予告の間に露出からの大技で倒しきるか、支給の胸当てを着た剣士以外が下がる（防御）。

**学ぶこと**：敵情報を読む。弱点は「ある」ものではなく「作る」もの。準備してから大技を撃つ。

**報酬**：鉄鉱石、古い導線（鍛冶屋の最初のレシピの要の素材）

**教育の入口**：金属は電気を通す。配線が露出すると危ない理由。

### S1b　岩の大蛇（タケシのイワーク型・ポケモン赤・緑）

**場所・Lv**：遺跡・上層の崩落区画／Lv2

**元ネタの核**：最初のジムで待つ岩の大蛇。電気はまったく効かず、炎も通りにくい。炎タイプを選んだ人にとって、伝説的な最初の壁になった。

**本作での形**：遺跡の崩落区画に巣くう、岩の体を持つ大蛇。

**脅威**

1.  岩の体：炎0.5倍、雷は無効。初期パーティーの魔術師2人が、そのままでは主役になれない。
2.  締め付け：単体を2ターン拘束しながら削る。
3.  岩石封じ：全体に小ダメージと敏捷低下。

**回答**

- S1の前に借りた採掘つるはし（打属性・岩特効）が決定打になる。誰に持たせるかを選ぶ。
- 剣士の斬撃は普通に通る。剣士が主役の戦い。
- 炎魔術師は印を最大まで溜めれば、0.5倍でも十分な威力が出る（準備技の価値）。雷魔術師は先制と支援に回る。

**学ぶこと**：相性の悪い仲間がいる戦い。その戦いの主役を入れ替える。

**報酬**：岩蛇の抜け殻（内装のレシピ）

**教育の入口**：岩石と電気。岩が電気を通しにくい理由（絶縁体）。

### S2　過熱する発電ユニット（ボム型）

**場所・Lv**：遺跡・中層／Lv3

**元ネタの核**：ダメージを受けるたびに膨らみ、限界で自爆する。削り方を間違えると痛い目にあう。

**本作での形**：放熱が壊れた小型の発電機。攻撃を受けるほど熱を溜め、赤熱していく。

**脅威**

1.  過熱の段階：HPが25%減るごとに過熱が1段上がる。3段目の次の行動が自爆（全体・炎属性・大）。自爆の1ターン前に予告。
2.  炎を吸収：炎属性の攻撃は回復になり、過熱も1段上がる。

**回答**

- 雷の攻撃で「放電」させると過熱が1段下がる。
- 剣士の準備技（剣気解放→大技）で、25%の区切りを2つまたいで一気に削る。
- 炎魔術師は炎を封じられるので、この戦いでは印を溜めずに支援に回る（体温上昇など）。「エースが効かない相手もいる」ことを最初に見せる。

**学ぶこと**：HPのしきい値を管理する。属性吸収がある。役割を入れ替える。

**報酬**：蓄電の核（雷系装備の素材）

**教育の入口**：放電とコンデンサ。機械の放熱が止まると何が起きるか。

### S2b　培養槽の粘体（キングスライム型）

**場所・Lv**：遺跡・中層の奥／Lv4

**元ネタの核**：小さな敵が集まって合体し、大きな1体になる。

**本作での形**：コールドスリープ施設の培養槽から漏れ出した粘体。3体で現れ、揃っていると合体する。

**脅威**

1.  合体：3体が残っている状態で2ターン経つと合体し、HPと攻撃力が大きく上がる。合体の1ターン前に予告。
2.  分裂：合体後にHPが半分を切ると、再び3体に分かれる。

**回答**

- 合体の前に1体でも減らせば合体しない。雷の先制と剣士の単体技で1体を落とす。
- あえて合体させて、炎の印を溜めた大技を1体に集中させる。分裂したら全体攻撃で片付ける。

**学ぶこと**：敵の数が変わる相手には、減らすか、まとめるかを選ぶ。

**報酬**：粘体の核（薬師の最初のレシピの素材。村で薬師が加入すると使える）

**教育の入口**：細胞の分裂と集合（粘菌が集まって1つの体になる現象）。

### S2c　床から伸びる手（ウォールマスター／フロアマスター型・ゼルダの伝説）

**場所・Lv**：遺跡・中層の回廊／Lv5

**元ネタの核**：天井や床から現れる手に捕まると、ダンジョンの入口まで連れ戻される。多くのプレイヤーのトラウマとして語られる。

**本作での形**：施設の搬送用アーム。「侵入者を外へ運び出す」命令だけが、今も生きている。

**脅威**

1.  掴み：単体を掴み、2ターン以内に解放できないと、その仲間は遺跡の入口へ運び出されて戦闘から外れる（倒れたわけではないので、ゲームオーバーにはならない）。掴む1ターン前に「影が落ちる」と予告。
2.  抜け手：回避が高く、攻撃が当たりにくい。

**回答**

- 掴まれた仲間は、ほかの2人が腕を攻撃すれば解放できる。
- 予告で狙われた仲間は防御すると、掴まれる確率が下がる。
- 雷の先制で、掴む前に腕を痺れさせる。

**学ぶこと**：倒れなくても戦力を失うことがある。3人しかいないときの1人の重さ。

**報酬**：搬送アームの関節（靴のレシピ）

### S3　施設防衛システム（りゅうおう型・変化なし、魔封じが主役）

**場所・Lv**：遺跡・最深部／Lv6（ビーツー加入直後の序章ボス）

**元ネタの核**：1対1で、重い打撃と強力な呪文に加えて、こちらの呪文を封じてくる。呪文に頼る側ほど追い詰められる。

**本作での形**：施設全体を守る防衛機構。侵入者の「魔導の使用」を検知すると、施設ごと魔力を遮断する。本体は1体で、手下を出さない。

**脅威**

1.  魔導遮断（魔封じ）：全体に魔封じ3T。魔法タイプのスキルが使えなくなる。1ターン前に「遮断装置が起動する」と予告。戦闘中2回まで。
2.  掃射：全体への強力な魔法攻撃。1ターン前に「砲口が開く」と予告。
3.  鉄槌：単体への重い物理攻撃。

初期パーティーは2人が魔術師なので、魔封じが入るとパーティーの半分が止まる。これがこの戦いの主題になる。

**回答**

- **雷魔術師の物理技**（ATK依存の電光石火など）は魔封じの対象外。両刀という職業の意味を、ここで初めて体で分からせる。
- **炎魔術師の「印を結ぶ」は魔法ではない**（別のスキルタイプ）。封じられている3Tを印の準備に使い、解けた直後に最大段で撃つ。封じられた時間が、そのまま準備の時間になる。
- 遺跡の宝箱で手に入る帽子「遮断除けの頭巾」（魔封じ耐性）が1つだけある。炎と雷のどちらに被せるかを選ぶ。
- 掃射はビーツーのかばうで受ける（企画書の予定どおり）。
- 剣士のTP技は影響を受けないので、封じられている間の火力を支える。

**学ぶこと**：手段を1つに頼らない。封じられている時間を準備に使う。職業の両刀・準備の仕組みが、弱点を補う形で生きる。

**報酬**：宇宙世紀の規格部品（ビーツー用装備の素材）

**実装メモ**：MZの魔封じは「スキルタイプ封印」の特性で作る。「印を結ぶ」と雷の物理技は、魔法とは別のスキルタイプに入れておく必要がある。

**教育の入口**：電磁シールド（ファラデーの籠）。電波や電気を遮る仕組み。

### 3.1 段が固定されたボスを各ルートに置く

3つの依頼ルートそれぞれに、強さの段が決まった赤シンボルを段ごとに2体、計6体置く。**敵の強さはクリアした本数で変えない**。

| 段  | 各ルートの赤シンボル                                        | 想定Lv（ぎりぎり） | 開く条件             |
|-----|-------------------------------------------------------------|--------------------|----------------------|
| 段1 | A1・A1b・B1・B1b・C1・C1b                                   | 18                 | 第1章の開始時        |
| 段2 | A2・A2b・B2・B2b・C2・C2b                                   | 29                 | 段1の6体をすべて倒す |
| 段3 | A3b・A3・B3b・B3・C3b・C3（A3・B3・C3がルートのボスで判子） | 38                 | 段2の6体をすべて倒す |

- **同じ段の中の順番は自由**。段の1体目は想定より3Lvほど低く挑む「格上」、6体目は3Lvほど高く挑む「少し楽」になる。この±3Lvの差が、少し強くなった実感の場面になる。

- 段を上がる条件には物語の理由を付ける。たとえば、魔導炉の奥へ進む鍵は宇宙港の記録にあり、宇宙港の奥の扉は聖地の古文書で開く。「三つの遺産は根でつながっている」ことが、段を上がるたびに見えてくる。

### A1【段1】　杖持ちの魔導残滓（ウィズローブ型）

### A2【段2】　冷却外套の炉番（ルビカンテ型）

**場所**：地下魔導炉・中層（水魔術師が加入する中ボス）

**元ネタの核**：マントを閉じている間は冷気を吸収し、開くと冷気に弱くなる。耐性が状態で入れ替わる。

**本作での形**：炉を守る魔導機兵。冷却用の外装を閉じて熱を溜め、開いて放熱する。

**脅威**

1.  外装の開閉：閉じている間は水を吸収、開いている間は水弱点（2倍）。開閉は交互で、次の状態が情報画面に出る。
2.  炉熱の放射：開く直前に、溜めた熱を全体の炎攻撃として吐く。

**回答**

- 水魔術師の水を、開いたターンに合わせる。CTBの行動順を読んで、開く直後に動く味方に水を撃たせる。
- 対炎の外装で放射を受ける。

**本作での形**：荒野に群生する針の魔物の、特に大きな個体。

**脅威**

1.  針の嵐：固定ダメージ（その時点の炎魔術師の最大HPの9割ほど）。2ターン前に予告。
2.  高回避：物理回避が非常に高い。

**回答**

- 固定ダメージは倍率で減らせないので、最大HPで受ける。内装や装飾品のHP上昇がここで初めて決定的に効く。
- HPの高いビーツーがかばう。

**学ぶこと**：固定ダメージは耐性ではなく最大HPで受ける。装備のHPの意味。

**報酬**：針玉の芯（装飾品「針の護符」のレシピ）

### G1　包丁の小鬼（トンベリ型）

### X1　境界の番人（ボンゴボンゴ型）

**場所**：3つの依頼の完了後（第1章の章ボス）

**元ネタの核**：姿が見えない敵。見えるようにする道具を使って初めて戦える。

**本作での形**：外宇宙民の残滓。次元の揺らぎの中にいて、姿がほとんど見えない。本体と両手の3部位。

**脅威**

1.  揺らぎ：本体の回避がほぼ100%。
2.  両手の同時攻撃：両手が同じターンに別々の味方を叩く。
3.  境界の圧：3ターンごとに全体攻撃。

**回答**

## 5. 決めておきたいこと

1.  **98体の作り方**：第2章以降の53体を、核の敵と組み合わせ・上位個体にどう振り分けるか。第4章はループごとに同じ場所の敵の条件を変えて使える。
2.  **段の開く条件の厳しさ**：「段をまたげない」は消化試合を確実に防ぐが、自由度は下がる。緩めるなら「段3だけは段2を2つで開く」などにする（最大の差が±4Lvほどに広がる）。
3.  **逃げる敵（W1・M1）**：逃げられても翌日また現れる形にした。逃走までのターン数は実機で調整する。
4.  **部位のある敵**（F1、F6、F4、A3、A3b、B2b、B3、C3、C3b、G4、X1、任意2）：MZでは部位を別の敵として並べる。部位を壊したときの連動はコモンイベントかプラグインで組む。
5.  **FOEの移動**：歩数に合わせて動くシンボルは、イベントの自律移動で作れるが、見つかったら追う動きと当たり方の判定（先制か被先制か）は作り込みが要る。
