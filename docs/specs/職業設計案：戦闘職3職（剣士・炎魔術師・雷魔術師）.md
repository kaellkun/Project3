## 1. 剣士（魔法剣士 → オールレンジ剣士）

### コンセプト
**序盤は純粋な物理剣士、中盤で魔法剣士化、終盤でニュータイプ的なオールレンジ戦闘へ進化**。
「感覚を研ぎ澄ます」から始まり、最終的には「サイコミュ」で遠隔操作する浮遊剣を自在に操る。
ガンダムのニュータイプ＋剣心の飛天御剣流を融合させたイメージ。

### 得意属性
- **斬**（刀剣による斬撃）
- **破**（超振動・分子結合破壊）
- **遠距離物理**（オールレンジ攻撃）

### 設計思想
- 序盤：TP技中心の堅実な物理剣士（斬撃→4連斬りの成長）
- 中盤：魔力を纏わせた「魔法剣」を習得、属性攻撃＋状態異常が可能に
- 終盤：「ビッド」「浮遊剣」によるオールレンジ攻撃で戦場を支配
- 「直感」「感覚研ぎ澄まし」系のバフで回避型アタッカーとしても機能

### 成長フェーズ設計

#### フェーズ1：剣士の基本（Lv1～10）
習得：基本斬撃、感覚を研ぎ澄ます、直感
**設計意図**：TP管理を覚えながら、堅実な物理火力を出す基本を学ぶ。

#### フェーズ2：魔法剣士への覚醒（Lv11～25）
習得：魔力纏い、属性剣、飛天系連撃
**設計意図**：「魔力を纏う」ことで属性攻撃が可能に。弱点を突く戦術が広がる。

#### フェーズ3：オールレンジ覚醒（Lv26～）
習得：浮遊剣操作、サイコミュ技、ファンネル系
**設計意図**：サイコミュ的な遠隔操作で、1人で多角攻撃が可能に。

### 戦術例

**序盤（物理剣士期）**
1. 感覚を研ぎ澄ます → 集中状態でTP回復
2. 斬撃[TP技] or 牙突 で単体火力
3. 雑魚戦は土龍閃で処理
4. ボス戦は直感 → 4連斬り で大ダメージ

**中盤（魔法剣士期）**
1. 神速抜刀 → 先制確定＋回避UP
2. 敵の弱点に応じて 炎纏/雷纏/風纏 を選択
3. 龍槌閃 でスタン狙い、龍巻閃 で乱れ傷付与
4. 乱れ傷が付いたら連撃でクリティカル狙い

**終盤（オールレンジ期）**
1. 戦闘開始時に浮遊剣展開
2. ニュータイプ覚醒 で全バフ
3. ボスには 包囲斬撃（1120固定）→ ファンネル斬撃（2100固定）
4. 複数敵には オールレンジ乱舞（全体600固定）
5. 最終奥義は 九頭龍閃（1350%＋大出血確定）

## 2. 炎魔術師（炎の形状変化型）

### コンセプト
**「炎を自在な形に変化させる」形状変化の達人**。
NARUTOの「性質変化」「形状変化」の概念を取り入れ、炎を剣・盾・龍・鎧などに変形させて戦う。
イタチ/サスケの「加具土命」、マダラの「火遁」を彷彿とさせる。

### 得意属性
- **炎**（火炎・爆発・形状変化した炎）
- **破**（爆発による衝撃波）

### 設計思想
- **「炎を何に変えるか」で戦術が変わる**
- 炎剣＝近接攻撃、炎矢＝遠距離攻撃、炎盾＝防御、炎龍＝大技
- 「印を結ぶ」システムで次の術を強化
- 既存の連射系スキルは「炎弾」系として継続
- 最終奥義は「天照」（消えない黒炎）

### 特殊システム：印を結ぶ

**基本ルール**
- 「印」を結ぶと、次に使う炎術が強化される
- 印は最大3段階まで重ねがけ可能
- 印の段階に応じて威力・効果が上昇
- 一部の大技は「印Lv2以上」が発動条件

| 印の段階 | 効果 | 備考 |
|----------|------|------|
| 印Lv1 | 次の炎術の威力1.2倍 | 基本の強化 |
| 印Lv2 | 次の炎術の威力1.5倍＋追加効果発動率+20% | 中級術の解禁 |
| 印Lv3 | 次の炎術の威力2.0倍＋追加効果確定＋消費MP-30% | 奥義の解禁 |

※印は術を使うと消費される（1回限り）

```

```

#### 【機械特化】旧世紀技術者 × 剣士（ビッド装備）

```
戦術：機械敵を完封しつつ、味方機械を強化
1. 技術者「緊急停止コード」→ 機械敵1T完封
```

### パーティ編成例

#### 【万能型】剣士・炎魔術師・薬師・鍛冶屋
- 物理（剣士）＋魔法（炎）＋デバフ（薬師）＋支援（鍛冶屋）
- バランス良くどんな敵にも対応可能
- 鍛冶屋の過熱→炎魔術師の追撃が強力

#### 【対機械特化】剣士・雷魔術師・旧世紀技術者・鍛冶屋
- 機械敵を技術者が完封
- 味方機械（ビーツー等）を技術者が強化
- 剣士のファンネル、雷魔術師のビーム連携

#### 【状態異常特化】薬師・雷魔術師・旧世紀技術者・自由枠
- 技術者が耐性を下げ、薬師が状態異常をバラまく
- 雷魔術師の感電で追加拘束
- 自由枠は火力担当（剣士or炎魔術師）

#### 【物理特化】剣士・鍛冶屋・薬師・旧世紀技術者
- 剣士＋鍛冶屋の物理コンビ
- 薬師の脆弱＋技術者の弱点指示で物理火力倍増
- 魔法耐性の高い敵に有効

#### 【魔法特化】炎魔術師・雷魔術師・薬師・旧世紀技術者
- 炎＋雷の二大魔法アタッカー
- 薬師の腐食＋技術者の解析で耐性低下
- 物理耐性の高い敵に有効
