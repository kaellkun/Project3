# 職業設計案：追加4職（老兵・機械装甲兵・氷魔術師・闇魔術師）

## 設計方針

- 既存12職との役割被りを避ける
- 各職業に明確な「この人でないとダメ」な理由を持たせる
- 世界観設定（宇宙世紀の遺産・第2世代魔導）を活かす
- **教育要素を職業の核心に組み込む**

### システム前提（既存職業設計と同様）
- **戦闘不能は存在しない**（誰か一人でも死んだらゲームオーバー）
- **敵の全ステータスと弱点属性は常に表示**されている
- **敵にはレベルがない**
- **DEFという概念がない**（「被ダメージX倍」の耐性システム）
- **回復スキルは職業に付与しない**（回復が貴重なゲームバランス）

## 1. 老兵（ベテランソルジャー）

### コンセプト
**「何十年も戦場で生き延びてきた、正統派のタンク役」**。
派手な技はないが、仲間を守り、敵の攻撃を引き受け、戦場を支配する。
「囮」「挑発」「カバーリング」のプロフェッショナル。
ダークソウルの騎士＋FFの暗黒騎士（セシル前）＋ベルセルクのガッツ（老年）的イメージ。

### 得意属性
- **打**（盾・鎧による打撃）
- **無**（威圧・挑発など精神的効果）

### 設計思想
- **「なぜこの人でないとダメか」**：数十年の実戦経験による「読み」と「体の使い方」
- 装備があれば誰でもできる「盾を持つ」ではなく、「盾で戦場を支配する」技術
- 囮・挑発で敵の攻撃を自分に集め、味方を守る
- 自己回復はないが、**被ダメージ軽減**と**耐久力**で耐える
- 「老い」による性能低下を「経験」でカバーする設計

### 教育的テーマ
- **物理学**：衝撃吸収、慣性、運動量の分散
- **心理学**：威圧、士気、恐怖のコントロール
- **軍事史**：陣形、戦術、指揮

### 戦術例

**基本戦術（タンク）**
1. 挑発 → 敵の攻撃を自分に集める
2. 鉄壁 → 被ダメ軽減
3. 味方が安全に攻撃
4. 繰り返し

**カバーリング戦術**
1. 身代わり → 最も脆い味方を指定
2. 防御姿勢 → その味方への攻撃を被ダメ0.5倍で受ける
3. 味方の生存率が大幅UP

**カウンター戦術**
1. 挑発 → 敵を引きつける
2. 読み切り → 次の攻撃を確定回避＋カウンター
3. 敵に隙を見せた付与（読み切りの効果）
4. カウンターバッシュ → 1.3倍×400%＝520%相当

## 2. 機械装甲兵（パワードアーマー）

### コンセプト
**「宇宙世紀の遺産『パワードスーツ』を装着した重装兵」**。
旧世紀技術者が「理論・分析・整備」なら、機械装甲兵は「実践・装着・運用」。
ガンダムのジム＋アイアンマン＋スターシップトゥルーパーズの機動歩兵的イメージ。

### 得意属性
- **打**（装甲による打撃）
- **ビーム**（内蔵火器）

### 設計思想
- **「なぜこの人でないとダメか」**：パワードスーツの「操縦適性」と「身体適合性」
  - 誰でも着れる装備ではない。神経接続と身体反応の適合が必要
  - 「技術を理解している」のではなく「体で使いこなせる」
- 旧世紀技術者との差別化：
  - 技術者＝整備・分析・ハッキング（後方支援）
  - 装甲兵＝装着・戦闘・突撃（前線戦闘）
- 高耐久＋重火力だが、機動力は低め
- 「オーバーヒート」によるリスク管理

### 教育的テーマ
- **工学**：パワーアシスト、外骨格、アクチュエーター
- **物理学**：てこの原理、トルク、エネルギー効率
- **材料科学**：装甲材、軽量化、耐熱性

### 熱蓄積システム詳細

```
【熱蓄積】
・特定スキル使用時に「熱蓄積」カウンターが増加
・熱蓄積が5以上になると「オーバーヒート」状態に
・オーバーヒート：毎ターン固定ダメージ＋スキル使用不可30%
・熱蓄積は「排熱」「緊急パージ」「冷却システム」で解除可能
・戦闘終了で自動解除

【設計意図】
・高火力・高耐久の代償としての「熱管理」
・「いつ攻撃し、いつ冷却するか」の戦術的判断
・工学的な「冷却」「排熱」の概念を自然に学ぶ
```

**「熱を奪い、凍結させ、脆くする」冷気の専門家**。
水魔術師が「流体・属性相性操作」なら、氷魔術師は「凍結・減速・脆化」。

- 「絶対零度」への到達が最終目標

### 教育的テーマ
- **熱力学**：絶対零度、熱運動の停止、エントロピー
- **相転移**：融解、凝固、昇華
- **結晶学**：結晶構造、脆性破壊
