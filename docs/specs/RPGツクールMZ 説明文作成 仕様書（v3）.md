# RPGツクールMZ 説明文作成 仕様書（v3）

## 概要

本仕様書は、RPGツクールMZのスキル・武器・防具・アイテムの説明文（description）およびnoteフィールドにおける記述ルールを定義する。

**改訂日：2026-01-08 (v3)**

---

## 基本構造

### 3行構成（共通）

| 行 | 配置場所 | 内容 | 文字数目安 |
|----|----------|------|------------|
| 1行目 | description | 主要データ（威力・属性・効果等） | 約50文字 |
| 2行目 | description | 補助データ＋戦略コメント | 約50文字 |
| 3行目 | note (`<拡張説明:>`) | **[要]＋フレーバーテキスト** | **45文字以内** |

### 表示例（スキル）

```
\c[2][威力] ATKの6倍  \c[27][属性] 近接物理 / 斬  \c[24][効果] 大出血付与10%
\c[1][対象] 敵単体  \c[17][命中] +95%  \c[23][消費] MP30 / TP22  \c[0]高威力の切り札。
---
\c[30][要] 剣  \c[7]運動エネルギーE=½mv²。速度を上げれば威力は二乗で増加する。
```

## 色コード一覧

### 基本ルール

1. **タグと値は同じ色でブロック化する**（視認性向上）
2. **ブロック間の`\c[0]`リセットは原則不要**（冗長なため省略）
3. **戦略コメント前は必ず`\c[0]`でリセット**
4. **消費タグの色はMPの有無で決定**（v3変更点）

### 色コード対応表

| タグ | 色コード | 色 | 用途 |
|------|----------|-----|------|
| [威力] | `\c[2]` | 赤 | ダメージ値 |
| [回復] | `\c[3]` | 緑 | HP/MP/TP回復量 |
| [対象] | `\c[1]` | 青 | 対象範囲 |
| [属性] | `\c[27]` | オレンジ | 属性タイプ |
| [効果] | `\c[24]` | 薄青 | 付与効果・状態異常・バフ |

| **[消費]（MP有）** | **`\c[23]`** | **青紫** | **MPがある場合の消費タグ** |

## 消費表記ルール【重要・v3変更点】

### 統一形式

消費リソースは**1つの[消費]タグにまとめる**。  
**[消費]タグの色は、MPの有無で決定する。**

### 色決定ルール

| パターン | [消費]タグの色 | 書式 |
|----------|---------------|------|
| MPあり（MP+TP両方） | `\c[23]`（青紫） | `\c[23][消費] MP30 / \c[29]TP22` |
| MPのみ | `\c[23]`（青紫） | `\c[23][消費] MP30` |
| TPのみ | `\c[29]`（ピンク） | `\c[29][消費] TP22` |

### 書式詳細

**MPがある場合（MP+TP両方）：**
```
\c[23][消費] MP30 / \c[29]TP22
```
※ [消費]タグとMP値は青紫、TP値はピンク

**MPのみの場合：**
```
\c[23][消費] MP30
```

**TPのみの場合：**
```
\c[29][消費] TP22
```

### NG表記（使用禁止）

| NG | 理由 | 正 |
|----|------|-----|
| `[消費MP] 30  [消費TP] 22` | 文字数過多 | `[消費] MP30 / \c[29]TP22` |
| `[MP] 30  [TP] 22` | 略記＋文字数過多 | `[消費] MP30 / \c[29]TP22` |
| `\c[16][消費] MP30` | タグの色が間違い | `\c[23][消費] MP30` |
| `\c[23][消費] MP30 / TP22` | TP値の色なし | `\c[23][消費] MP30 / \c[29]TP22` |

## 威力表記ルール【重要】

### 統一形式

威力は**日本語で読みやすい形式**に統一する。

| 計算式 | 表記 |
|--------|------|
| `100*(a.atk/100)` | ATKの1倍 |
| `250*(a.atk/100)` | ATKの2.5倍 |
| `600*(a.atk/100)` | ATKの6倍 |
| `a.mat*1.5` | MATの1.5倍 |
| `a.mat*3` | MATの3倍 |
| `350` (固定値) | 350 |

### NG表記（使用禁止）

| NG表記 | 理由 |
|--------|------|
| `600*ATK%` | 計算式のまま |
| `600%ATK` | 英語表記 |
| `ATK 6倍` | 「の」がない |
| `ATK×6` | 記号が読みにくい |

## タグ名ルール【重要】

### 略記禁止

すべてのタグは**正式名称で記載**する。

| 正 | 誤（略記） |
|----|----------|
| [消費] MP30 / TP22 | [MP] 30  [TP] 22 |
| [対象] 敵単体 | [対象] 敵単 |
| [対象] 味方全体 | [対象] 味方全 |
| [命中] 100% | （省略不可） |
| [常時発動] | [パッシブ] |
| 大出血付与10% | 大出血10% |

## スペーシングルール【重要】

### 基本原則

1. **タグと値の間はスペース1つ**：`[威力] ATKの6倍`
2. **ブロック間はスペース2つ**：`\c[2][威力] ATKの6倍  \c[27][属性]`
3. **色コードとタグの間はスペースなし**：`\c[2][威力]`（`\c[2] [威力]`はNG）
4. **消費内のスラッシュ前後はスペース1つ**：`MP30 / TP22`
5. **行頭に余分なスペースを入れない**

### NG例

```
NG: \c[2] [威力] ATKの6倍     （色コードとタグの間にスペース）
NG: \c[2][威力]ATKの6倍       （タグと値の間にスペースがない）
NG: \c[2][威力] ATKの6倍   \c （スペース3つ以上）
```

## 属性表記ルール【重要】

### 大分類必須

属性は必ず**大分類（近接物理/遠距離物理/魔法）**から始める。

```
正: [属性] 近接物理 / 斬
正: [属性] 魔法 / 炎
正: [属性] 遠距離物理 / 刺
誤: [属性] 斬
誤: [属性] 炎
```

### 複合属性の書式

```
[属性] 近接物理 / 斬 / 炎
[属性] 魔法 / 雷 / 水
```

### 属性ID対応表

| ID | 属性名 | ID | 属性名 |

| 2 | 炎 | 11 | 斬 |

## ステート付与表記ルール【重要】

### 統一書式

ステート（状態異常・バフ・デバフ）を付与する効果は以下の形式で記載する。

```
ステート名付与付与率%
```

### 書式詳細

| 要素 | 説明 | 例 |
|------|------|-----|
| ステート名 | 付与するステートの名前 | 大出血、スタン、毒Lv1 |
| 付与 | 固定文字列「付与」 | 付与 |
| 付与率% | 付与確率（%付き） | 10%、100%、50% |

### 記述例

| 正しい表記 | 誤った表記 |
|-----------|-----------|
| 大出血付与10% | 大出血10% |
| スタン付与20% | スタン20%付与 |
| 毒Lv1付与100% | 毒Lv1(100%) |
| 防御低下付与50% | 防御低下50% |

### 複数ステート付与の場合

スラッシュ（/）で区切る。

```
[効果] 毒付与30% / 麻痺付与10%
[効果] 大出血付与5% / スタン付与5%
```

### 自己バフ・味方バフの場合

「付与」の代わりに効果内容を直接記載してもよい。

```
[効果] ATK+30% 3T
[効果] 集中+3T (命中+30%)
```

## 装備条件（[要]タグ）ルール

### 配置場所

**3行目（拡張説明タグ内）の先頭**に配置する。

```
<拡張説明:\c[30][要] 剣  \c[7]フレーバーテキスト>
```

### 理由

- 2行目のスペースを確保するため
- フレーバーテキストと併記しても視認性が良好

### 職業別デフォルト装備条件

| 職業 | デフォルト装備 | 備考 |
|------|---------------|------|
| 剣士 | 剣 | 長剣、短剣含む |
| 薬師 | 魔術書 | 調合用 |
| 鍛冶屋 | 魔術書 | 鍛造用 |
| 炎魔術師 | 杖 | 炎属性杖 |
| 雷魔術師 | 杖 | 雷属性杖 |

### 複数条件の場合

```
<拡張説明:\c[30][要] 長剣/槍  \c[7]フレーバーテキスト>
```

### 装備条件なしの場合

[要]タグを省略し、フレーバーテキストから開始。

```
<拡張説明:\c[7]フレーバーテキスト>
```

## データタイプ別 記述ルール

### スキル（Skills.json）

#### 1行目：主要スキルデータ

```
\c[2][威力] ATKの6倍  \c[27][属性] 近接物理 / 斬  \c[24][効果] 大出血付与10%
```

**記載順序（優先度順）：**
1. [威力] or [回復]
2. [属性]
3. [発動速度]（**マイナスの場合は必須**）
4. [効果]（1行目に収まる場合）

#### 2行目：補助データ＋戦略コメント

```
\c[1][対象] 敵単体  \c[17][命中] +95%  \c[23][消費] MP30 / TP22  \c[0]高威力の切り札。
```

**記載順序（優先度順・厳守）：**
1. [効果]（1行目から溢れた場合）
2. [対象] **必須**
3. [命中] **必須**（successRateが100未満の場合は必ず記載）
4. [消費] **必須**（コストがある場合）
5. 戦略コメント（`\c[0]`で開始）**必須**

#### 3行目：装備条件＋フレーバーテキスト（note内）

```
<拡張説明:\c[30][要] 剣  \c[7]運動エネルギーE=½mv²。速度を上げれば威力は二乗で増加する。>
```

**構造：**
1. `\c[30][要] 装備名  `（装備条件がある場合）
2. `\c[7]フレーバーテキスト`（45文字以内）

## パッシブスキル（常時発動）の書式【重要】

### スキル名

```
正: 剣の心得 [常時発動]
正: 神速の素質 [常時発動]
誤: ★剣の心得
誤: 剣の心得（パッシブ）
```

### description書式

```
\c[6][常時発動]\c[24] ATK+15%・斬属性+10%\c[0]
\c[0]中盤の火力底上げパッシブ。
```

**構造：**
- 1行目：`\c[6][常時発動]` + 効果
- 2行目：`\c[0]` + 簡潔な説明

### 生産系パッシブ（◆マーク）

```
名前: ◆基本鍛造 [常時発動]
description:
\c[6][常時発動]\c[24] 基本金属加工が可能\c[0]
\c[0]生産スキル解禁。鍛冶の第一歩。
```

**note（3行目）：**
```
<拡張説明:\c[30][要] 魔術書  \c[7]炭素含有量で鋼の硬度が決まる。Fe-C系状態図は材料科学の基礎。>
```

### 記載条件

- **マイナス（遅くなる）場合は必ず記載**
- プラス（速くなる）場合は任意

```
\c[16][発動速度] -50
\c[16][発動速度] -100
```

## 命中タグルール【v3追加】

### 記載条件

- **successRateが100未満の場合は必ず記載**
- successRateが100の場合は任意（省略可）だが、記載推奨

### 書式

```
\c[17][命中] +95%
\c[17][命中] +85%
\c[17][命中] 100%
\c[17][命中] 必中
```

## 禁止事項

### 使用禁止の表現

| 禁止 | 理由 | 代替 |
|------|------|------|
| ▶ | 視認性が悪い | なし |
| [パッシブ] | 旧表記 | [常時発動] |
| 600%ATK | 英語表記 | ATKの6倍 |
| [消費MP] [消費TP] | 文字数過多 | [消費] MP値 / TP値 |
| [MP] [TP] | 略記 | [消費] MP値 / TP値 |
| 敵単、味方全 | 略記 | 敵単体、味方全体 |
| 2行目に[要] | 配置ミス | 3行目（拡張説明内）に配置 |
| [命中]省略（95%以下） | 必須項目 | 必ず記載 |
| 大出血10% | 「付与」なし | 大出血付与10% |
| スタン20%付与 | 語順が違う | スタン付与20% |
| `\c[16][消費]` | 色が間違い | MPあり→`\c[23]`, TPのみ→`\c[29]` |

## 戦略コメントの書き方

### 基本ルール

- 2行目の末尾に `\c[0]` で配置
- 簡潔に（20文字程度が目安）
- ゲームプレイに役立つ情報を優先

### コメント例

| 用途 | 例 |
|------|-----|
| 基本評価 | 低コストで堅実な基本技。 |
| 特効情報 | 物理耐性特攻で硬い敵に有効。 |
| 戦術提案 | 高スタン率で行動封じ。 |
| リスク説明 | 命中低めだが高リターン。 |
| 用途提示 | 全体攻撃で雑魚掃討向き。 |
| 重要度 | ボス戦の切り札。 |

## フレーバーテキスト（3行目）

### 拡張説明タグの書式

**装備条件ありの場合：**
```
<拡張説明:\c[30][要] 剣  \c[7]フレーバーテキスト（35文字程度）>
```

**装備条件なしの場合：**
```
<拡張説明:\c[7]フレーバーテキスト（45文字以内）>
```

### 文字数制限

- [要]タグありの場合：フレーバー部分は**約35文字**
- [要]タグなしの場合：フレーバー部分は**45文字以内**

### 教育要素の必須ルール

1. **受験キーワードを必ず1つ含める**
2. **因果関係を含める**

```
○ 「燃焼の三要素を強制供給―酸素・熱・燃料が揃えば何でも燃える」
○ 「電位差で電流を流す―これが雷の正体」
× 「めっちゃ燃える炎を出す」（キーワードなし）
```
