### 命中・回避・会心の考え方

- **当たらないが痛い**（格闘家・竜騎士）と**絶対に外さない**（ガンナー・狩人）を両端に置く
- **低命中は手数の多い職にだけ付ける**。AGIが低い職は1回外す損失が大きい
- **避ける職は徹底的に避け、避けない職は0%**。タンクは避けると身代わり・★老練・★囮の心得が機能しない
- 純魔術師は会心0。火力は印・凍結・契約など各システム側で出す
- 命中100%超過分は、命中デバフ（砂嵐-30%、不協和音-15%、暗闇）への保険
- 魔法スキルは命中率を参照しないので、魔術師の命中値は通常攻撃と物理スキルにだけ効く
- MZには攻撃側のステート付与率特性がないので、付与の得意不得意はスキル成功率とパッシブで表現する

## 準備がかかる技の強さ基準

### 基準：N手かけたら（N+1）倍を必ず超える

準備に1手使って次の一撃が2倍なら、同じ技を2回撃つのと同じで、敵に動かれるぶん損になる。リソースを1回分しか払わない利点はあるが、それだけでは準備する理由にならない。そこで全ての準備技を「**次の一撃ボーナス**（+X）」で統一し、次の式で管理する。

> 次の一撃の倍率 ＝ 1 ＋ ボーナスの合計 行動あたり効率 ＝（1 ＋ ボーナス合計）÷（準備の手数 ＋ 1）

| 準備の重さ                                         | ボーナス | 倍率 | 同じ技を連打した場合との効率比 |
|:---------------------------------------------------|:---------|:-----|:-------------------------------|
| 1手（リスクなし）                                  | **+1.5** | ×2.5 | 1.25                           |
| 1手（行動不可・回避低下・自傷などのリスクつき）    | **+2.0** | ×3.0 | 1.5                            |
| 攻撃しながら付与（裁きの剣→破邪、急降下→墜落地点） | +1.0     | ×2.0 | 手数を使わないので常に得       |
| 味方に渡す支援（一点集中研磨）                     | +1.0     |      | 渡す相手の一撃が大きいほど得   |

効率比に加えて、準備技には次の利点が乗る：大技のコストを1回分しか払わない／ブレイク中（2倍）に合わせて撃てる／印Lv2・Lv3や急所貫通のように、準備しないと撃てない高倍率の専用技がある。

### 重複ルール：自己準備も重ねてよい。ただし加算

| 方式                   | 集中（+1.5）＋構え（+2.0）の場合 | 行動あたり効率 | 評価                                                                                                                                         |
|:-----------------------|:---------------------------------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| 重複なし（最大値のみ） | ×3.0（集中が無駄になる）         | 1.0            | 準備スキルを複数持つ意味がなくなる                                                                                                           |
| **加算（採用）**       | **×4.5**（3手）                  | **1.5**        | 重ねても効率は落ちず、ブレイクに合わせた一撃が大きくなる                                                                                     |
| 乗算                   | ×7.5（3手）                      | 2.5            | 重ねるほど効率が上がり続ける。「全員が数ターン溜めて一撃」が常に最適解になり、研磨・死亡フラグ・会心・ブレイクまで掛けるとボスが一撃で落ちる |

- **加算プールに入れるもの**：自分の「次の攻撃X倍」（構え、集中、印、過電流、過冷却、風読み、零距離姿勢、理論武装、精密照準、ロックオン）、味方からの「次の一撃」（研磨済み）、敵側の「次の被ダメX倍」（破邪、死亡フラグ、刻印、墜落地点、貫通痕）
- **乗算のままにするもの**：会心2倍、ブレイク2倍、弱点1.5倍、通常のバフ・デバフ（ATK+30%、耐性低下、脆弱など）
- 同じステートの二重がけは不可（上書き）。重ねられる数は職ごとの準備スキルの種類で自然に決まる
- 属性や技の種類が合わないボーナスは加算しない（印は炎術のみ、零距離姿勢は刺のみ、など）

実装例（ステートのメモ欄に `<PrepBonus:1.5>`、敵側ステートに `<TakenBonus:1.0>` を書き、対象スキルの式にだけ掛ける）：

``` js
Game_BattlerBase.prototype.prepRate = function(target) {
  const sum = (b, key) => b.states().reduce((r, s) => r + Number(s.meta[key] || 0), 0);
  return 1 + sum(this, "PrepBonus") + (target ? sum(target, "TakenBonus") : 0);
};
// ダメージ式の例：a.atk * 8 * a.prepRate(b)
```

属性限定のボーナスは `<PrepBonusFire:1.5>` のようにキーを分け、炎術の式では両方を足す。消費は既存の「1回消費」ステートの解除処理をそのまま使う。

## バランス評価

火力指数 = 主力ステータス × min(命中,100%) ×（1＋会心率×会心倍率の上乗せ分）× AGI比。剣士を1.00とする。「素」は職業特性のみ、「パッシブ込み」はLv99で常時発動する攻撃系パッシブを含む。条件付きパッシブ・スキル倍率・準備技は含まない。物理実効HP = HP ÷（1−回避）。

|:-----------|-----:|-------------:|-----------:|:------------------------------------------------------------------------------------|

### 評価まとめ

- **格闘家**がパッシブ込みで約2.0の単独トップ。雨天中の水魔術師（約1.9、5T限定）と並ぶ位置に上げた。侍（居合い系1.7）、特記戦力兵（1.3）が続く。v2のままだと特記戦力兵が約2.1で突出していた
- **剣士**はパッシブの伸びが大きく、素の指数で上にいる職の多くをパッシブ込みで追い抜く。最初の職業が終盤まで主力でいられる水準
- **剣士の九頭龍閃**は切り札の中で最も低いが、準備不要・TP50＋MP50で撃てる。剣気解放（ATK+30%・3T持続のバフ）を先に使えばブレイク＋弱点で約43,000
- **準備型の職**（炎魔術師・水魔術師・竜騎士・機械装甲兵）は指数が低く見えるが、準備技の倍率引き上げで実戦火力は上位に届く。指数が低い職ほど準備技が強い、という関係にしている
- **機械装甲兵**は依然として最下位。テスト戦闘で、ロックオン→ビームライフル（MAT\*3.5×3.0）とパイルバンカー500%が低AGIを補えているか要確認
- **回避0で低HPの職**（召喚士2800、氷魔術師3600、炎魔術師3800）は、ボスの全体物理で落ちすぎないか要確認
