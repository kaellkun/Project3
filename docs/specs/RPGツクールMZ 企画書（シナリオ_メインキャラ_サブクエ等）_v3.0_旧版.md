## 1.2 序章：目覚めの遺跡

### 概要

| 項目 | 内容 |
|------|------|
| 舞台 | コールドスリープ施設跡（チュートリアルダンジョン） |
| 目的 | 操作習得、ビーツーとの出会い、世界観の導入 |
| ボス | 施設防衛ドローン（チュートリアル戦闘） |

### イベントフロー

```
[オープニング]
├─ 主人公パーティー、ギルドから遺跡調査依頼を受ける
├─ 依頼内容：「崩落した施設から"光る何か"を回収せよ」
└─ 報酬：500$（序盤としては破格）

[遺跡探索]
├─ 基本操作のチュートリアル（移動、メニュー、セーブ）
├─ 戦闘チュートリアル（弱い機械系モンスター）
├─ 宝箱から「宇宙世紀の規格書」（メモアイテム）入手
└─ 最深部でビーツー発見

[ビーツー起動イベント]
├─ 主人公がビーツーに触れると再起動
├─ ビーツーの記憶は断片的
│   ├─ 「任務…地球圏…調査…」
│   └─ 「警告：外宇宙からの…（ノイズ）」
├─ 施設防衛システムが起動（ボス戦）
└─ ビーツーが加入、脱出

[序章終了]
├─ 拠点「ノヴァ・ローマ」に帰還
├─ ギルドに報告、ビーツーの処遇を相談
└─ 第1章へ
```

### 教育的要素（序章）

| 分野 | 要素 | 表現方法 |
|------|------|----------|
| 工学 | 冷凍保存技術 | メモアイテム「コールドスリープ技術概論」 |
| 物理 | 絶対零度の概念 | NPC「-273℃まで冷やせば時間も止まる…理論上は」 |
| 歴史 | 文明の断絶と継承 | 遺跡の状態から「1500年」の時間経過を実感 |

## 1.4 第2章：封印の真実

### 概要

| 項目 | 内容 |
|------|------|
| 舞台 | 各地の封印施設、統一政府時代の遺跡 |
| 目的 | 「封印」の正体を解明する |
| 章ボス | 覚醒した外宇宙民の尖兵「ヴォイド・ハンター」 |

### 核心的発見

- 第2世代が外宇宙民を「封印」で閉じ込めた
- 封印は「3つの柱」（魔導・科学・信仰）で維持
- 1500年経ち、封印が弱まっている

### 教育的要素（第2章）

| 分野 | 要素 | 表現方法 |
|------|------|----------|
| 物理 | 次元の概念 | 「3次元の我々には、4次元の存在は理解できない」 |
| 歴史 | 文書の焚書 | 「記録を消しても、真実は消えない」 |
| 政治 | 評議会制度 | アルカディア評議会の意思決定プロセス |
| 工学 | 冗長性設計 | 「3つの柱は、1つが壊れても他が補う設計だ」 |

## 1.5 第3章：分断と選択

### 概要

| 項目 | 内容 |
|------|------|
| テーマ | 対立する解決策と選択 |
| 舞台 | 拠点内の政治劇、各地の封印施設 |
| 章ボス | 封印施設の守護者たち |

### 対立構造

**封印強化派（セオドア、長老）**
- 封印を強化し、外宇宙民を永遠に閉じ込める
- 根拠：1500年間平和だった実績
- リスク：封印維持のコスト、いつかは限界

**共存模索派（マルクス）**
- 外宇宙民との対話・共存の可能性を探る
- 根拠：相手を知らずに封じ続けるのは限界
- リスク：対話が失敗すれば壊滅的被害

### 教育的要素（第3章）

| 分野 | 要素 |
|------|------|
| 政治学 | 合意形成の難しさ |
| 倫理学 | トロッコ問題的選択 |
| 経済学 | 機会費用 |
| 心理学 | 確証バイアス |

## 1.6 第4章：黎明の刻（時間ループによる複数エンディング体験）

### 概要

| 項目 | 内容 |
|------|------|
| テーマ | **何度も失敗し、そこから学び、真の解決に至る** |
| 構造 | ループ1→ループ2→ループ3→真の選択→真ED |
| 舞台 | 次元の狭間、外宇宙民の残骸、時間の回廊 |

### 時間ループの世界観的説明

外宇宙民は「次元の外」から来た存在であり、時間軸に縛られない。
封印の核が弱まったことで、主人公パーティーは「時間のループ」に巻き込まれる。

### 第4章の構造：4回のループ

#### ループ1：封印強化の未来

- 選択：セオドアの提案に従い、封印を強化する
- ダンジョン：次元の狭間
- ボス：境界の守護者
- 結末：封印は強化されるが、ビーツーが封印の核に同化し永眠
- 【バッドエンドA：封印の代償】→ 時間が巻き戻る

**教育的要素：** 問題の先送り、サンクコスト、犠牲の倫理

#### ループ2：共存模索の未来

- 選択：マルクスの提案に従い、対話を試みる
- ダンジョン：外宇宙民の残骸
- ボス：対話拒否派の外宇宙民
- 結末：対話は一部成功するが、長老が死亡、全面戦争が始まる
- 【バッドエンドB：共存の代償】→ 時間が巻き戻る

**教育的要素：** 対話の限界、過激派の問題、歴史的トラウマ

#### ループ3：第三の道（不完全版）

- 気づき：「封印」でも「共存」でもない方法があるはず
- 試行：封印を「壁」から「扉」に変える
- ダンジョン：時間の回廊
- ボス：時間を歪める外宇宙民「クロノス」
- 結末：成功しかけるが、長老がいない（ループ2で死亡）ため不完全
- 【バッドエンドC：不完全な第三の道】→ 時間が巻き戻る
- ★重要な気づき★「長老を救わなければ、第三の道は完成しない」

**教育的要素：** 三権分立の必要性、過去の選択の影響、部分最適と全体最適

#### ループ4：真の選択

過去のループで学んだ全てを活かす：
1. ループ2で長老を救う方法を発見
2. ループ1でビーツーを救う方法を発見
3. セオドア・マルクス・長老を同時に説得

- 最終ダンジョン：黎明の回廊
- 最終ボス：対話拒否派の長
- 結末：対話拒否派を説得、封印を「扉」に変換成功、誰も犠牲にならない
- 【真エンディング：黎明】

**教育的要素：** 試行錯誤の価値、対立の止揚、信頼構築、多様な視点の統合

### 各エンディングまとめ

| エンディング | 到達条件 | 結末 | 教育的メッセージ |
|--------------|----------|------|------------------|
| バッドA | ループ1完了 | 封印強化、ビーツー永眠 | 問題の先送りは解決ではない |
| バッドB | ループ2完了 | 対話失敗、全面戦争 | 対話には相互の意志が必要 |
| バッドC | ループ3完了 | 不完全な扉、世界崩壊 | 部分最適は全体最適ではない |
| 真ED | ループ4完了 | 完全な解決、誰も犠牲にならない | 失敗から学び、協力で乗り越える |

## 4.2 各職業の教育的見せ場（概要）

### 戦闘職3職

**剣士**
- 「超振動斬り」：分子振動と物質の構造破壊
- 「浮遊剣展開」：遠隔操作と脳波制御の原理
- 「九頭龍閃」：連続攻撃と運動エネルギーの蓄積

**炎魔術師**
- 「火炎3連弾」：燃焼反応と酸素供給
- 「印を結ぶ」：触媒と反応速度
- 「天照」：黒体放射と熱エネルギー

**雷魔術師**
- 「帯電付与」：電位差と電流の流れ
- 「雷化」：電気抵抗とイオン化
- 「心網展開」：生体電気と神経伝達

### 製作職3職

**薬師**
- 「劇薬システム」：薬物動態と副作用
- 「腐食液」：酸とアルカリ、pH
- 「解毒剤」：解毒のメカニズム

**鍛冶屋**
- 「焼けた鉄槌」：熱伝導と金属の性質
- 「過熱システム」：熱膨張と材料劣化
- 「武器を研ぐ」：摩擦係数と切れ味

**旧世紀技術者**
- 「ハッキング」：コンピュータセキュリティ
- 「回路過負荷」：電気回路と過電流
- 「共鳴増幅」：共振と振動

### 追加職6職

**聖騎士**
- 「聖印システム」：信仰と心理的効果
- 「浄化」：光のエネルギーと殺菌作用
- 「裁きの剣」：正義論と罪の概念

**ハロルド**
- 「メタスキル」：ゲームデザインとメタ認知
- 「死亡フラグ」：物語の構造とお約束
- 「主人公補正」：確率と期待値

**イケメン狩人**
- 「急所作成」：動物の解剖学と弱点
- 「追跡開始」：追跡技術と行動予測
- 「罠設置」：力学と機械仕掛け

**ケモっ娘狩人**
- 「匂いをつける」：嗅覚のメカニズム
- 「野生の勘」：直感と無意識の処理
- 「獣化」：アドレナリンと闘争本能

**美人格闘家**
- 「二重の極み」：衝撃波と物質破壊
- 「破砕」：応力と材料の限界
- 連撃スキル：運動量と力積

**水魔術師**
- 「浸水」：水と電気の関係
- 「水圧」：圧力と深度の関係
- 「あまごい」：気象と水循環

# 6. 魔法の科学体系

## 6.1 基本原理

本作の魔法は「未解明の物理現象」として扱う。
魔力（マナ）は「宇宙世紀に発見された未知のエネルギー場」であり、
第2世代がその制御方法を体系化した。

### 魔法の三要素

1. **魔力源（マナ）**：生物が生成するエネルギー場
2. **触媒（印・詠唱）**：魔力を特定パターンに変換
3. **対象（標的・範囲）**：魔力がどこに作用するか

## 7.2 各権力の詳細

### 立法府：元老院（Senate）

| 項目 | 内容 |

| 項目 | 内容 |

| 項目 | 内容 |
|------|------|
| 構成 | 最高法官1名 + 法官12名 |
| 選出方法 | 元老院による指名、終身任期 |
| 主要権限 | 法解釈、違憲審査、勢力間紛争の仲裁 |

## 7.3 チェック・アンド・バランス

- **元老院 → 執政官府**：予算否決、不信任決議
- **執政官府 → 元老院**：法案拒否権（議会で2/3で覆せる）
- **法官会議 → 両者**：違憲判断で法律・行政命令を無効化
- **元老院 → 法官会議**：法官の任命
- **執政官府 → 法官会議**：訴追権

## 7.4 政治制度と物語の連動

### 第3章での対立

封印強化法案をめぐり、元老院（セオドア）と執政官府（マルクス）が対立。
法官会議（長老）が調停役として介入。

### 真エンディングでの政治的解決

1. セオドアの譲歩：「封印を維持しつつ、扉への改造を認める」
2. マルクスの譲歩：「対話は監視下で行い、危険があれば即座に中止」
3. 長老の仲裁：「両者の合意を法的に担保する特別条約を制定」
4. 三権の協力により、第三の道が可能になる

- 政治的安定：不安定だと通貨下落
- 中央銀行の政策：金融緩和で通貨下落
- 戦争・紛争：リスク回避で安全通貨に逃避
