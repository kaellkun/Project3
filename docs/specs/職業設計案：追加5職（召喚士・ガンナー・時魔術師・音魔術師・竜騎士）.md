# 職業設計案：追加5職（召喚士・ガンナー・時魔術師・音魔術師・竜騎士）

## 設計方針

- 既存18職との役割被りを避ける
- 各職業に明確な「この人でないとダメ」な理由を持たせる
- 世界観設定（宇宙世紀の遺産・第2世代魔導）を活かす
- **教育要素を職業の核心に組み込む**

### システム前提（既存職業設計と同様）
- **戦闘不能は存在しない**（誰か一人でも死んだらゲームオーバー）
- **敵の全ステータスと弱点属性は常に表示**されている
- **敵にはレベルがない**
- **DEFという概念がない**（「被ダメージX倍」の耐性システム）
- **回復スキルは職業に付与しない**（回復が貴重なゲームバランス）

## 19. 召喚士（サモナー）

### キャラクター設定

| 項目 | 内容 |
|------|------|
| 名前 | （仮）リーシャ |
| 出自 | 第2世代の「契約者」の末裔、精霊と対話できる一族 |
| 登場時期 | 第2章中盤（封印の調査で協力を求められる） |
| 加入時期 | 第2章終盤（封印の性質を理解するために同行） |
| 見た目 | 神秘的な雰囲気の少女、常に小さな精霊が周囲を漂う |
| 性格 | 穏やかだが芯が強い、精霊との会話を優先することがある |

### コンセプト
**「契約した精霊を召喚し、状況に応じて戦う」多属性対応アタッカー**。
精霊との「契約」によって様々な属性攻撃が可能。
召喚した精霊によって戦闘スタイルが変化する「切り替え型」。
FFの召喚獣＋ペルソナ＋Fateのマスターのイメージ。

### 得意属性
- **召喚した精霊に依存**（炎・水・雷・土・光・闇から選択）
- **無**（契約魔法自体）

### 設計思想
- **「なぜこの人でないとダメか」**：
  - 精霊との「契約」は生まれつきの素質＋長年の修行が必要
  - 精霊言語を理解し、魂の共鳴ができる特殊な精神構造
  - 他者が召喚獣を「借りる」ことは不可能（契約は魂に刻まれる）
- 状況に応じて属性を切り替えられる柔軟性
- 召喚中は術者の行動が制限される（トレードオフ）
- 契約精霊を「育てる」成長要素

### 教育的テーマ
- **法学（契約法）**：契約の成立要件、双務契約、解除条件
- **神話学**：各文化の精霊・神話体系
- **量子力学**：観測と存在（召喚＝観測して実体化）
- **心理学**：信頼関係の構築

## 20. ガンナー（土魔術師＋銃使い統合）

### キャラクター設定

| 項目 | 内容 |
|------|------|
| 名前 | （仮）クレイ |
| 出自 | 鉱山都市出身、鍛冶屋の一族から派生した「弾丸術師」 |
| 登場時期 | 第1章中盤（鉱山ダンジョンで出会う） |
| 加入時期 | 第1章終盤（鍛冶屋との連携イベント後） |
| 見た目 | ゴーグルをかけた実用的な服装、腰に銃と鉱石サンプルを携帯 |
| 性格 | 理論派で几帳面、弾丸の素材にこだわる職人気質 |

### コンセプト
**「大地から弾丸を生成し、精密射撃で敵を仕留める」遠距離物理アタッカー**。
土属性の魔法で鉱物を操り、その場で弾丸を生成して撃つ。
弾丸の素材によって属性や効果が変化する「弾丸切替型」。
ガンダムのスナイパー＋鋼の錬金術師＋ゴールデンカムイのイメージ。

### 得意属性
- **土**（鉱物操作・弾丸生成）
- **刺**（弾丸による貫通）
- **破**（炸裂弾）

### 設計思想
- **「なぜこの人でないとダメか」**：
  - 「鉱物との対話」ができる特殊な感覚（鍛冶屋の血統から派生）
  - 弾丸生成は瞬時の鉱物変成が必要で、長年の修行が必須
  - 銃は「弾丸を飛ばす道具」であり、弾丸こそが本体
- 鍛冶屋との差別化：
  - 鍛冶屋＝近接打撃＋武器強化＋炎
  - ガンナー＝遠距離射撃＋弾丸生成＋土
- 弾丸の素材選択で戦術が変化

### 教育的テーマ
- **地質学**：岩石の種類、鉱物の性質、地層
- **弾道学**：放物線運動、空気抵抗、終端速度
- **材料科学**：金属の硬度、密度、融点
- **結晶学**：結晶構造、劈開、硬度

## 23. 竜騎士（ドラグーン）※獣使い9割＋FF竜騎士1割

### キャラクター設定

| 項目 | 内容 |
|------|------|
| 名前 | （仮）レオン |
| 出自 | 辺境の「獣語り」の村出身、様々な魔獣と契約してきた |
| 登場時期 | 第1章中盤（荒野ダンジョンで魔獣と戦っているところに遭遇） |
| 加入時期 | 第1章中盤（魔獣の群れを共に退けた後） |

| 性格 | 無口だが動物には優しい、獣と話す時だけ饒舌になる |

### コンセプト
**「様々な魔獣と心を通わせ、共に戦う」獣召喚＋跳躍攻撃のハイブリッド**。
複数の魔獣（狼、鷹、熊、そして竜）と契約し、状況に応じて呼び出す。
竜との契約で「ジャンプ」技を習得、FFの竜騎士要素を少し持つ。
ポケモントレーナー＋FFカイン＋ナルトのキバのイメージ。

### 得意属性
- **打・斬**（獣の攻撃に依存）
- **風**（飛行系の獣、ジャンプ攻撃）

### 設計思想
- **「なぜこの人でないとダメか」**：
  - 「獣の言葉」を理解する特殊な感覚器官（一族の遺伝）
  - 魔獣との信頼関係は長年かけて構築（道具では代替不可）
  - 自分の生命力を分け与える「絆」システム
- 獣の種類で戦術が変化
- 竜との契約で「ジャンプ」解禁（高リスク高リターン）

### 教育的テーマ
- **動物行動学**：非言語コミュニケーション、社会性、群れの構造
- **進化生物学**：共生、相利共生、擬態
- **神経科学**：ミラーニューロン、共感
- **生態学**：食物連鎖、生態ピラミッド、捕食者と被食者
