# 序盤から使える基本スキル選定案（拡張版）

## 概要
各職業に以下を選定：
- **基本スキル4つ**（剣士のみ6つ）：低〜中コスト、序盤の主力
- **重めスキル2つ**：中〜高コスト、溜めて撃つ切り札
- **TP100必殺技1つ**：戦闘のクライマックス

- コスト：TP30-60 / MP60-100

- 大ダメージ or 戦局を変える効果
- 一部は「条件付き」でさらに強化
