# RPGツクールMZ データ変換仕様書

## 概要

本書は、スプレッドシート（skill_state_v6.xlsx）のデータをRPGツクールMZのJSON形式（Skills.json / States.json）に変換するためのルールを定義する。

---

## 第1章：設計方針（スプレッドシートより）

### 1.1 完全固有化の原則

| 原則 | 説明 |
|------|------|
| 1スキル＝1固有ステート | 同じ効果でも、スキルごとに別のステートを定義 |
| 全ステート重複可能 | 「気合い(C)」と「闘気(格闘)」は両方同時に適用される |
| 参照されないステートは存在しない | すべてのステートが必ずスキルから付与される |

### 1.2 ステートID体系

| ID範囲 | 用途 |
|--------|------|
| 1〜20 | 既存システムステート（戦闘不能、ブレイク等）※変更禁止 |
| 21〜199 | バフステート |
| 200〜299 | デバフ・バッドステート |

### 1.3 C.汎用スキルと職業スキルの差別化

| 種別 | 特徴 | 例 |
|------|------|-----|
| C.汎用スキル | シンプルで短い効果（1T or 1回消費） | C.気合い：次の一撃1.5倍（1回消費） |
| 職業スキル | 特化して長い/強い効果（3T以上、複合効果） | 格闘家.闘気：ATK+30%・被ダメ0.9倍（3T持続） |

## 第4章：Skills.json変換ルール

### 4.1 基本フィールド

| JSONフィールド | 型 | 変換ルール |
|---------------|-----|-----------|
| `id` | number | 連番で採番（既存1〜60は使用済み） |
| `name` | string | スプレッドシートの「スキル名」をそのまま |
| `iconIndex` | number | 種別に応じて設定（攻撃:76〜78, 補助:72, パッシブ:89） |
| `stypeId` | number | アクティブ→1or2, パッシブ→3 |
| `scope` | number | 対象範囲（後述） |
| `occasion` | number | 使用可能場面（1:常時, 0:使用不可） |
| `speed` | number | 発動速度（通常0, 遅い技は-50〜-100） |
| `successRate` | number | 命中率（通常95, 必中100, 低命中70〜85） |
| `repeats` | number | 連続回数（"×2連"→2, "×4連"→4） |
| `tpGain` | number | TP獲得量（攻撃系:10, 補助系:0〜10） |
| `messageType` | number | 1（固定） |

### 4.2 コスト変換

| スプレッドシート | mpCost | tpCost |
|-----------------|--------|--------|
| "TP15" | 0 | 15 |
| "MP50" | 50 | 0 |
| "MP50 TP10" | 50 | 10 |
| "TP22 MP30" | 30 | 22 |
| "-" または空 | 0 | 0 |

**パース手順：**
1. "MP"の後の数値 → `mpCost`
2. "TP"の後の数値 → `tpCost`
3. "HP-20%"などは別途処理（effects配列へ）

### 4.3 damage オブジェクト

```json
{
  "critical": true,
  "elementId": 11,
  "formula": "250*(a.atk/100)",
  "type": 1,
  "variance": 10
}
```

| フィールド | 変換ルール |
|-----------|-----------|
| `critical` | 攻撃系:true, 補助系:false |
| `elementId` | 属性の1つ目を設定（斬=11）。複数属性は`note`に追加 |
| `formula` | 効果概要からパース（後述） |
| `type` | 1:HPダメージ, 3:HP回復, 4:MP回復, 0:なし |
| `variance` | 通常10〜20 |

### 4.4 formula変換

| 効果概要の記述 | formula |
|---------------|---------|
| 250%ATK | `"250*(a.atk/100)"` |
| MAT*1 | `"a.mat*1"` |
| MAT*1.5 | `"a.mat*1.5"` |
| 350固定 | `"350"` |
| HP15%回復 | `"a.mhp*0.15"` |

### 4.5 scope（対象範囲）

| 記述 | scope値 |
|------|---------|
| 敵単体 | 1 |
| 敵全体 | 2 |
| ランダム1〜3回 | 3 |
| ランダム4回 | 4 |
| 味方単体 | 7 |
| 味方全体 | 8 |
| 使用者/自分 | 11 |
| 使用不可（パッシブ） | 0 |

### 4.6 effects配列

ステート付与の場合：
```json
{
  "code": 21,
  "dataId": 14,
  "value1": 0.1,
  "value2": 0
}
```

| code | 効果 | dataId | value1 |
|------|------|--------|--------|
| 21 | ステート付与 | ステートID | 付与確率（0.1=10%） |
| 12 | MP回復 | 0 | 0, value2=回復量 |
| 13 | TP回復 | 0 | 回復量 |

**付与ステートのパース：**
- "【敵】スタン" → code:21, dataId:14（スタンのID）, value1は効果概要から確率取得
- "【自】剣気解放" → 自己付与、対応するステートIDを参照
- "-" または "-（パッシブ）" → effects配列は空`[]`

### 4.7 description（説明文）

仕様書に従い、色コード付きで2行構成：

```
\c[2][威力] 250*ATK%  \c[27][属性] 近接物理 / 斬  \c[24][効果] 大出血5%
\c[1][対象] 敵単体  \c[17][命中] +95%  \c[29][消費TP] 15  \c[0]高威力の一閃。
```

**色コード対応：**
| タグ | 色コード |
|------|----------|
| [威力] | `\c[2]` |
| [回復] | `\c[3]` |
| [属性] | `\c[27]` |
| [効果] | `\c[24]` |
| [対象] | `\c[1]` |
| [命中] | `\c[17]` |
| [消費MP] | `\c[23]` |
| [消費TP] | `\c[29]` |
| [パッシブスキル] | `\c[6]` |
| 戦略コメント | `\c[0]` |

### 4.8 note（メモ欄）

```
<属性追加: 近接物理,斬>
<拡張説明:\c[7]「運動エネルギーを刃に集中。E=½mv²」―質量×速度²が威力の源>
```

| タグ | 用途 |
|------|------|
| `<属性追加: X,Y>` | 複数属性の追加 |
| `<拡張説明:\c[7]...>` | フレーバーテキスト（45文字以内） |
| `<NoLukStateSkill>` | 運補正なしのステート付与 |
| `<PassiveSkill:N>` | パッシブスキルのパッシブID |
| `<SEランダム回数:N>` | ランダム対象の回数 |

### 4.9 requiredWtypeId（装備条件）

| 条件 | requiredWtypeId1 |
|------|-----------------|
| [要] 長剣 | 2 |
| [要] 短剣 | 1 |
| [要] 杖 | 6 |
| [要] 硬いもの | 13 |
| [要] ビーム兵装 | 14 |
| 条件なし | 0 |

## 第5章：States.json変換ルール

### 5.1 基本フィールド

| JSONフィールド | 型 | 変換ルール |
|---------------|-----|-----------|
| `id` | number | シートのID列をそのまま使用 |
| `name` | string | ステート名 |
| `iconIndex` | number | バフ:72〜73, デバフ:2,9,74 |
| `priority` | number | 通常40〜50, 行動不能系:90 |
| `restriction` | number | 0:なし, 4:行動不能 |
| `motion` | number | 0:通常, 1:異常 |
| `overlay` | number | 0:なし, 1:毒, 10:ブレイク |
| `removeAtBattleEnd` | boolean | 戦闘終了時解除（通常true） |
| `messageType` | number | 1（固定） |

### 5.2 持続ターン変換

| シートの「持続」 | minTurns | maxTurns | autoRemovalTiming |
|-----------------|----------|----------|-------------------|
| 1T | 1 | 1 | 2 |
| 2T | 2 | 2 | 2 |
| 3T | 3 | 3 | 2 |
| 5T | 5 | 5 | 2 |
| 1回消費 | 1 | 1 | 1（行動終了時） |
| 永続 | 1 | 1 | 0（自動解除なし） |

### 5.3 traits配列（特性）

```json
{
  "code": 21,
  "dataId": 2,
  "value": 1.3
}
```

| code | 効果 | dataId | value |
|------|------|--------|-------|
| 11 | 属性有効度 | 属性ID | 倍率（0.5=半減, 2=弱点） |
| 13 | ステート有効度 | ステートID | 倍率 |
| 21 | 能力値レート | 能力ID | 倍率（1.3=+30%） |
| 22 | 追加能力値 | 追加能力ID | 加算値（0.3=+30%） |
| 23 | 特殊フラグ | フラグID | 0 |
| 62 | 身代わり | 2 | 1 |

**能力ID（code:21用）：**
| dataId | 能力 |
|--------|------|
| 0 | 最大HP |
| 1 | 最大MP |
| 2 | ATK |
| 4 | MAT |
| 6 | 敏捷 |
| 7 | 運 |

**追加能力ID（code:22用）：**
| dataId | 能力 |
|--------|------|
| 0 | 命中率 |
| 1 | 回避率 |
| 2 | クリティカル率 |

### 5.4 message設定

```json
{
  "message1": "%1は剣気を解放した！（ATK+30%/クリ率+20%/命中+20% 3T）",
  "message2": "",
  "message3": "%1は剣気を解放している！（ATK+30%/クリ率+20%/命中+20%）",
  "message4": "%1の剣気が収まった。"
}
```

| フィールド | タイミング | 用途 |
|-----------|-----------|------|
| message1 | ステート付与時（味方） | 効果説明を含む |
| message2 | ステート付与時（敵） | 敵視点のメッセージ |
| message3 | 継続中 | 毎ターン表示 |
| message4 | 解除時 | 効果終了メッセージ |

### 5.5 note（メモ欄）

```
<NoLukState>
<SlipDamageFixedHP:-100>
```

| タグ | 効果 |
|------|------|
| `<NoLukState>` | 運補正なし |
| `<SlipDamageFixedHP:N>` | 毎ターン固定HPダメージ |
| `<SlipDamageFixedMP:N>` | 毎ターン固定MPダメージ |
| `<EscapeBonus:N>` | 逃走成功率ボーナス |

## 第7章：変換作業フロー

### 7.1 職業単位での作業手順

```
1. スプレッドシートから該当職業の行を抽出
   ├─ 「全職業スキル一覧」シートから職業でフィルタ
   ├─ 「ステート_バフ」シートから職業でフィルタ
   └─ 「ステート_デバフ」シートから職業でフィルタ

2. ステートを先に作成（Skills.jsonのeffectsで参照するため）
   ├─ ID採番（バフ:21〜199, デバフ:200〜299）
   ├─ traits配列の構築
   └─ message1〜4の設定

3. スキルを作成
   ├─ ID採番（職業ごとに50枠確保推奨）
   ├─ damage/effects/description/noteの構築
   └─ ステートIDの参照を正しく設定

4. JSON形式で出力
   ├─ States.json追加分
   └─ Skills.json追加分

5. ツクールでテストプレイ
   └─ 動作確認・修正
```

### 7.2 ID採番計画（推奨）

**Skills.json：**
| ID範囲 | 職業 |
|--------|------|
| 1〜60 | 既存（使用済み） |

| 101〜150 | 剣士 |
| 151〜200 | 炎魔術師 |
| 201〜250 | 雷魔術師 |
| ... | （以下50枠ずつ） |

**States.json：**
