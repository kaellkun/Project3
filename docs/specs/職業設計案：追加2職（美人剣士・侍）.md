# 職業設計案：追加2職（美人剣士・侍）

## 設計方針

- 既存16職との役割被りを避ける
- 各職業に明確な「この人でないとダメ」な理由を持たせる
- 世界観設定（宇宙世紀の遺産・コールドスリープ）を活かす
- **教育要素を職業の核心に組み込む**
- シナリオ上の役割を反映した設計

### システム前提（既存職業設計と同様）
- **戦闘不能は存在しない**（誰か一人でも死んだらゲームオーバー）
- **敵の全ステータスと弱点属性は常に表示**されている
- **敵にはレベルがない**
- **DEFという概念がない**（「被ダメージX倍」の耐性システム）
- **回復スキルは職業に付与しない**（回復が貴重なゲームバランス）

## 17. 美人剣士（プラズマレイピア使い）

### キャラクター設定

| 項目 | 内容 |
|------|------|
| 名前 | （仮）セレーネ |
| 出自 | 宇宙世紀853年製造の**第0世代**（コールドスリープ最新ロット） |
| 覚醒時期 | **ゲーム終盤**（シナリオ上の重要イベントで覚醒） |
| 見た目 | 細身の美人、長い髪、細長いレイピア型プラズマブレードを持つ |
| 性格 | 冷静沈着だが、1500年のブランクに内心動揺している |

### コンセプト
**「宇宙世紀の最先端技術で強化された、精密一撃必殺の剣士」**。
コールドスリープから目覚めた「最新世代」であり、第1〜3世代とは一線を画す技術を持つ。
**プラズマブレード**と**強化神経系**による超精密な刺突攻撃が特徴。
「一撃で仕留める」カウンター型アタッカー。
FFのライトニング＋SAOのアスナ＋攻殻機動隊の素子のイメージ。

### 得意属性
- **刺**（レイピアによる精密刺突）
- **光**（プラズマブレードの光熱）

### 設計思想
- **「なぜこの人でないとダメか」**：宇宙世紀の強化神経系を持つ唯一の人間
- 1500年前の最先端技術（ナノマシン、強化シナプス）を体に埋め込まれている
- 「道具」ではなく「体の一部」として強化されているため、他者には再現不可能
- カウンター・見切り・一撃必殺に特化
- 連続攻撃よりも「一撃の重さ」で勝負する

### 教育的テーマ
- **神経科学**：シナプス伝達、反射弧、反応速度
- **ナノテクノロジー**：ナノマシン、分子機械
- **プラズマ物理**：プラズマの生成、温度、光
- **流体力学**：刺突の最適軌道、空気抵抗最小化

## 18. 侍（和風剣客・師匠キャラ）

### キャラクター設定

| 項目 | 内容 |
|------|------|
| 名前 | （仮）宗一郎（そういちろう） |
| 出自 | 東方都市国家出身の剣客、主人公の師匠的存在 |
| 登場時期 | **序盤から登場**（チュートリアル的に剣術を教える） |
| 加入時期 | **終盤**（「教えることはもうない」と言って正式加入） |
| 見た目 | 和装の壮年男性、刀を一本だけ持つ |
| 性格 | 寡黙だが温かい、武士道を体現する |

### コンセプト
**「居合いと心眼で敵を斬る、読み合いの達人」**。
序盤から主人公を導く師匠キャラであり、終盤に「もう教えることはない」と言って仲間になる。
**居合い**（一撃必殺）と**心眼**（先読み）に特化した和風剣客。
るろうに剣心の比古清十郎＋サムライスピリッツの覇王丸＋SEKIROの一心のイメージ。

### 得意属性
- **斬**（刀による斬撃）
- **無**（精神系・読み合い）

### 設計思想
- **「なぜこの人でないとダメか」**：数十年の修行で磨いた「心眼」と「居合い」
- 道具や技術ではなく、**純粋な技と精神**で戦う
- 「先の先」「後の先」など、読み合いの概念をスキル化
- 一撃の威力は全職業トップクラス、ただし外すと隙が大きい
- 剣士との差別化：連続攻撃ではなく「一撃必殺」

### 教育的テーマ
- **運動学**：居合いの力学（加速度、運動エネルギー）
- **呼吸法**：横隔膜、自律神経、集中力
- **心理学**：読み合い、予測、フェイント
- **武士道**：倫理、礼、義、勇
- **神経科学**：無意識の処理、直感

## シナリオ上の役割

### 美人剣士（セレーネ）

**登場シーン案**
- 第3章〜第4章で、別のコールドスリープ施設を発見
- 主人公パーティーが施設を調査中、彼女が目覚める
- 「第0世代」として、第1〜3世代とは異なる視点を持つ
- 宇宙世紀の末期、大厄災直前の記憶を持っている可能性

**教育的な見せ場**
- 宇宙世紀の技術（ナノマシン、強化神経）について語る
- 「1500年前の最先端」が現代にどう影響しているかを説明
- プラズマ技術の原理を戦闘中のセリフで解説

### 侍（宗一郎）

**登場シーン案**
- 序章〜第1章で「謎の剣客」として登場
- 主人公が困っている場面で助けてくれる
- 「剣の基本」を教えるチュートリアル的役割
- 第3章終盤で「もう教えることはない」と言って正式加入

**教育的な見せ場**
- 武士道の精神（義、礼、勇、誠）について語る
- 呼吸法や心眼の科学的根拠を説明
- 「心と体の関係」について主人公に教える
