# 職業ステータス設計案：戦闘3職（剣士・炎魔術師・雷魔術師）

雷魔術師を「両刀型高速アタッカー」（ATK技とMAT技を両方持つ／手数で稼ぐ）として再定義し、剣士・炎魔術師との差を**能力値曲線・職業特性・TP設定**で作るための提案。

前提：Lv上限99・現行値なし（ゼロから提案）／CTBはVisuMZ BattleSystemCTB／DEFの概念なし（耐性は被ダメ倍率で表現）／回復は貴重・一人でも死ねばゲームオーバー。

---

## 第1章：まず押さえるべきMZの仕様（ステータス設計に効くものだけ）

### 1.1 職業が持つ8つの能力値（Classes.json `params`）

| index | 能力値 | このゲームでの扱い |
|---|---|---|
| 0 | 最大HP | 生存ライン。一人死んだらゲームオーバーなので職業差の最重要軸 |
| 1 | 最大MP | 魔術師のリソース |
| 2 | 攻撃力 ATK | `a.atk` 式の火力源 |
| 3 | 防御力 DEF | **使わない**。ダメージ式で `b.def` を参照しないなら値は無意味。全職一定値で固定しておく |
| 4 | 魔法力 MAT | `a.mat` 式の火力源 |
| 5 | 魔法防御 MDF | **使わない**（同上） |
| 6 | 敏捷性 AGI | CTBでは**行動回数そのもの**（後述） |
| 7 | 運 LUK | ステート付与率の微補正（後述） |

- `params` は8本の配列で、各配列は index 1〜99 がレベル値（長さ100、index 0 は未使用）。
- エディタでは「能力値曲線」を右クリック→**曲線生成**で「Lv1の値／Lv99の値／成長タイプ（早熟・普通・晩成）」を指定できる。Pythonで生成する場合は `v(L) = v1 + (v99 - v1) * ((L-1)/98) ** k`（k<1 早熟、k=1 普通、k>1 晩成）で同等の曲線が作れる。
- 「その他」の能力（命中・回避・会心・TPチャージ率など）は`params`ではなく**特性（traits）**で職業に付ける。

### 1.2 特性で決まる「追加能力値」と「特殊能力値」

デフォルトの新規プロジェクトでは、職業側に「命中率+95%／回避率+5%／会心率+4%」の特性が付いている。**ここが職業の個性を出す2つ目のレバー**。

| 特性コード | 名称 | 3職の設計で使うもの |
|---|---|---|
| 22 / dataId 0 | 命中率 hit | 物理技の命中に**だけ**乗る（魔法技は成功率のみで判定） |
| 22 / 1 | 回避率 eva | **物理攻撃だけ**を避ける |
| 22 / 4 | 魔法回避率 mev | 魔法攻撃を避ける（別枠） |
| 22 / 2 | 会心率 cri | 会心時ダメージは**3倍**（MZ標準） |
| 22 / 6 | 反撃率 cnt | **物理攻撃を受けた時だけ**発動し、反撃は「通常攻撃」で行う |
| 22 / 9 | TP再生率 trg | 毎ターン `100×trg` のTPを回復（=TP自動回復） |
| 23 / 4 | MP消費率 mcr | 魔術師の燃費 |
| 23 / 5 | TPチャージ率 tcr | スキル使用時のTP獲得・被ダメ時のTP獲得の両方に乗る |
| 23 / 6, 7 | 物理／魔法ダメージ率 pdr, mdr | このゲームの「被ダメX倍」耐性の実体 |
| 51 / 52 | 装備武器／防具タイプ | ATK・MATのどちらが装備で伸びるかを決める |

**両刀型にとって重要な含意**
- 敵の耐性は pdr（物理）と mdr（魔法）で別々に設定される。**両刀＝敵の「物理耐性・魔法耐性の低い方」を選んで殴れる職**になる。これが雷魔術師を両刀にする戦術上の意味。
- 物理技は hit×eva、魔法技は成功率×mev で判定が分かれる。両刀は「回避型の敵には魔法技、魔法回避の高い敵には物理技」という使い分けが生まれる。
- 反撃特性（cnt）は通常攻撃で反撃するため、**雷魔術師の通常攻撃をATK依存にしておく**と「瞬間移動→反撃」系のスキルがステートの反撃率で自然に実装できる。

### 1.3 CTB（VisuMZ）と敏捷性

- VisuMZ BattleSystemCTBの初期設定では、ゲージの溜まる速度は敏捷性にほぼ比例する（速度式はプラグインパラメータで変更可能なので、変更していればそれに従う）。
- つまり**AGI比＝行動回数比**。AGIが1.35倍なら同じ時間に1.35倍行動する。
- 結果：職業の「時間あたり火力」≒「1行動の威力 × AGI」。**AGIを盛った職は1行動あたりの威力を下げないと単純上位互換になる**。これが雷魔術師のステータス設計の核心。
- 注意：「敏捷2倍」のバフ（雷化）や「敏捷×4倍」（変なテンション）はターン制よりはるかに強い。行動回数が本当に2倍になる。雷化は**+50%程度**に落とすか、持続を短くするのを推奨（第5章）。

### 1.4 TPの仕様（瞬発力設計の根拠）

| 項目 | MZ標準 |
|---|---|
| 最大TP | 100 |
| 戦闘開始時 | 0〜24のランダム（「TP持ち越し」特性があれば前の戦闘の残り） |
| スキル使用時 | スキルの「TP獲得」×tcr（攻撃系は仕様書どおり10） |
| 被ダメ時 | `50 × (ダメージ ÷ 最大HP) × tcr`（HPの20%を失うと10TP） |
| ターン毎 | `100 × TP再生率` |

- tcr 130%なら攻撃1回で13TP。TP25の技を**約2行動に1回**撃てる。tcr 80%なら8TPで**3行動に1回**。
- 「TP瞬発型」の雷魔術師は **tcr高め＋AGI高め** の掛け算で、時間あたりのTP収入が剣士の1.7倍前後になる。これが「MPよりTPを多く消費する設計」を数値で支える。

### 1.5 運（LUK）とステート付与率

- 付与率 = スキルの付与率 × `1 + (a.luk − b.luk) × 0.001`。運差100で±10%。
- 補正は小さいので、感電・麻痺を撒く雷魔術師でもLUKは「少し高め」で十分。主レバーはスキル側の付与率。仕様書の `<NoLukState>` を使う技には無関係。

## 第2章：3職の役割とステータス配分の方針

| 軸 | 剣士 | 炎魔術師 | 雷魔術師（両刀・高速） |
|---|---|---|---|
| 火力源 | ATK単独 | MAT単独 | ATK＝MAT（どちらも剣士・炎の80%） |
| 1行動の威力 | 高 | 中〜高（印で跳ねる） | 低〜中 |
| 行動回数（AGI） | 1.00 | 0.85 | **1.35** |
| 耐久（HP） | 高 | 低 | 中（回避で補う） |
| リソース | TP主体 | MP主体 | TP主体＋MP |
| 敵耐性への対応 | 物理耐性に弱い | 魔法耐性に弱い | **低い方を選べる** |

**雷魔術師の数値上の存在意義**
1. 手数：AGI 1.35倍でステート付与機会・TP収入が多い。
2. 選択：物理技（ATK）と魔法技（MAT）を敵の耐性で使い分けられる。
3. 弱み：1発の威力は剣士の約0.7倍、HPも剣士の約0.78倍。「盛られたAGIを1発の軽さで払っている」構造にする。

## 第3章：能力値曲線の具体案（Lv1 → Lv99）

全職共通の「標準値」を Lv1→Lv99 で **HP 160→2000、MP 40→500、ATK/MAT 25→250、AGI 25→250、LUK 20→200**（約10倍成長）と置き、職業ごとの倍率で振る。DEF/MDFは全職「Lv1=10、Lv99=10」の平坦固定（未使用の明示）。

### 3.1 剣士（物理・耐久・TP）

| 能力値 | Lv1 | Lv99 | 成長タイプ | 対標準 |
|---|---|---|---|---|
| 最大HP | 185 | 2300 | 早熟（k=0.9） | 115% |
| 最大MP | 25 | 300 | 普通 | 60% |
| ATK | 30 | 300 | 普通 | 120% |
| MAT | 12 | 110 | 普通 | 45%（魔法剣のMP消費用、火力には使わない） |
| AGI | 25 | 250 | 普通 | 100% |
| LUK | 20 | 200 | 普通 | 100% |

### 3.2 炎魔術師（魔法・MP・全体）

| 能力値 | Lv1 | Lv99 | 成長タイプ | 対標準 |
|---|---|---|---|---|
| 最大HP | 135 | 1700 | 普通 | 85% |
| 最大MP | 55 | 650 | 早熟（k=0.85） | 130% |
| ATK | 12 | 110 | 普通 | 45% |
| MAT | 32 | 310 | 普通 | 125% |
| AGI | 21 | 210 | 普通 | 85% |
| LUK | 20 | 200 | 普通 | 100% |

MAT を晩成にしない理由：印システムで終盤の伸びは十分に出るため、序盤を弱くしすぎない。MPを早熟にして序盤から印を回せるようにする。

### 3.3 雷魔術師（両刀・高速・TP）

| 能力値 | Lv1 | Lv99 | 成長タイプ | 対標準 |
|---|---|---|---|---|
| 最大HP | 145 | 1800 | 普通 | 90% |
| 最大MP | 42 | 520 | 普通 | 105% |
| ATK | 24 | 240 | 普通 | 95%（剣士の80%） |
| MAT | 24 | 240 | 普通 | 95%（炎の77%） |
| AGI | 34 | 340 | **早熟（k=0.9）** | **135%** |
| LUK | 22 | 220 | 普通 | 110% |

ATKとMATを**完全に同値**にするのがポイント。装備（短剣か杖か）でどちらに寄せるかをプレイヤーに委ねられる。

## 第4章：職業特性（traits）の具体案

| 特性 | 剣士 | 炎魔術師 | 雷魔術師 | 意図 |
|---|---|---|---|---|
| 命中率 | +95% | +95% | +95% | 共通（物理技の基礎命中） |
| 回避率 | +5% | +3% | **+12%** | 雷は物理を避ける職。ただし雷化と合わせて100%に近づけない |
| 魔法回避率 | 0% | +5% | +5% | 魔術師は魔法に多少強い |
| 会心率 | +6% | +2% | **+8%** | 手数×会心で雷の期待値を補う |
| TPチャージ率 | 100% | 80% | **130%** | 雷のTP瞬発力。炎はMP職なのでTP収入を絞る |
| TP再生率 | 0% | 0% | 0%（★パッシブで+3〜5%） | 職業に直付けせず、パッシブ「★雷体質」等の報酬にする |
| MP消費率 | 100% | 100%（★高速結印で-20%） | 100% | 炎の燃費はパッシブ側で |
| 装備武器 | 長剣 | 杖 | **短剣＋杖** | 雷は装備でATK寄り／MAT寄りを選べる |
| 装備防具 | 中〜重装 | 軽装のみ | 軽装のみ | 雷の耐久は回避で、剣士は防具で |

補足
- 回避型の敵と魔法回避の高い敵を用意すると、雷の両刀が「状況で技を選ぶ」職として機能する。
- 雷の会心率+8%は、AGI1.35倍と合わせて「時間あたりの会心回数」が剣士の約1.8倍になる。乱れ傷（被クリ率+20%）を撒く剣士との連携が自然に強くなる。

## 第5章：雷魔術師を両刀にするためのスキル側の対応（最小限）

ステータスだけでは両刀にならないので、ダメージ式の振り分けだけ決めておく。

| 系統 | 式 | 該当スキル（既存案から） | 理由 |
|---|---|---|---|
| 近接電撃（物理・雷属性） | `a.atk × n` | 電光石火、雷速移動後の追撃、瞬間移動の反撃、通常攻撃 | 「雷の速度で殴る」体感。hit/eva判定・反撃特性と噛み合う |
| 放電・落雷（魔法） | `a.mat × n` | 放電、サンゴ、雷3連撃系、神の裁き、雷龍、万雷 | 既存どおり |
| 混合（切り札） | `(a.atk + a.mat) × n` | 200,000,000V、雷迎 | 装備を問わず最大出力。両刀の象徴技 |

倍率の目安（剣士基準で時間あたり火力を揃える）
- 剣士 4連斬り：`a.atk × 4.8`（TP25）＝Lv30で 528 × 行動回数1.00 → **528**
- 雷 雷3連撃Lv1：`a.mat × 3`（MP45）＝Lv30で 264 × 1.36 → **359**
- 雷 サンゴ（帯電時）：`a.mat × 6` ＝ 528 × 1.36 → **718**（ただし帯電付与の1行動を前提）
- 雷 電光石火（物理）：`a.atk × 2.5`（MP55 TP30）＝220 × 1.36 → **299** ＋確定先制の価値
- 炎 火炎6連乱弾：`a.mat × 6`（MP60）＝684 × 0.84 → **574**

素の連射だけなら剣士より下、帯電コンボを組めば上、という形になる。「手数＝ステート付与とTP回収」で差を作る。

**CTBで見直したいバフ倍率**
- 雷化「敏捷2倍」→ **敏捷+50%・3T**（行動回数2倍はCTBでは過剰）。物理無効60%と組み合わせれば十分強い。
- 神速「敏捷+100%・2T」→ 2Tなら許容範囲だが、CTBでは「2行動分」と読み替える。
- 雷速移動「敏捷+200%・1T」→ 1Tなので実質「次の1行動が即来る」。CTBではむしろ「行動後にゲージを50%残す」等の実装のほうが意図に近い（VisuMZ CTBのノートタグで対応可）。

## 第6章：実装手順

### 6.1 エディタで行う場合
1. データベース→職業→対象職業を選択。
2. 能力値曲線の各タブを右クリック→「曲線生成」→ Lv1の値／Lv99の値／成長タイプを第3章のとおり入力。
3. 特性欄に第4章の行を追加（追加能力値／特殊能力値／装備武器タイプ／装備防具タイプ）。
4. DEF・MDFは Lv1=10、Lv99=10 で生成し「未使用」をコメントに残す。

### 6.2 JSONを生成する場合（既存のpandas/openpyxlパイプライン向け）

```python
def curve(v1, v99, k=1.0):
    # index 0 は未使用。1..99 をレベル値として返す（長さ100）
    return [0] + [round(v1 + (v99 - v1) * ((L - 1) / 98) ** k) for L in range(1, 100)]

# 雷魔術師
params = [
    curve(145, 1800),        # mhp
    curve(42, 520),          # mmp
    curve(24, 240),          # atk
    curve(10, 10),           # def（未使用）
    curve(24, 240),          # mat
    curve(10, 10),           # mdf（未使用）
    curve(34, 340, k=0.9),   # agi（早熟）
    curve(22, 220),          # luk
]

traits = [
    {"code": 22, "dataId": 0, "value": 0.95},   # 命中率
    {"code": 22, "dataId": 1, "value": 0.12},   # 回避率
    {"code": 22, "dataId": 4, "value": 0.05},   # 魔法回避率
    {"code": 22, "dataId": 2, "value": 0.08},   # 会心率
    {"code": 23, "dataId": 5, "value": 1.30},   # TPチャージ率
    {"code": 51, "dataId": 1, "value": 1},      # 装備武器：短剣
    {"code": 51, "dataId": 6, "value": 1},      # 装備武器：杖
    # 装備防具タイプ（code 52）はSystem.jsonの防具タイプIDに合わせる
]
```

剣士・炎魔術師も同じ関数に第3章・第4章の値を渡すだけ。

### 6.3 テストプレイで確認するチェックリスト
- [ ] Lv30付近で、剣士の4連斬り1回と雷の雷3連撃1.36回が同程度の時間に発生しているか（CTBの速度式が敏捷比例であることの確認）
- [ ] 雷が「TP25技を2行動に1回」撃てているか（tcr 130%の確認）
- [ ] 物理耐性の高い敵に雷の魔法技、魔法耐性の高い敵に雷の物理技が通っているか（両刀の意味の確認）
- [ ] 雷化中に行動回数が2倍になっていないか（倍率を+50%へ落とした場合の確認）
- [ ] 回避+12%＋雷化の物理無効で「ほぼ被弾しない」状態になっていないか（一人死＝ゲームオーバーなので回避依存は危険側にも振れる）
