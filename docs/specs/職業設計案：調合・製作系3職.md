### 劇薬システム（バフ＋デバフ同時付与）

**基本ルール**
- 敵に劇薬を投げつけると**短期バフと永続デバフが同時に**付与される
- バフは2ターンで消滅、デバフは永続で残る（※加速剤のみ例外）
- 同じ劇薬を重ねがけすると、デバフが**3段階まで強化**される
- **敵の行動パターンに合わせて劇薬を選ぶ**

| 劇薬名 | 2Tバフ効果 | デバフ効果（Lv1→2→3） | 主な用途 |
|--------|------------|------------------------|----------|
| 興奮剤 | ATK+30% | MAT -10%→-20%→-30%（永続） | 魔法も使う敵の魔法封じ |
| 集中剤 | MAT+30% | 敏捷 -15%→-30%→-50%（永続） | 速い敵の行動順操作 |
| 硬化剤 | 物理耐性0.7倍 | ATK -10%→-20%→-30%（永続） | 物理攻撃封じ |
| 加速剤 | 敏捷+50% | 被ダメージ1.2倍（**バフ中のみ**） | ハイリスク・ハイリターン |

**デバフの理由付け**
- 興奮剤：脳の過剰興奮で判断力低下 → MAT減少
- 集中剤：視野狭窄で動きの精度低下 → 敏捷減少
- 硬化剤：筋肉硬直で繊細な動作が困難 → ATK減少
- 加速剤：高速移動中は防御姿勢が取れない → 被ダメ増加（加速中のみ）

**戦術的な判断**
- 魔法も使う敵には興奮剤（MAT低下で魔法を弱体化）
- 速くて先制される敵には集中剤（敏捷低下で行動順操作）
- 物理攻撃メインの敵には硬化剤（ATK低下で火力減）
- 加速剤は**短期決戦用**：2Tの超加速中に倒しきれないと被ダメ増でリスク
- 2Tのバフ期間は味方で耐える必要あり→防御・回避・耐性で凌ぐ

## 2. 鍛冶屋

### コンセプト（再設計）
**物理アタッカー兼装備支援**。自分で鍛えた武具で戦い、味方の武器も強化する。
鍛冶の火を活かした**炎属性の物理攻撃**と、大火傷の上位互換「**過熱**」が特徴。
タンクではなく、火力貢献と支援を両立するアタッカー寄りの設計。

### 得意属性
- **打**（ハンマー・鍛冶道具）
- **炎**（鍛冶の火・焼けた金属）
- **破**（装甲破壊・防御無視）

### 設計思想
- 炎を使うが、MAT依存ではなく**ATK依存の物理炎攻撃**
- 「過熱」ステートで継続火力＋炎追撃の起点を作る
- 味方武器への属性付与・強化で間接的に火力貢献
- タンクではないので、HP・耐久は中程度

---

## 3. 旧世紀技術者（メカニック）

### コンセプト
失われた宇宙世紀の技術を**理解し、応用できる**稀有な存在。
旧世紀の機械は「使い方を知っている人」がいないと真価を発揮しない。
メカニックは設計思想・回路構造・制御理論を理解しているからこそ、
**機械の調整・ハッキング・弱点分析**ができる。

### 得意属性
- **ビーム**（既存システムと連携）
- **音**（振動理論・共鳴計算）

※電子戦（ハッキング等）は「雷属性の魔法」ではなく「技術による無属性介入」。
　雷魔術師とは明確に差別化される。

### 設計思想
- 「装置があれば誰でも使える」スキルは避ける
- 「この人の知識・技術がないと使えない」スキルに特化
- 機械の内部構造を理解しているから、調整・妨害・分析ができる
- 電子戦は魔法ではなく技術（無属性）
- 物理学・工学の理論に基づいた攻撃（共鳴・過負荷など）

## 補足：劇薬システム詳細

### 重ねがけの仕様案

```
【興奮剤・集中剤・硬化剤】
1回目投擲：バフ(2T)＋デバフLv1(永続) が同時付与
2回目投擲：バフ(2T)再付与＋デバフLv2に上書き
3回目投擲：バフ(2T)再付与＋デバフLv3に上書き（最大）

【加速剤】※例外
投擲：敏捷バフ(2T)＋被ダメ1.2倍(2T) が同時付与
バフ終了と同時にデメリットも消滅（永続デバフなし）
重ねがけ：バフ延長のみ、デメリットは変わらず
```

### 戦術例

**魔法も使うボス戦（興奮剤）**
1. 1ターン目：興奮剤投擲 → 敵ATK+30%(2T) ＋ MAT-10%(永続)
2. 2ターン目：バフ期間中、物理攻撃が痛いので盾役で耐える
3. 3ターン目：バフ消滅、デバフLv1のみ残る（MAT-10%）
4. 4ターン目：興奮剤投擲 → 敵ATK+30%(2T) ＋ MAT-20%(永続)
5. 6ターン目：バフ消滅、デバフLv2（MAT-20%）
6. 最終的にMAT-30%で魔法が弱体化したボスを叩く

**速い敵（集中剤）**
- 集中剤でMAT+30%を与えつつ、敏捷を永続で下げる
- MAT上昇中は魔法攻撃に注意
- 敏捷-50%まで落とせば行動順を完全に制御可能

**物理アタッカー（硬化剤）**
- 硬化剤で物理耐性0.7倍を与えつつ、ATKを永続で下げる
- 耐性上昇中は物理が通りにくいが、2T耐えれば逆転
- ATK-30%まで落とせば物理攻撃が大幅弱体化

**短期決戦（加速剤）**
- 加速剤は**唯一の短期戦向け劇薬**
- 敵の敏捷+50%で先制されるが、被ダメ1.2倍で脆くなる
- 2T以内に倒しきれば、敏捷バフ中に先制されるリスクと引き換えに大ダメージ
- 倒しきれないとバフだけ消えて通常に戻る（永続デバフなし）

**雑魚戦**
- 劇薬は基本使わない（バフ期間中に倒してしまうため意味がない）
- 通常の毒瓶・麻痺針・腐食液で対処
- 加速剤だけは短期決戦に使える可能性あり

## 補足：旧世紀技術者のシステム詳細

### 対機械戦術（ハッキング・回路過負荷）

```
ハッキング：機械の制御を奪い、50%で味方を攻撃させる
回路過負荷：毎ターン固定ダメージ＋スキル封印（通常攻撃のみに）
緊急停止コード：確定で1T行動不能（ボス機械にも有効）
```

**戦術例（対機械ボス）**
1. 緊急停止コード → 1T完封
2. システム解析 → 全耐性-30%
3. ハッキング → 制御混乱で自滅誘発
4. 回路過負荷 → 継続ダメージ＋スキル封印
5. 味方のビーム攻撃が耐性低下で大ダメージ

### 共鳴コンボ（振動理論）

```
周波数特定：共鳴状態を付与（音属性被ダメ2倍）
共鳴増幅：共鳴状態の敵に2.5倍ダメージ
```

**戦術例（対生物ボス）**
1. 周波数特定 → 共鳴付与（固有振動数を計算）
2. 共鳴増幅 → 2.5倍の音属性大ダメージ
3. 以降、共鳴状態が続く限り音攻撃が2倍

### 観察・計算（生物にも有効）

```
行動解析：回避-50%＋状態異常耐性-30%（5T）
耐性スキャン：状態異常耐性-30%（3T）
行動予測：味方全体の回避+30%（3T）
```

**戦術例（対生物ボス・薬師との連携）**
1. 行動解析 → 敵の回避-50%＋状態異常耐性-30%
2. 耐性スキャン → さらに耐性-30%（合計-60%）
3. 薬師の麻痺針・腐食液が高確率で命中＆付与
4. 弱点狙撃指示 → 味方全体のクリ率UP
5. 行動予測 → 味方の回避UP

**技術者＋薬師の相性**
- 技術者の耐性スキャン → 薬師の状態異常が通りやすくなる
- 技術者の行動解析 → 薬師の攻撃が当たりやすくなる
- 役割分担：技術者が「お膳立て」、薬師が「仕留める」

### 技術者の強み

| 対象 | 有効度 | 理由 |
|------|--------|------|
| 機械系敵 | ◎圧倒的 | ハッキング・回路過負荷・停止コードで完封可能 |
| 生物系敵 | ○有効 | 共鳴コンボ・行動解析・耐性スキャンで薬師と連携 |
| 機械系味方 | ◎最適 | 調整・メンテナンスで性能を引き出せる |
| 生物系味方 | ○有効 | 行動予測・弱点狙撃指示で支援可能 |
