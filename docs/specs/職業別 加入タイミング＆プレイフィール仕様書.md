# 職業別 加入タイミング＆プレイフィール仕様書

Sep 21, 2026 · @みねい

## 1. 目的と前提

本書は、全職業（＋ビーツー）について「いつ仲間になるか」と「その時点でどんな手触りを提供すべきか」を1か所に固定する。スキル・ステータスの個別設計は各職業設計案が正で、本書はそれらを加入順という軸で束ねる上位指針として扱う。

参照した設計書は次のとおり。

- 企画書（シナリオ／メインキャラ／サブクエ等）
- 世界観設定書
- 職業設計 基本方針書
- 職業設計案（戦闘3職／調合・製作系3職／追加6職 修正版v2／追加4職／追加2職／追加5職）
- 職業攻略ガイド（全23職業）
- 序盤から使える基本スキル選定案（拡張版）
- 教育要素の開示指針

既存設計書に加入時期の記述がある職はそれに従い、記述がなかった職は本書で定めた。いずれも確定とし、企画書v4.0に反映している。

## 2. 加入タイミング全体像

## 3. プレイフィール設計の共通原則

加入が早い職ほど仕組みを1つに絞り、加入が遅い職ほど特殊効果を強く複雑にする。全体の目標である「ギリギリで切り抜ける緊張感」を、加入のたびに違う角度から味わわせるための原則を6つ置く。

1. **加入直後に必ず見せ場を置く。** 加入から最初のボスまでの間に、その職がいないと苦しい敵を1種類は配置する。「なぜこの人でないとダメか」を戦闘で先に体験させ、説明は後から付ける。
2. **加入時点の操作は3手で説明できる範囲にする。** 序盤の基本スキル4つ（剣士は6つ）と重めスキル2つで、その職の核になる仕組みが1回転するようにする。
3. **準備技は1手かけたら2倍を超える。** 印・構え・弾丸生成・召喚などの準備型は、加入直後の戦闘でこの報酬を体感できる倍率にする。
4. **回復が貴重という前提を崩さない。** 新加入の職は「回復手段」ではなく「被害を減らす別の方法」（かばう、凍結、暗闇、行動順操作）として資源問題に答える。
5. **後半加入は即戦力にする。** 加入Lvはパーティー平均に合わせ、スキルツリーも加入時点の章に見合う段階まで開いた状態で渡す。育て直しの手間を加入の代償にしない。
6. **教育要素は第1層から順に開く。** 加入時はスキル説明文（第1層）と戦闘後セリフ（第2層）だけで十分とし、拠点会話以降は加入後の使用回数で開示する。

全員Lv1から始め、経験値は赤シンボルを倒したときだけ入る。想定Lvは序章1→5、第1章5→18、第2章18→30、第3章30→50、第4章50→90で、加入者はその時点のパーティー平均Lvで入る。第1章の3ルートは順不同のため、ルート加入の3職はパーティー平均Lvで加入させる。

## 4. 序章〜第1章の加入職（11職）

この時期の11職は、戦闘の基本文法を1職につき1つずつ教える役割を持つ。序章はアタッカー3人で「殴る・溜める・速く動く」を覚えさせ、遺跡の最深部でビーツーのかばうを足す。遺跡攻略後に開拓村で薬師と鍛冶屋が入って「弱らせる・強化する」が加わり、第1章の6職で「連携する・調べる・守る・呼ぶ・歌う・弾を管理する」を足す。

終盤の4職は、加入した瞬間に既存メンバーと並ぶか上回る即戦力にする。いずれも「読み合い」か「確率・時間への介入」を扱い、ここまでに覚えた準備技や連携を一段強くする側に立つ。

## 7. ビーツー

ビーツーは序章の最深部で起動し、施設防衛ドローン戦の直前に加入する。24人の中で唯一、物語の中心にいる戦闘メンバーで、位置づけは「最初のかばう役」である。

| 時期 | ビーツーの役割 | 目指すプレイフィール |
| --- | --- | --- |
| 序章〜第1章 | 唯一のかばう役 | かばう→シールドの2手で守りの基本を覚える。一撃死がゲームオーバーになるルールを、ビーツーが受けることで実感させる。剣士は攻撃に専念できる |
| 第1章〜第2章 | かばう役の1人 | 剣士の守護ツリーと聖騎士が加わり、6人編成やパーティー分割で守り手を分担する。雷弱点（1.5倍）の場面では他の誰かに任せる判断が生まれる |
| 第2章中盤以降 | バリアとスキャンの支援役 | 老兵・機械装甲兵に純耐久で抜かれた後は、支援に比重を移す。旧世紀技術者のレシピで強化される関係を保つ |
| 第4章 | 物語の鍵 | ループ1で封印の核に同化して永眠する。失う体験がループ4で救う動機になるため、ここまで編成に入れ続けたくなる強さを保つ |

成長はレベルではなく、専用クエストの記憶データ復元（第1章クリア後、第2章開始後、第2章クリア後、第4章中の全4回、最大+20%）で行う。HPは超早熟型とし、Lv30まで剣士の約1.3〜1.4倍を保つ。ループ1の離脱時に装備と育成が無駄にならないよう、離脱中の扱いを別途決める必要がある。
