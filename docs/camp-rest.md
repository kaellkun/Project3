# 焚き火休憩

焚き火イベントの「プラグインコマンド」で `CampRest: 焚き火休憩を開始` を実行すると、焚き火休憩画面を開けます。

- 「魔物の肉を使う」から肉の種類と使用個数を選び、確認して決定します。
- 肉1個につき、生存中のパーティ全員が最大HPの25%回復します。複数個使うと回復量が増えます。
- 「使わずに休憩する」も選べます。どの終了方法でも、パーティ全員のMPは最大まで回復します。
- 画面上部のヘルプ欄に説明が常時表示されます。選択操作は不要です。

標準ではアイテム ID 2・65・89 を魔物の肉として扱います。追加の肉アイテムは、アイテムのメモ欄に `<CampRestMeat>` を記入してください。対象 ID と HP 回復率は `CampRest` のプラグインパラメータで変更できます。
