# 焚き火休憩

焚き火イベントの「プラグインコマンド」で `CampRest: 焚き火休憩を開始` を実行すると、焚き火休憩画面を開けます。

- 「食材を使う」から、複数種類の食材をそれぞれ個数指定して選べます。「使わない」（0個）でその種類の選択を解除できます。
- 一覧には種類ごとの選択数／所持数、ヘルプには合計個数とHP回復率を表示します。「選んだ食材で休憩する」から確認して一括使用します。確定前は食材を消費せず、選び直しやキャンセルが可能です。
- HP回復量は食材ごとの回復率×使用個数の合計です。生存中のパーティ全員が、それぞれの最大HPに対する割合で回復します（端数切り捨て、最大HPまで）。
- 「使わずに休憩する」も選べます。休憩を確定すると、パーティ全員のMPは最大まで回復します。「やめる」では回復・消費とも行いません。
- 休憩時は通常のメニュー操作音のみを使い、専用の音・演出ウェイト・完了メッセージ待ちは入れず、回復後すぐマップへ戻ります。
- 画面上部のヘルプ欄に説明が常時表示されます。選択操作は不要です。

## 食材の設定

アイテムのメモ欄に `<CampRestHpRate:25>` を記入すると、焚き火で使える食材になり、1個で最大HPの25%を回復します。数値は0～100（小数可）。良質な魔物の肉（ID 2・65）は25%、硬めの魔物の肉（ID 89）は10%を回復します。ゴブリンはID 89の肉を落とします。

```text
<CampRestHpRate:10>
```

硬めの魔物の肉を2個、良質な魔物の肉を1個使うと、全員のHPを45%回復します。数量選択・合計表示にも個別の回復率が反映されます。

### 状態異常回復用の食材

```text
<CampRestHpRate:0>
```

HP回復なしで状態異常だけを治す場合は0を指定し、データベースの「使用効果」に「ステート解除」を設定してください。HP回復とステート解除を両方設定することもできます。

- 焚き火で確定すると、「ステート解除」だけを生存中の全員へ適用します。戦闘不能者の蘇生は行いません。
- 解除するステートと解除確率は、そのアイテムの「使用効果」に従います。複数個使えば個数分の解除判定を行います。表示される解除名は効果の候補であり、確率が100%未満の場合は解除を保証しません。
- 通常使用時の単体対象・効果は変わりません。焚き火ではダメージ・ステート付加・コモンイベントなど、ステート解除以外の通常使用効果は実行しません。
- 毒消し草（ID 9・78）には回復率0のタグを追加済みです。それぞれ元の使用効果に設定されているステートを解除します。

互換用として、プラグインパラメータの対象IDおよび `<CampRestMeat>` による登録も引き続き利用できます。回復率タグがない食材だけはプラグインパラメータ `HpRecoveryRate`（標準25%）を使用します。回復率タグがあれば常にそちらを優先します。不正な回復率は設定エラーとして通知します。

## 焚き火再開ポイント（ゲームオーバー後の再開）

- `GoddessFeatherFastTravel.js` 使用時は、`<CampRestPoint>` 付きイベントを起動すると女神様の羽根の移動先にも自動登録されます。休憩や専用コマンドの実行は不要で、セーブだけ・「やめる」でも登録されます。訪問済み情報はセーブデータに保持されます。従来のコモンイベント経由の登録と宿屋の登録も引き続き利用できます。
- 女神様の羽根は、決定ボタン・プレイヤー接触・イベント接触で起動した転送イベントの実際の転送先も、ドアの移動先として記録します。町の施設へ入ったことがあれば、次回から施設前へ直接移動できます。訪問済み情報はセーブデータに保持されます。
- 女神様の羽根のプラグイン設定「移動先カテゴリ」でカテゴリIDと表示名を定義すると、場所選択の前にカテゴリを選べます。焚き火または転送イベントのメモ欄に `<FastTravelCategory: town,forest>` のようにIDをカンマ区切りで書くと、複数カテゴリに登録されます。「すべて」にはカテゴリ未設定の場所も含まれます。
- マップイベントのメモ欄に `<CampRestPoint>` を記入すると、そのイベントを決定ボタンで起動した瞬間に再開ポイントが記録されます。イベント内でセーブだけした場合や「やめる」を選んだ場合でも記録されます。
- 再開ポイントが記録された状態でゲームオーバーになると、ゲームオーバー画面に「焚き火から再開」コマンドが表示されます（戦闘・マップ上どちらのゲームオーバーでも選択可能）。選ぶと記録時点の状態・位置に戻ります。
- プラグインコマンド `CampRest: 焚き火再開ポイントを記録` で任意のタイミングに手動で記録することもできます。
- 再開ポイントはメモリ上にのみ保持されます。ニューゲーム・セーブデータのロード・ゲーム終了でクリアされます。
- ゲームオーバー画面のコマンド表示は `BattleRetryOnPartyDeath.js` が担当します（`CampRest.js` より後に配置してください）。
