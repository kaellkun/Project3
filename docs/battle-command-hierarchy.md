# バトルコマンド（アクターのみ・２階層）

[BattleCommandHierarchy](../js/plugins/BattleCommandHierarchy.js) を関連プラグインより後に登録。
エンジン本体・データベース・セーブ形式は変更しない。

| １階層目 | ２階層目／動作 |
| --- | --- |
| 戦う | 弱攻撃、強攻撃、アイテム、補助･回復、妨害、戻る |
| オート | 全員の自動戦闘を開始。キャンセル／右クリック／長押しで解除 |
| 準備 | 装備変更、味方ステータス、敵ステータス、バトルログ、戻る |
| 入れ替え | 操作中のアクターと控えを交代する選択画面 |
| 逃げる | 既存の逃走成功率・失敗時処理を使用 |

## 操作・制約

- パーティーコマンドは表示・操作しない。互換性のためウィンドウ生成だけ維持。
- 戦うのスキルタイプIDは順に1・2・3・4。通常攻撃・防御・常時発動タイプはコマンドに出さない。
- タイプ未所持／封印中は無効表示。既存のコマンド封印・スキル使用条件を維持。
- サブメニューでキャンセルすると最上位へ戻る。スキル／アイテム一覧からは「戦う」に戻る。
- 最上位のキャンセルではパーティー選択に戻らず、そのアクターの入力を維持。
- 装備変更後は「準備」の装備変更に戻る。装備・情報・ログでは行動を消費しない。
- 味方／敵ステータスは既存のステータス・ステート情報画面を対象陣営で絞り込む。
- 情報・ログ・交代候補の表示中は時間を停止する。
- 逃走禁止の戦闘では「逃げる」を無効表示。

## 入れ替え

- 現在入力中のアクターが交代する。控えがいない場合・並び替え禁止時は無効。
- 戦闘不能・行動不能・自動戦闘の控えは選択不可。
- HP・MP・TP・ステート・装備を保持。パーティー内の加入／離脱処理は使わない。
- 交代する２人の未実行行動とゲージをリセットし、交代先は次の行動順を待つ。
- ターン制では交代がそのアクターの行動を消費し、次のアクターの入力へ進む。
- キャンセル時は誰も交代せず、ゲージ・行動も変わらない。

## 検証

[回帰テスト](../tests/battle-command-hierarchy.test.cjs) は実MZエンジンを使って
階層・コマンド封印・ターゲット選択キャンセル・TPB／ターン制・オート・逃走・
装備往復・交代・画面幅別の配置を確認する。描画基盤と情報ウィンドウはテスト用代替。
全プラグインの描画・入力の統合は、保存を無効にした隔離ブラウザーで別途確認。

RPGツクールMZで開いているプロジェクトは、外部の登録変更後に保存せず開き直すこと。
開き直す前にMZ側で保存すると、プラグイン登録が上書きされる場合がある。
