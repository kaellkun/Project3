# 素早さ比例ATB・行動順表示

[LinearTimeBattle](../js/plugins/LinearTimeBattle.js) を導入し、[プラグイン設定](../js/plugins.js)で有効化しています。
戦闘・レイアウト変更プラグインより下に配置してください。追加画像やメモタグは不要です。

## 行動頻度

1回の充填量は「素早さ ÷ 基準の素早さ ÷ 基準の充填フレーム数」です。
初期値では素早さ100が120フレーム、200が60フレームで満タンになります。
演出や入力で停止する時間を除くゲーム内時間です。既存のゲージ高速化倍率は別途適用されます。

- 素早さ200のAと100のBなら **A → A → B → A → A → B**。
- 素早さ300対100なら、300側が3回、100側が1回の行動機会を得ます。
- 小数比にも対応します。素早さ150対100なら長期的に3対2です。
- 同時刻に満タンになる場合は素早さ順。同速なら味方の並び順、その後に敵グループ順です。
- 通常開始時のゲージは全員0で、初期乱数は使いません。先制・不意打ちの有利側は満タンです。
- スキル・アイテムの「速度補正」による詠唱待ちは無効です。
- 行動処理・行動待ち中は全員の時間を停止し、他のバトラーの充填済み割合を保持します。
- 装備・ステート・強化/弱体化による現在の素早さを毎回反映します。0以下は1として扱います。
- パーティの最速キャラクターを基準にしないため、全員の素早さを上げると全員の充填も速くなります。

**回数は攻撃ヒット数ではなく、コマンドを選べる行動機会の回数です。**
反撃、行動の強制、行動回数追加、連続攻撃、行動不能は通常のMZ仕様のため例外になります。
行動不能中は充填しませんが、回復用の経過時間は進むため、全員が行動不能でも停止し続けません。
演出待ちがあるので、実時間で「戦闘全体が必ず2倍速」になるわけではありません。

## パラメータ

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| 基準の素早さ | 100 | 充填時間の基準となる素早さ |
| 基準の充填フレーム数 | 120 | 基準の素早さで満タンになる時間（60フレーム≒1秒） |
| 入力中も全員の時間を停止 | ON | コマンドを考える時間で不利にならない。入力タイムアウトも停止 |
| 行動順を表示 | ON | 画像付き予測UIを表示 |
| 予測する行動数 | 8 | 2〜16。狭い画面では表示可能な数に自動調整 |

戦闘システムが **タイムプログレス（アクティブ/ウェイト）** のときのみ有効です。
このプロジェクトのDBはウェイト設定で、変更していません。ターン制には適用しません。

完全なアクティブ入力にする場合は、DBを「タイムプログレス（アクティブ）」にして、
「入力中も全員の時間を停止」をOFFにします。その場合、コマンド入力が遅いと実際の行動回数は減ります。
素早さ比を分かりやすく保つ場合は、初期設定を推奨します。

## 行動順UI

上部コマンドの下・左寄せの小さなウィンドウに、左から近い順で表示します。
幅は「予測する行動数 × 48px + 余白」、高さは64pxで、通常のウィンドウスキンを使います。

- **青地：味方の歩行グラフィック（正面）、赤地：敵の戦闘画像**。名前は表示しません。
- 敵は同じ画像でも区別できるよう、システムが付けるＡ/Ｂなどの識別文字を右下に表示します。
- 先頭（次に行動するバトラー）の味方は足踏みアニメーションします。
- 行動中・行動待ち・入力待ちで確定したバトラーは地色が濃く、予測は薄く表示します。
- 対象選択されたバトラーは金色の枠になります。
- 同じキャラクターを複数回表示し、次の2回目・3回目も分かるようにしています。
- スキル・アイテム・敵選択一覧と戦闘ログを下にずらし、バーと操作項目が重ならないようにします。
- 味方HP欄とヘルプ欄の位置は維持します。会話表示中と戦闘終了時には非表示です。

予測は**現時点の素早さ・ゲージ・行動待ち**に基づき、状態変化に応じて更新します。
未確定のスキル、将来の素早さ変更、死亡、復活、行動不能解除、強制行動、入力を遅らせる操作などは先読みしません。
予測計算によって敵AIや乱数を消費したり、ゲージを書き換えたりすることはありません。

## 互換性・導入

- 既存セーブを利用できます。通常はゲームを再起動するだけで反映されます。
- [Keke_SpeedStarBattle](../js/plugins/Keke_SpeedStarBattle.js) のゲージ速度・早送り・オートファスト倍率を維持します。
- [FlexibleTopDownUI](../js/plugins/FlexibleTopDownUI.js)、[VerticalDisplayFullscreen](../js/plugins/VerticalDisplayFullscreen.js)、[HelpWindowThreeLines](../js/plugins/HelpWindowThreeLines.js) の配置に対応します。
- 別のATB/TPB全面変更プラグインとの同時利用は要確認です。標準のフレーム進行を共有時計に変更しています。
- ツクールのエディターでプラグイン一覧を保存すると、外部から追加した登録が上書きされる場合があります。管理画面で末尾に本プラグインがあり、ONであることを確認してください。

### 確認済み範囲

[回帰テスト](../tests/linear-time-battle.test.cjs) は `node --test tests/linear-time-battle.test.cjs` で実行できます。
実エンジンのTPB、手動入力、敵AI、行動キュー、終了処理を利用して、比率・同着・入力停止・行動不能・逃走ペナルティ・予測の副作用などを検証します。
Kekeのヘッドレステストは実ファイルから抽出したタイミング処理を利用し、描画基盤は代替実装です。
ブラウザーでは全有効プラグインを読み込み、横画面・縦画面の画像バーと配置を確認しています。

**既存のブラウザー起動エラーについて：**
[Keke_PattoMute](../js/plugins/BGM/Keke_PattoMute.js#L50) は末尾が `.js` のURLを想定しており、
このプロジェクトのキャッシュ回避用クエリ付きURLでは起動エラーになります。
今回のATBとは別件のためファイルは変更していません。ブラウザー表示検証では、そのスクリプトURLだけ検証ページ内でクエリを外して確認しました。
