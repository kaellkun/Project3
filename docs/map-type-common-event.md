# マップ種別・昼夜・特殊シンボル撃破の管理（v2.0.0）

**使い方はプラグイン管理画面のヘルプにも日本語で記載しています。** この文書を開かなくても、設定・コマンド名・計算例を確認できます。

## 最短の設定：特殊シンボル3勝で夜になる

1. マップのメモに `<マップ種別:街>`、`<マップ種別:ワールドマップ>`、`<マップ種別:ダンジョン>`、`<マップ種別:屋内>` のいずれかを記入。
2. 特殊シンボルのイベントの **「戦闘の処理 → 勝ったとき」** に、本プラグインの **「特殊シンボルの撃破を記録」** を1つ置く。「逃走可能」「敗北可能」が両方OFFで勝利分岐がない場合は **戦闘の処理の直後** に置く。
3. 宿泊などのイベントに **「朝にする（宿泊など）」** を置く。

これだけで、昼に3勝すると夜になり、宿泊後はまた昼に3勝で次の夜になります。敵の数ではなく、コマンドを呼んだ勝利の回数を数えます。通常の敵、逃走・敗北の分岐には撃破記録コマンドを置かないでください。**自動勝利検出はしません。同じ勝利に2回コマンドを置くと2回分です。**

既存の特殊シンボルを識別できる情報がまだないため、マップのイベント内容は変更していません。上のコマンドを対象イベントに配置してください。スイッチ・変数の割当は必須ではありません。

### 登録済みの見た目の初期値

| 種別 | 昼 | 夜 | 夜の影響を除外 |
| --- | --- | --- | --- |
| 街 | 1：明るい村 | 標準を継承＝5：夜の村 | OFF |
| ワールドマップ | マップ既存設定を継承 | 標準を継承＝5 | OFF |
| ダンジョン | マップ既存設定を継承 | 標準を継承＝5 | OFF |
| 屋内 | 4：屋内 | 昼と同じ4 | ON |

現在のフィルター番号：0＝標準、1＝明るい村、3＝明るめの森、4＝屋内、5＝夜の村、6＝戦闘。2は存在しません。

「夜の標準フィルター番号」を変えると、独自の夜番号を設定していない屋外マップに一括反映できます。昼・夜の独自番号は **マップ種別の設定** にまとめています。

## 屋内とフィルターの優先順

- `-2` は継承、`-1` はフィルター無効、`0` は番号0のフィルターです。
- 昼：**種別の昼 → 昼の標準 → マップの `<FilmicFilter:番号>` → 0**。
- 夜：**種別の夜 → 夜の標準 → そのマップの昼**。
- **夜の影響を除外** がONの種別は、夜でも昼用フィルターを使用します。
- `<屋内>` を追記すると、種別を維持したまま夜の影響を除外できます。例：`<マップ種別:街><屋内>` は、街として判定し、街の昼フィルターを使います。
- 建物専用の見た目なら、種別を「屋内」にするか、独自の「店」「洞窟」などを追加してください。
- 屋内でも**世界の昼夜は変わりません**。外へ出ると夜用へ戻ります。
- タグなしマップにも標準設定を適用するため、暗くしたくない洞窟などは夜除外を設定してください。
- `<昼夜フィルター無効>` のマップでは本プラグインはフィルターに触れず、LN本体・イベントによる設定に任せます。
- 同じ種別を複数登録した場合、見た目は先頭の設定、入場コモンは登録順に全件を使用します。

マップ開始・ロード・昼夜変更で再適用し、切替は瞬時です。毎フレームの上書きはしないため、イベントで一時的なフィルター演出も可能です。演出終了後は **種別・昼夜フィルターを再適用** を実行します。戦闘中の昼夜変更はマップ復帰時に見た目へ反映します。

## 撃破数と夜の到来回数の計算

独立した次の値を保持します。

| 値 | 意味 |
| --- | --- |
| 累計撃破数 | 夜も含め、撃破記録で加算した合計。朝にしても維持 |
| 今回の撃破進捗 | 現在の昼に記録した加算数。夜の到来・朝で0へ |
| 夜の到来回数 | 昼→夜の切り替わりで1加算。屋内移動やロードでは増えない |

標準の必要数は **基本撃破数 ＋ 夜の到来回数 × 必要数増減**（最低1）。

| 設定 | 各昼に必要な撃破数 |
| --- | --- |
| 基本3、増減0（初期値） | 3 → 3 → 3 → … |
| 基本3、増減2 | 3 → 5 → 7 → 9 → … |
| 基本5、増減-1 | 5 → 4 → 3 → 2 → 1 → 1 → … |
| 個別リスト `3,5,7` | 3 → 5 → 7 → 7 → … |

必要数の優先順は **指定変数の正の整数 → 個別リスト → 増減式**。最後に任意の上限を適用します。変数が0以下などのときはリスト・式へ戻ります。毎回の「撃破を記録」で計算し直すため、章や難易度による変更も可能です。**変数を変えただけでは夜へ切り替わりません。**

### 境界の扱い

- 夜になったら、宿泊などの **朝にする** コマンドまで夜のままです。歩数・時間による自動夜明けはありません。
- 昼に必要数へ到達すると1夜だけ開始し、進捗は0へ。加算の余剰は繰り越しません。
- 例：必要3、加算10 → 累計10、進捗0、到来1。合計撃破数を3で割って3夜と数える方式ではありません。
- 夜中の撃破は累計だけに加算し、次の昼には繰り越しません。
- **朝にする** は昼でも進捗を0にします。累計・到来回数は維持します。
- **夜にする** は物語用の強制切替。すでに夜なら無処理です。
- **今回の撃破進捗を変更** は昼の進捗を設定し、次の撃破時に判定します。夜中は変更しません。

## コモンイベント・変数・スイッチとの連携

- 夜・朝のコモンイベントは任意で設定できます。トリガーは **なし**。各状態変化で1回だけ通常予約し、実行中イベントやタイミングコモンには割り込みません。
- **現在の数値を変数へ取得** で、累計・今回の進捗・夜到来回数・次の必要数・あと何回で夜か、を必要なものだけ取得できます。
- 夜中の「あと何回で夜か」は0。「次の必要数」は次の昼に適用する必要数です。
- 夜状態の出力スイッチは任意です。世界が夜なら屋内でもONになります。**出力専用**なので直接切り替えず、昼夜コマンドを使用してください。
- 入場コモンも含め、初期設定のコモンIDはすべて0です。既存イベントを勝手に割り当てていません。

## ゲーム開始時の時間帯

**ゲーム開始時の時間帯** で **昼／夜** を選択できます。初期値は昼です。

- 夜開始でも全カウントは0で、夜到来コモンは実行しません。
- 最初のマップから夜用の見た目・夜状態スイッチを適用します。屋内は夜除外設定に従います。
- 夜開始→朝にする→昼に基本3勝なら、そこで初めて夜の到来回数が1になります。
- 保存済みの昼夜状態は開始設定より優先します。設定を変更しても、既存セーブの時間帯を上書きしません。
- 昼夜状態がまだない導入前のセーブは、現在の開始設定で初期化します。

## セーブ互換

昼夜・累計・進捗・到来回数は通常セーブに保存します。ニューゲームは選択した開始時間帯・全カウント0。導入前のセーブは初めて使うときに同じ初期値を作成し、導入前の撃破回数は推定しません。ロードだけで到来回数や昼夜コモンを追加しません。

## 最短の設定：街に入ったときだけ実行

1. プラグイン管理で **MapTypeCommonEvent** をONにします。プロジェクトには登録済みです。
2. **マップ種別の設定 → 街 → コモンイベント** で、実行したいコモンを選びます。
3. 対象のマップを右クリック → **編集 → メモ** に `<マップ種別:街>` を記入します。
4. コモンイベントのトリガーは **なし** にします。
5. ゲームを再起動し、別マップから街に移動して確認します。

初期設定のコモンイベントはすべて **0（なし）** です。既存のマップやコモンイベントの内容は変更していません。IDを設定するまでは入場コモンは実行しません。

## 種別の記入例

| マップの種類 | マップのメモに記入するタグ |
| --- | --- |
| 街・村 | `<マップ種別:街>` |
| ワールドマップ | `<マップ種別:ワールドマップ>` |
| ダンジョン | `<マップ種別:ダンジョン>` |
| 屋内 | `<マップ種別:屋内>` |
| 独自の種類 | `<マップ種別:城>` など。設定リストにも「城」を追加 |

- 1マップにつき1種別を指定します。タグなしは種別なしです。
- `<MapType:街>` も使用できます。両方ある場合は日本語タグが優先です。
- 前後の空白を除いて完全一致です。英字の大文字・小文字は区別します。
- 同じ種別に複数のコモンを登録すると、設定リストの順に実行します。
- 街だけで実行したい場合は、ワールドマップ・ダンジョンのコモンを0のままにします。

## 街の建物に入るたびには実行したくない場合

**種別が変わるときだけ実行** をONにして、街の屋内・店にも `<マップ種別:街><屋内>` を付けます。この場合は街の昼用フィルターを使います。種別「屋内」を選ぶと街とは別種別になるため、店から街への復帰も入場コモンの対象になります。

| 移動例 | OFF：別マップへの入場ごと（初期値） | ON：種別が変わるときだけ |
| --- | --- | --- |
| ワールドマップ → 街 | 実行 | 実行 |
| 街 → 店（種別：街） | 実行 | 実行しない |
| 店（種別：街）→ 街 | 実行 | 実行しない |
| 街A → 街B | 実行 | 実行しない |
| タグなしマップ → 街 | 実行 | 実行 |
| 同一マップ内の場所移動 | 実行しない | 実行しない |

店をタグなしにすると、店から街へ戻るときは種別が変わるため実行されます。

## 発動しないタイミング

- メニューを閉じたとき、戦闘から戻ったとき
- 通常のロード、マップ再読込だけのとき
- 同一マップID内での場所移動
- ニューゲームの開始マップ（初期設定）。必要なら **ニューゲーム開始マップでも実行** をONにします。

「初訪問だけ」ではなく、条件を満たした入場のたびに実行します。初回限定の演出にする場合は、コモン内でスイッチの条件分岐を追加してください。

## タイミングコモンとの併用

プラグイン管理では **LN_FilmicFilter → Keke_TimingCommon → MapTypeCommonEvent** の順に配置してください。タイミングコモン本体は導入・ON登録済みです。各タイミングのコモンIDは未指定（0）なので、必要な処理だけ割り当ててください。特殊シンボル専用の撃破記録を「全戦闘の勝利コモン」に置くと通常戦闘も数えるため、個別の勝利分岐に配置します。

導入したKeke v1.3.8にはキャッシュ付きURLと起動前データ参照の保護、および変数のグローバル汚染防止だけをローカル修正しています。作者・MIT表記・元のタイミング処理は保持し、修正点を本体ヘルプに記載しています。

入場コモン・昼夜管理は単独でも動作します。フィルター連携だけLN本体が必要です。入場コモンはタイミングコモンの設定や既存の予約を上書きせず、昼夜コモンは標準予約キューへ追加します。

通常の実行順は次のとおりです。

1. タイミングコモンの「場所移動-前」
2. 場所移動
3. タイミングコモンの「場所移動-後」と終了後の処理
4. 継続中の通常マップイベントの残り、既存の予約コモン
5. 本プラグインの入場コモン
6. その他の開始待ちマップイベント・自動実行コモン

タイミングコモンが別のタイミングコモン中などの理由で「場所移動-後」を実行しない場合、本プラグインは実行中の処理の終了を待ちます。省略されたタイミングコモンの補完は行いません。

### 注意点

- **街限定のコモンをタイミングコモンの「場所移動-後」にも登録しないでください。** 両方に登録すると2回実行されます。
- タイミングコモンの「全無効」は、本プラグインの入場コモンには影響しません。
- 入場コモンは通常のマップインタープリターで実行します。文章表示・ウェイト・子コモン呼び出しが使えます。通常イベントの処理途中には割り込みません。
- 並列処理イベントは止めません。文章表示などを並列イベントと同時に操作しないようにしてください。
- 開始待ちの間に別マップへ移動すると、古いマップの未実行の入場予約は破棄されます。
- 入場コモン内で別マップへ移動すると、移動先で再び条件判定します。無限の移動ループに注意してください。
- 存在しないコモンIDは警告してスキップし、空のコモンは何もせずスキップします。

## セーブ・ロード

導入前のセーブでも使用できます。マップ開始時に現在の種別を読み直します。

未実行の入場予約はマップデータと一緒にセーブされます。入場直後のオートセーブ等からロードすると、**保存時点で未実行だった予約を再開**します。実行済みの状態をセーブした場合は、ロードで新しく発動しません。実行中のコモンは標準インタープリターとして保存・再開されます。
