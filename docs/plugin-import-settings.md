# 追加プラグイン設定の統合

登録の一次情報は [js/plugins.js](../js/plugins.js)。Project1の参照設定をもとに、配置先のパスへ変換して登録しています。

## 今回の追加分

- 未登録の新規31件を登録（ON 22件／OFF 9件）。前回までの59件の設定・有効状態・相対順は保持。
- Archive内の旧プラグインは追加対象外。
- 参照元でOFFだったものはOFFを維持。パラメーターは移植済み。
- 共通基盤の後、既存の独自UI・戦闘プラグインより前に追加。ステート経過ターン、パッシブスキル、スキルコスト基盤を利用側より先に読み込む。
- 追加5ファイルのプラグイン名取得を、キャッシュ回避用のクエリ付きURLに対応。

## 重複を避けるための例外

| 登録 | 状態・理由 |
| --- | --- |
| `Battle/Slip/Keke_SlipCustom` | 前回採用したものをONで維持 |
| `State/Keke_SlipCustom` | 別版。参照パラメーターを移植し、二重実行を避けてOFF |
| `State/NUUN_SlipDamageEX` | 参照元どおりOFF。既存Kekeスリップ処理と同時有効化しない |
| `State/SlipDamageEX` | NUUNスリップ処理の旧版。参照元に独立登録がなく、パラメーター定義もないため空設定・OFF |

既存の `BattleEquipCommand` は引き続き使用します。

## 設定上の注意

- `NRP_EquipSlot` の参照設定は11枠。アクター等のメモ設定があればそちらが優先されます。
- `LL_EncounterAdjust` の参照値 `encountRate=0` はランダムエンカウントを無効化します。
- `NUUN_Destination` 単体では表示しません。後続の[外部JSON・メニュー表示アドオン](destination-external-data.md)で表示とデータ編集に対応しています。
- `DescriptionExtend` は参照元の3行設定を維持し、後続の `HelpWindowThreeLines` と組み合わせています。
- `MainFontLetterSpacing` は標準の縁取り・本文描画フックを使うよう拡張済みです。`NRP_MessageShadow` の影色・位置・太さ・対象設定が独自文字間描画にも反映され、無効コマンドの薄さも維持します。両プラグインの前後関係は問いません。
- 他プロジェクト由来のスイッチ・ステート・アニメーションIDや文章は意味まで自動変換していません。個別のゲーム内容に合わせた調整が必要です。

## 検証範囲

[登録検証](../tests/plugin-registration.test.cjs) で、実在パス、登録漏れ、有効な同名プラグインの重複、依存順序、OFFにすべき別版、主要設定、URLからの名前取得を確認します。参照元プロジェクトがなくても実行できます。

全有効プラグインを読み込む独立したブラウザー環境で、タイトル、メニュー、アイテム、スキル、装備候補、オプション、セーブ画面の表示、ステータス画面のPC／縦画面操作、マップ、戦闘中の装備画面への往復、自動戦闘の終了を確認しました。検証中の保存は無効化しています。

個別メモタグの全組み合わせ、すべての戦闘イベント、既存セーブの移行、全端末の表示を保証する検証ではありません。

**RPGツクールMZが開いている場合は、保存する前にプロジェクトを開き直してください。エディターの古い設定で外部変更が上書きされるのを防ぐためです。**
