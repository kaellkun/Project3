# 序章ボス設計：畑荒らしの大猪・瓦礫纏いの作業機

薬草地帯の手前（まだ安全な場所）で必ず倒す大猪と、遺跡の最初の赤シンボルS1（イワロック型）の数値案。

**前提**：大猪を序章の最初の赤シンボル（Lv1で挑み、倒してLv2）とし、S1はLv2で挑む。大猪を赤シンボルにしない場合は、S1をLv1で挑むことになるので、HPを3400前後に下げる（6章）。

------------------------------------------------------------------------

## 1. 畑荒らしの大猪（ドスファンゴ型・モンハン）

**場所・Lv**：村の畑の外れ、薬草地帯へ抜ける道／Lv1（必須）

**教える軸**：戦いの準備は戦闘前から始まっている（村の道具と森の素材を持ち込む）。相手の一番強い行動を逆に利用する。

**本作での形**：畑に居座り、作物を荒らしている大猪。村人は困っているが、殺したいとまでは思っていない。倒すと死なずに山へ逃げ、村人が電気柵を立てる。

### 1.1 能力値

| 項目 | 値 |
|------|----|
| 能力値 | `[6500, 0, 85, 0, 0, 0, 60, 0]` |
| 属性有効度 | 近接物理 70％、炎 130％ |
| ステート有効度 | 粉毒 100％（毒の粉が効く） |
| メモ | `<ShieldPoints:5>`（弱点は炎が自動で入る） |

### 1.2 行動（自分の行動回数で4つの周期）

| 順 | スキル | 内容 |
|----|--------|------|
| 1 | 体当たり | `a.atk*1.5`（約128）、打＋近接物理、敵単体ランダム、分散10 |
| 2 | 土かき | ダメージなし。「前足で土を掻いている……」。行動予測で次の突進が見える |
| 3 | 猪突進 | `a.atk*4`（306〜374）、打＋近接物理、敵単体ランダム、分散10。Lv1の炎（380）は満タンなら耐え、削られていれば倒れる |
| 4 | 泥浴び | 自分の粉毒を解除する。「ぬた場に転がり、体の泥を塗り直した」 |

- **怒り**：HPが50％以下になったら1回だけ「いきり立つ」（敏捷1.4倍のステート）。以降も周期は同じ。
- 周期は行動条件「ターン 1+4X / 2+4X / 3+4X / 4+4X」で作れる（タイムプログレスでは本人の行動回数）。

### 1.3 回答（村の道具と森の素材）

**毒の粉（既存・森の毒キノコが必ず落とす）**

- 粉毒は1行動ごとに600（3〜6行動）。泥浴びで消される。
- 泥浴びの直後にかけると最大3回分（1800）入る。泥浴びの直前にかけると無駄になる。周期を読む遊び。

**撒き菱（新規・武具屋）**

- 大猪に使うと、状態「撒き菱」が付く。次の猪突進で効果が出て、消費される。
- **1回目**：踏んで転倒。突進は不発になり、大猪に300ダメージとブレイク（2行動分）。
- **2回目以降**：見切って避ける。突進はそのまま当たり、撒き菱は無駄になる（猪は学習する）。

**撒き菱に雷を流す（電気柵）**

- 撒き菱状態の大猪に雷属性の攻撃が当たると、「通電撒き菱」に変わる。
- 通電撒き菱は、何回目でも転倒させられる。
- 一度でも通電撒き菱で転倒すると「電気を覚えた」状態になる。以降、撒き菱が撒かれていると突進をやめて威嚇（ダメージなし）に変え、撒き菱は消える。
- 電気柵は痛みで「近づくと危ない」と学習させる仕組み、という教育要素をそのまま戦闘にする。

### 1.4 シミュレーション（Lv1）

勝率／勝ったときの残りHP合計（％）。各4000戦。撒き菱2個、毒の粉3個を持っている想定。

| 回答 | 結果 |
|------|------|
| なし（殴るだけ） | 0％ |
| 撒き菱だけ | 37％／50 |
| 毒の粉だけ | 39％／50 |
| 撒き菱＋通電 | 68％／63 |
| 撒き菱＋毒の粉 | 100％／86 |
| 撒き菱＋通電＋毒の粉 | 100％／86 |

- 赤シンボルの基準（回答0で負け、1つでときどき勝てる、2つでぎりぎり勝てる）に沿っている。2つ揃えたときは少し楽寄りだが、安全な場所の最初のボスなのでこのままを推奨。
- 挑発は回答にならなかった（剣士が突進を受け続けて先に倒れる）。挑発は機械虫の圧砕の回答として残す。

### 1.5 報酬・教育

- 報酬：猪の革、猪の牙（合成素材）。
- 教育の入口：日本の獣害と電気柵。殺さずに近づかせない、という共存の道具。戦闘後に村人が電気柵を立てる会話を入れる。
- 探究とのつなぎ：畑の柵の探究（鉄の虫はいつ出るのか）と並べて、「同じ畑を荒らすものでも、獣は学習し、機械は学習しない」を次の問いにできる。

## 2. S1 瓦礫纏いの作業機（イワロック型・ゼルダ）

**場所・Lv**：遺跡・上層／Lv2（大猪を赤シンボルにした場合）

**教える軸**：弱点は「ある」ものではなく「作る」もの（既存の設計どおり）。

### 2.1 能力値

| 項目 | 値 |
|------|----|
| 能力値 | `[4200, 0, 75, 0, 0, 0, 40, 0]` |
| 属性有効度 | 近接物理 30％、魔法 50％、鉱石特攻 300％ |
| メモ | `<ShieldPoints:6>` `<WeakElements:19>`（シールドを削れるのは鉱石特攻だけ） |

### 2.2 行動（4つの周期）

| 順 | スキル | 内容 |
|----|--------|------|
| 1 | 殴打 | `a.atk*1.5`（約113）、打＋近接物理、敵単体ランダム |
| 2 | 天井が軋む | ダメージなし（予告1） |
| 3 | 天井が大きく軋む | ダメージなし（予告2） |
| 4 | 天井落とし | `300`（固定）、打＋遠距離物理、敵全体、分散10 |

- 天井落としはLv2の炎（415）・雷（437）が満タンなら1回耐え、2回目で倒れる。剣士は遠距離物理0.8倍で約240。
- 近接物理ではないので、隊列の後衛でも避けられない。

### 2.3 回答

**雷で配線に通電する（露出）**

- 紫電-放（雷＋魔法）が当たると、状態「露出」になる（S1の2行動分）。
- 露出：近接物理の有効度×3.3、魔法の有効度×2（瓦礫の装甲がほぼ無くなる）。倍率は1.0を超えないので、弱点システムとは干渉しない。
- 紫電-斬（近接物理＋雷）では露出しない。「電気を通すには、斬るのではなく流す」という差を見せる。
- 炎は露出していない間に火遁印を結び、露出したら豪火球を撃つのが最適になる。

**採掘つるはし（初期装備の具体案どおり、鍛冶場で借りる）**

- 攻撃に鉱石特攻を付ける。近接物理0.3倍×鉱石特攻3倍で、ほぼ等倍になる。
- シールドを削れる唯一の手段で、6回当てるとブレイク。

### 2.4 シミュレーション（Lv2）

| 回答 | 結果 |
|------|------|
| なし | 0％ |
| 露出だけ | 65％／37 |
| つるはしだけ | 30％／37 |
| 露出＋つるはし | 99％／91 |

## 3. 新しく作るもの

| 種類 | 名前 | 内容 |
|------|------|------|
| アイテム | 撒き菱 | 武具屋。敵単体に状態「撒き菱」を付与 |
| ステート | 撒き菱／通電撒き菱 | 次の猪突進で効果。雷属性の被弾で撒き菱→通電撒き菱に置き換え |
| ステート | 電気を覚えた | 大猪専用。撒き菱があると突進を威嚇に変える |
| ステート | いきり立つ | 敏捷×1.4 |
| ステート | 露出 | 近接物理×3.3、魔法×2、2行動で解除 |
| スキル | 体当たり・土かき・猪突進・泥浴び・いきり立つ・威嚇 | 大猪 |
| スキル | 殴打・天井が軋む・天井が大きく軋む・天井落とし | S1 |

## 4. 実装メモ

- 猪突進の撒き菱判定は、ダメージ式の中で `a.isStateAffected(撒き菱)` を見て分岐させるのが一番手軽（不発時は0ダメージを返し、大猪側にダメージと転倒を入れる）。
- 撒き菱→通電撒き菱、紫電-放→露出は「特定の属性で被弾したら状態を変える」処理なので、Keke_ReactionSkill（雷化で使用中）かStateUpdateで作る。
- 転倒をシールドブレイクとして起こせるか（外部から強制ブレイクするAPIがあるか）は要確認。無ければ「転倒（行動不能2行動）」のステートで代用し、被ダメ2倍は付けない（弱点システムの方針に合わせる）。その場合、撒き菱の強さは少し下がる。
- 採掘つるはしは、武器2本装備なら剣と併用できる。その場合、剣士はミナモギリも使えるので、シミュレーションより少し楽になる。

## 5. シミュレーションの前提

- 初期装備とパッシブ（剣：回避+10・会心+15・斬×1.2、炎：炎×1.1、雷：回避+30・魔法回避+30）を反映。
- 回復アイテム、瞑想、TP技、鍛冶場で研ぐ、風切り羽根などは使っていない。
- 行動はAGIに比例（LinearTimeBattle）。
- 粉毒の600/Tは「変更一覧」で未調整とされている値。ここが変わると大猪のHPも見直す。
- 機械虫の設計書のシミュレーションはパッシブを反映していないので、実機では表より少し楽になる可能性がある。

## 6. 大猪を赤シンボルにしない場合

S1をLv1で挑むことになる。Lv1ではHP4500で「露出＋つるはし」でも45％だったので、HPを3400前後に下げる。序章の赤シンボルは14体のままで済む。

赤シンボルにする場合は序章が15体になり、全体で最終Lvが100になるので、どこか1体を任意に回すか、第1章以降で1体減らす。
